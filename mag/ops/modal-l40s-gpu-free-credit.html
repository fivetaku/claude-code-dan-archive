Modal 무료 크레딧으로 L40S GPU 코딩 모델 돌려보니

서버리스 GPU 임대 서비스 Modal의 무료 크레딧으로 오픈 소스 코딩 모델을 얼마나 돌릴 수 있는지 실측치와 공식 단가로 따져봤다

2026-08-16논의 1회 정리

클로드코드로 매일 작업하다 보면 API 요금이 부담스러운 순간이 온다. 오픈 소스 코딩 모델을 무료로 GPU에 얹어 대신 굴릴 수 있다면 어떨까. 클코단 방에서는 서버리스 GPU 임대 서비스 Modal로 L40S를 무료 크레딧 범위 안에서 돌려본 사례가 공유됐다. 실제로 몇 시간이나 쓸 수 있는지, 어디서 발이 걸리는지 짚어봤다.

서버 관리 없이 GPU를 빌린다는 것

Modal은 파이썬 함수에 데코레이터를 하나 붙이면 그 함수가 GPU 컨테이너로 자동 배포되는 구조의 서버리스 플랫폼이다. 서버를 직접 띄우고 SSH로 들어가 환경을 세팅하는 대신, 코드만 올리면 요청이 들어올 때 컨테이너가 뜨고 끝나면 사라진다. 같은 서버리스 GPU 시장에서 RunPod은 SSH로 접속해 직접 설정하는 팟 모델과 관리형 서버리스 엔드포인트를 함께 제공한다는 점에서 결이 다르다.

값싸게 쓰려는 이들이 몰리는 이유는 단순하다. 초 단위 과금이라 GPU를 쓴 시간만큼만 내면 된다. 방에서도 이 점이 부각됐다. 사용 한도를 낮게 걸어두면 예산을 벗어날 걱정 없이 시험해볼 수 있다는 설명이었다.

크레딧 30달러가 실제로 몇 시간인가

Modal 공식 가격 페이지 기준 L40S는 시간당 1.95달러다. 방에서 언급된 "월 약 50시간"이라는 계산은 이 단가로는 나오지 않는다. 30달러를 1.95달러로 나누면 15시간 남짓이다. 50시간에 가까운 수치는 L40S보다 훨씬 저렴한 GPU 단가를 적용해야 나온다. 현재 단가로 환산하면 30달러는 A100 80GB 약 12시간, B200 약 5시간에 해당한다. GPU 종류를 어디에 맞추느냐에 따라 같은 크레딧의 체감 사용 시간이 서너 배씩 벌어진다. 방에서 오간 "50시간"은 L40S가 아니라 다른 GPU 기준이 섞였을 가능성이 있다.

Starter 플랜은 월 30달러 무료 크레딧을 제공한다. Modal을 사용하려면 결제수단을 등록해야 한다. 방에서 나온 "결제수단 등록 시 크레딧이 늘어난다"는 설명과 방향은 같다. 다만 정확한 금액 구간은 계정 상태에 따라 달라질 수 있어 콘솔에서 직접 확인해보는 편이 안전하다.

MTP를 얹으면 숫자가 바뀐다

방에서 공유된 측정값 중 눈에 띄는 건 컨텍스트 160K, 초당 약 69토큰이라는 수치다. 이 환경에는 MTP, 멀티 토큰 예측이 적용됐다고 언급됐다. MTP는 모델이 한 번에 여러 개의 다음 토큰을 동시에 예측하도록 훈련시켜 별도의 드래프트 모델 없이도 추론 속도를 끌어올리는 기법이다. vLLM 프로젝트 문서는 EAGLE, n-gram과 함께 MTP를 스펙 디코딩 방식의 하나로 지원한다고 밝히고 있다. 관련 벤치마크에서는 MTP를 켰을 때 초당 토큰 수가 1.7배가량 뛴 사례가 보고됐다. 69토큰이라는 수치 자체가 유난히 빠른 편은 아니다.

클로드코드에 직접 물릴 수 있는가

Modal에서 띄운 모델을 클로드코드의 백엔드로 쓰는 방법도 이미 여럿 나와 있다. 흔히 쓰이는 방식은 LiteLLM 같은 프록시를 중간에 두는 것이다. 클로드코드가 보내는 앤트로픽 형식의 요청을 프록시가 받아 vLLM이 이해하는 OpenAI 형식으로 바꿔준다. 응답이 오면 다시 거꾸로 변환해 돌려준다. 이 조합을 시도한 개발 블로그들은 vLLM을 띄울 때 툴 콜 파서 옵션을 켜지 않으면 클로드코드가 기대하는 형식으로 도구 호출이 나오지 않는다는 점을 공통으로 지적한다.

앤트로픽 깃허브 저장소에는 클로드코드 하네스에서 자체 호스팅 모델을 정식으로 지원해달라는 기능 요청도 올라와 있다. 아직은 커뮤니티가 프록시로 우회하는 단계에 가깝다는 뜻이다.

콜드스타트라는 숨은 비용

서버리스의 함정은 쉬다가 다시 켜질 때 드러난다. Modal 측 설명으로도 최적화 없이는 대형 모델의 첫 요청이 컨테이너 콜드스타트 때문에 수십 초에서 1분 넘게 걸릴 수 있다. Modal은 GPU 메모리 스냅샷 같은 기법으로 이 시간을 12초 수준까지 줄였다고 밝힌다. 다만 콜드스타트 한 번마다 로딩 구간의 GPU 사용료가 그대로 붙는다. 20초짜리 콜드스타트 한 번에 대략 0.01달러가 나간다는 계산도 있다. 요청이 뜨문뜨문 들어와 컨테이너가 계속 껐다 켜지는 구조라면 이 금액이 쌓여 무시하기 어려운 항목이 된다.

써본 사람들 사이에서는 추론 제공 서비스를 두 부류로 나누는 얘기가 많다. 상시 가동 GPU에 요금을 얹어 빠르게 응답하는 쪽과, Modal이나 RunPod처럼 직접 vLLM을 설정하고 느린 콜드스타트를 감수하는 대신 저렴하게 쓰는 쪽이다. 컨테이너를 쉬지 않고 돌릴 때 쓸 수 있는 시간도 GPU 단가에 따라 달라진다. 실제 사용은 요청 사이 공백마다 콜드스타트가 끼어들기 때문에, 같은 크레딧으로 체감할 수 있는 시간은 이보다 줄어들 가능성이 크다.

무료 크레딧으로 코딩 모델을 굴려보는 실험 자체는 지금도 가능하다. 다만 크레딧이 몇 시간짜리인지는 어떤 GPU를 고르느냐에 달렸다. 그 시간의 상당 부분이 순수 추론이 아니라 컨테이너를 다시 깨우는 데 들어갈 수 있다는 점은 미리 계산해두는 편이 낫다.

Modal 무료 크레딧으로 L40S GPU를 얼마나 쓸 수 있나?

클로드코드에 자체 호스팅한 모델을 연결할 수 있나?

Q
