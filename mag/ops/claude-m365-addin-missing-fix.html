Claude M365 애드인 사라진 이유와 복구 방법

개인 Microsoft 계정과 Mac에서 반복된 Claude for Microsoft 365 누락 현상을 공식 상태와 사용 사례로 점검한다.

2026-11-25논의 1회 정리

Claude for Microsoft 365 애드인이 Excel·Word·PowerPoint에서 갑자기 사라지는 문제가 2026년 11월 24일 보고됐다. Anthropic은 일부 사용자에게만 발생하는 장애로 분류했지만 현재까지 원인은 공개하지 않았다. 이 글은 어떤 계정과 환경이 영향을 받았는지, 재설치가 해결책인지, 업무를 계속하려면 무엇을 써야 하는지에 답한다.

장애는 Claude 전체가 아니라 Office 애드인에 집중됐다

Anthropic 상태 페이지는 11월 24일 00:10 UTC부터 Claude for Microsoft 365 애드인이 사라지는 현상을 조사 중이라고 밝혔다. 대상은 Mac에서 개인 Microsoft 계정으로 Office에 로그인한 사용자다. Excel, Word, PowerPoint에서 애드인이 보이지 않지만 핵심 Claude 서비스와 다른 앱은 영향을 받지 않는다고 설명했다. (status.claude.com)

이 구분은 중요하다. Claude 웹사이트에 접속할 수 있고 일반 대화도 된다면 모델 장애가 아니라 Office 안에서 애드인을 불러오는 경로의 문제일 가능성이 크다. Anthropic은 업무·학교 계정은 영향을 받지 않는 것으로 안내했다. 다만 공식 공지는 “영향받지 않는 것으로 보인다”는 범위만 제시했을 뿐 지역별 차이나 예외 조건까지 설명하지는 않았다.

클코단 논의에서도 같은 상태 알림이 두 차례 공유됐다. 방에서는 원인보다 “일부 사용자에게 애드인이 누락됐다”는 점을 핵심으로 받아들였고, 장애가 전체 Claude 서비스 중단은 아니라는 해석이 많았다.

개인 계정과 Mac에서 문제가 집중된 이유

이번 현상은 기업용 Microsoft 365 테넌트 전체가 내려간 사건과 다르다. Microsoft Marketplace의 Claude for Microsoft 365 등록 정보는 Mac과 Windows의 Microsoft 365, 웹용 Word·Excel·PowerPoint를 지원 환경으로 제시한다. 애드인은 Microsoft Marketplace에서 설치되고 문서 안의 사이드바에서 Claude를 호출하는 구조다. (marketplace.microsoft.com)

Anthropic의 공식 안내가 특정한 조건은 개인 Microsoft 계정, Mac용 Office, 데스크톱 앱의 애드인 표시 문제다. 따라서 회사 계정의 관리자 정책 문제와 개인 계정에서 발생한 서비스 측 오류를 같은 방식으로 진단하면 안 된다. 기업 계정에서는 조직 배포나 Microsoft Entra 동의 같은 별도 조건이 작동할 수 있다. (support.claude.com)

일부 사용자 보고에서는 애드인을 다시 설치해도 문제가 계속됐다는 반응이 있었다. 이런 사례는 단순한 Claude 계정 로그아웃만으로 설명하기 어렵지만 Anthropic이나 Microsoft가 이를 공식 원인으로 확정한 것은 아니다. (learn.microsoft.com)

재설치보다 먼저 확인할 세 가지

첫째, Office 계정 유형을 확인해야 한다. 개인 Microsoft 계정으로 로그인했다면 이번 장애의 공식 영향 조건과 겹친다. 회사나 학교 계정이라면 관리자 설정 또는 조직 배포 상태를 먼저 확인하는 편이 맞다.

둘째, 웹 버전을 시험해야 한다. Anthropic은 장애 대응책으로 office.com의 웹용 Word·Excel·PowerPoint를 제시했고, 해당 환경에서는 Claude가 많은 사용자에게 계속 표시된다고 안내했다. 데스크톱 앱의 애드인 목록만 비어 있고 웹에서는 나타난다면 Claude 구독이나 문서 자체보다 Mac용 Office의 표시·동기화 경로를 의심할 수 있다. (status.claude.com)

셋째, 다른 애드인도 함께 사라졌는지 살펴봐야 한다. Claude만 사라졌다면 Anthropic의 이번 장애와 연결할 단서가 된다. 여러 애드인이 동시에 없어졌다면 Office 계정의 애드인 카탈로그, 캐시, 배포 정책 문제가 별도로 얽혔을 수 있다.

반대로 무작정 캐시를 지우거나 앱을 반복 설치하기보다, 공식 상태 페이지가 권장한 웹 버전과 계정 유형·실행 환경을 먼저 확인하는 편이 낫다. (personscan.online)

애드인은 문서 작업 흐름에 붙어 있어 영향이 작지 않다

Claude for Microsoft 365는 단순한 채팅 창이 아니다. Microsoft Marketplace 설명에 따르면 Excel에서는 여러 시트의 내용을 읽고 수식이 포함된 모델을 수정할 수 있으며, PowerPoint에서는 기존 템플릿을 활용하고 Word에서는 추적 변경 방식으로 편집할 수 있다. 한 앱에서 진행한 대화의 맥락을 다른 Office 앱으로 이어가는 것이 제품의 핵심 사용 방식이다. (marketplace.microsoft.com)

Anthropic도 Excel, PowerPoint, Word, Outlook을 오가는 업무를 주요 사용 사례로 소개했다. 모델을 Excel에서 검토한 뒤 PowerPoint 자료나 Word 문서로 옮기는 흐름을 애드인 안에서 처리하는 방식이다. 애드인 하나가 사라져도 Claude 전체를 못 쓰는 것은 아니지만 파일을 내려받아 웹 채팅에 다시 올리는 우회 작업이 필요해진다. (anthropic.com)

개인 개발자나 1인 사업자에게는 이 차이가 더 크게 느껴질 수 있다. 문서 요약만 필요하면 Claude 웹 버전으로 버틸 수 있지만 수식·슬라이드·추적 변경을 유지해야 한다면 웹과 데스크톱 사이의 전환 비용이 생긴다. 이번 장애가 보여준 문제는 AI 모델의 품질보다 업무 진입점의 안정성이 생산성을 좌우한다는 데 있다.

복구 시점보다 중요한 것은 영향 범위의 공개다

11월 25일 현재 Anthropic 상태 페이지에는 해당 incident가 해결됨으로 바뀌지 않았고, 개인 계정 사용자는 웹 버전을 임시 대안으로 사용하라는 안내가 남아 있다. 원인과 복구 예정 시각도 공개되지 않았다. (status.claude.com)

이번 사례에서 확인된 사실은 분명하다. 개인 Microsoft 계정으로 Mac용 Office를 쓰는 일부 사용자에게 Claude 애드인이 사라졌고, 업무·학교 계정과 Claude 핵심 기능은 공식 안내상 영향을 받지 않았다. 반면 Office 업데이트, 캐시, 애드인 카탈로그 중 무엇이 직접 원인인지는 아직 확인되지 않았다.

따라서 지금 필요한 판단은 “Claude가 고장 났는가”가 아니다. 웹 버전에서 같은 계정으로 애드인이 보이는지, 다른 Microsoft 계정에서는 정상인지, 다른 애드인도 함께 사라졌는지를 나눠 확인해야 한다. 이 구분이 끝나야 재설치가 해결책인지 Anthropic의 복구 공지를 기다려야 하는지 결정할 수 있다.

자주 묻는 질문

Q

Claude for Microsoft 365 애드인이 왜 사라졌나요?

Anthropic은 개인 Microsoft 계정으로 Mac용 Office를 사용하는 일부 사용자에게서 애드인이 사라지는 문제를 조사 중입니다. 정확한 원인과 복구 시점은 아직 공개되지 않았습니다.

Q

Claude 애드인이 안 보일 때 어떻게 사용하나요?

Anthropic은 office.com의 웹용 Word, Excel, PowerPoint를 임시 대안으로 안내했습니다. 웹 버전에서도 보이지 않으면 계정 유형과 다른 애드인의 표시 여부를 함께 확인해야 합니다.

Q

회사나 학교 계정도 영향을 받나요?

현재 공식 안내는 업무·학교 계정은 영향을 받지 않는다고 설명합니다. 다만 조직의 Office Store 정책이나 관리자 배포 설정으로 애드인이 보이지 않는 별도 문제는 발생할 수 있습니다.
