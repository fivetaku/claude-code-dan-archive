Aside vs Ego Lite, Claude Code 브라우저 자동화 어느 쪽을 붙일까

보조 브라우저는 Ego Lite, 윈도우 e2e는 Aside라는 실사용 판단을 공식 문서와 대조해 설치 순서와 한계까지 정리했다

2026-09-09논의 1회 정리

코딩 에이전트에 브라우저를 쥐여 주는 도구가 두 개 늘었다. 6월에 나온 Aside는 자체 에이전트를 품은 브라우저다. 4월에 깃허브에 올라온 Ego Lite는 Claude Code나 Codex가 조종하는 빈 브라우저다. 클코단에서는 둘을 써 본 뒤 용도에 따라 답이 갈렸다는 의견이 모였다. 메인 에이전트를 거드는 보조 브라우저라면 Ego Lite, 윈도우에서 e2e 테스트를 돌리는 안정성이라면 Aside라는 판단이다. 이 기사는 그 판단이 어디서 나왔는지, 실제로 어떻게 설치해 무엇을 시키는지, 그리고 아직 검증되지 않은 부분은 무엇인지에 답한다.

같은 문제를 반대 방향에서 푼 두 도구

둘 다 출발점은 같다. 브라우저 자동화 프레임워크는 별도 브라우저에서 기존 로그인을 유지하려면 인증 상태를 불러오는 설정이 필요하다. 사람과 에이전트는 같은 탭을 두고 다툰다. Ego Lite 저장소는 이 문제를 그대로 적어 둔다. 그러면서 사람과 에이전트가 처음부터 나눠 쓰도록 설계한 하나의 브라우저라고 자기를 소개한다.

Ego Lite는 Citro Labs가 만들었고 브라우저 앱은 무료 비공개 소스, 에이전트가 쓰는 ego-browser 스킬은 MIT 라이선스다. 에이전트마다 Space라는 격리 공간을 받아 여러 작업이 동시에 돈다. 사용자의 탭은 건드리지 않는다. 8월 중순 기준 깃허브 별은 1만 개에 가깝다.

Aside는 방향이 반대다. Y Combinator F25 배치의 Aside Computer가 만든 크로미움 기반 독립 앱으로, 에이전트가 브라우저 안에 들어 있다. 로그인된 메일·대시보드·내부 도구를 사람처럼 오가며 일을 끝내는 것이 핵심 기능이고, 개발자용으로 CLI·MCP·REPL을 1.0부터 함께 실었다. 회사가 자체 저장소에 올린 Online-Mind2Web 점수는 300문제 중 297문제 정답이다. 다만 eesel AI 같은 리뷰 매체는 자체 채점이라 제3자 재현 전까지는 벤더 주장으로 보라고 적었다.

Claude Code 보조용으로 Ego Lite를 고른 이유와 설치 순서

방에서 보조용으로 Ego Lite를 권한 의견의 근거는 단순했다. 이미 쓰는 에이전트가 그대로 브라우저를 갖게 되고, 에이전트가 따로 하나 더 생기지 않는다는 점이다. 이 구도는 Ego Lite 공식 문서의 설명과 일치한다. 에이전트는 snapshot·fill·click·wait·navigate·capture 여섯 가지 페이지 내 자바스크립트 함수를 한 번의 코드로 엮어 실행한다. 도구 호출을 한 동작마다 반복하지 않는다.

설치는 세 단계다. 먼저 깃허브에서 애플 실리콘 또는 인텔용 DMG를 받아 설치한다. 첫 실행 때 크롬 데이터를 옮길지 한 번 묻는데, 승낙하면 로그인·쿠키·확장·북마크가 그대로 넘어온다. 마지막으로 스킬을 등록하는데, Claude Code에 저장소 주소를 주고 install.md를 읽어 설치하라고 시키면 된다. 앱을 먼저 깔면 시스템의 모든 에이전트 스킬 폴더에 ego-browser가 자동 등록된다.

쓸 때는 Claude Code 안에서 /ego-browser 뒤에 원하는 일을 평문으로 적는다. 에이전트가 자기 Space에 페이지를 열고 스냅샷을 읽어 조작한 뒤 결과를 보고한다. 공식 사이트는 스냅샷 한 장이 원시 HTML 대신 수백 토큰 정도라고 밝힌다.

한계도 분명하다. macOS 전용이고 윈도우·리눅스는 로드맵에만 있다. 브라우저가 에이전트 샌드박스 바깥에서 돌기 때문에 에이전트에 브라우저 연결에 필요한 명령 실행 권한을 줘야 한다. 성공한 실행을 재사용 도구로 굳히는 경험 축적 기능은 아직 출시되지 않았다.

윈도우 e2e 테스트에서 Aside가 낫다는 판단의 배경

윈도우 e2e 안정성은 Aside 쪽이라는 의견은 두 가지 사실 위에 서 있다. 하나는 플랫폼이다. PiunikaWeb은 9월 7일 Aside의 윈도우 비공개 베타가 시작됐다고 보도했다. 8월로 예고했던 공개 출시는 아직이다. Ego Lite는 윈도우 빌드 자체가 없다. 그러니 윈도우에서 둘을 놓고 고른다는 것은 사실상 Aside만 후보에 오른다는 뜻이다.

다른 하나는 도구의 성격이다. Aside 개발자 문서는 세 가지 진입점을 용도별로 나눈다. 브라우저 검사를 개발 흐름 안에 넣으려면 CLI, 코딩 에이전트가 CI 로그나 스테이징 화면 같은 비공개 페이지의 증거를 가져와야 하면 MCP, 결정론적 검사가 필요하면 REPL이다. REPL은 Playwright처럼 page·tabs·locator·스크린샷·다운로드·자바스크립트를 준다. 동시에 에이전트가 보는 것과 같은 페이지 스냅샷과 안정된 요소 참조를 제공한다. 클릭이나 단언이 에이전트가 실제로 행동할 대상과 어긋나지 않는다는 것이 문서의 설명이다.

CLI 설치는 curl로 releases.aside.com의 설치 스크립트를 받아 실행하거나 앱의 개발자 설정에서 누르면 된다. 이후 터미널에서 `aside` 뒤에 작업을 적으면 에이전트 세션이 시작된다. 공식 블로그의 예시는 로컬 3000번 포트를 열어 가입 절차를 밟고 데스크톱·모바일 스크린샷을 찍어 짧은 QA 메모를 쓰라는 문장이다. `aside exec`에 `-m` 옵션을 붙여 모델을 지정하고, `aside mcp`로 다른 코딩 도구에 MCP 서버로 붙인다.

curl -fsSL https://releases.aside.com/install.sh | bash
aside "Open localhost:3000, run through signup, capture desktop and mobile screenshots"
aside exec -m openai-codex/gpt-5.5 "Plan this workflow"

다만 윈도우 베타의 CLI·REPL이 맥 버전과 같은 수준인지는 공개 문서로 확인되지 않는다. 방에서 나온 안정성 판단은 개인 경험이다. 베타 참여 경로도 공개 신청 양식 없이 회사 공지를 지켜봐야 하는 상태다.

Hermes에 Aside CLI와 GPT-6 Astra를 얹은 조합

방에는 Hermes, Aside CLI, Astra를 함께 쓰며 뭐든 된다고 만족한 사용자도 있었다. 이 조합은 세 층으로 읽힌다.

Hermes Agent는 Nous Research가 공개한 MIT 오픈소스 에이전트다. 세션을 넘어 기억을 유지하고 복잡한 작업 뒤 스킬을 스스로 만든다. 텔레그램·디스코드·슬랙 같은 메신저는 한 게이트웨이로 묶는다. 공식 문서는 브라우저 백엔드로 Browser Use, Browserbase, 로컬 크로미움, CDP로 붙인 자기 크롬을 나열하지만 Aside는 목록에 없다. Hermes에 터미널 도구와 MCP 로딩이 있으므로, 사용자가 `aside` 명령이나 `aside mcp`를 직접 연결한 형태로 추정된다. 공식 통합은 아니다.

Astra는 OpenAI가 9월 3일 내놓은 GPT-6 Astra다. OpenAI는 컴퓨터 사용과 브라우징을 최상위 강점으로 내세운다. 시스템 카드에는 5.6 Sol보다 프롬프트 인젝션에 강해졌다고 적었다. Hermes 문서는 OpenRouter 라우팅 설정 예시에 gpt-6-astra를 그대로 쓴다. Aside는 OpenAI 키도 받는다. 다만 OpenRouter 기준 입력 100만 토큰당 10달러, 출력 50달러라서 브라우저 작업처럼 토큰을 많이 쓰는 용도는 비용을 먼저 봐야 한다.

안정성·비용·벤치마크에서 아직 확인되지 않은 것

두 도구에 대한 바깥 반응도 갈린다. Aside를 써 본 사람들 사이에서는 빠르고 깔끔하다는 평과 함께 초기 충돌·잦은 로그아웃·기기 발열을 겪었다는 반응이 있다. 회사는 출시 뒤 성능·안정성 수정과 SuperGrok·Kimi·Ollama 같은 추가 모델 지원을 내놨다. Ego Lite 쪽에서는 맥에서 Claude Code를 이미 쓴다면 몇 분짜리 설치라는 호평과, 비공개 브라우저를 MIT 스킬로 감싼 구조에 대한 의문이 같이 나온다.

속도 수치는 둘 다 자체 측정이다. Ego Lite는 Vercel의 agent-browser와 비교해 최대 2.5배 빠르다고 README에 적었다. 사이트 헤드라인은 3.45배라 표기가 엇갈린다. Aside의 벤치마크 1위도 같은 처지다.

비용 구조는 다르다. Ego Lite는 무료이고 모델 비용은 Claude Code 요금에 그대로 얹힌다. Aside는 경쟁 제품 리뷰 페이지가 무료 500크레딧, 월 20달러 Pro, 월 200달러 Max를 전한다. 다만 공식 요금 페이지는 리뷰 매체들이 확인하지 못했다. 자기 API 키나 ChatGPT·Claude 구독을 가져올 수 있고, Aside 유료 요금제와 외부 모델 비용은 별도다.

1인 개발자라면 갈림길은 하나다. 맥에서 Claude Code로 개발하며 가끔 로그인된 페이지를 확인시키는 정도면 Ego Lite로 충분하다. 새로 배울 것도 없다. 윈도우 테스트 파이프라인이 필요하거나 에이전트가 CI 로그와 스테이징 화면을 근거로 가져와야 한다면 Aside의 CLI·MCP·REPL이 지금 유일한 선택지에 가깝다. 남는 질문은 Ego Lite 윈도우 빌드와 Aside 윈도우 공개 베타 중 무엇이 먼저 나오느냐다. 그때 방의 판단이 다시 갈릴 것이다.

자주 묻는 질문

Q

Ego Lite를 Claude Code에 연결하는 방법은?

깃허브 citrolabs/ego-lite에서 맥용 DMG를 설치하고 첫 실행 때 크롬 데이터 이전을 승낙한다. 이후 저장소를 ~/.claude/skills 아래에 클론하거나 Claude Code에 install.md를 읽고 설치하라고 시키면 ego-browser 스킬이 등록된다. 쓸 때는 /ego-browser 뒤에 작업을 평문으로 적는다.

Q

Aside 브라우저는 윈도우에서 쓸 수 있나?

2026년 9월 7일부터 비공개 베타가 시작됐고 공개 베타나 정식 출시 일정은 없다. 공식 다운로드는 아직 macOS 15 이상만 제공한다. Ego Lite는 윈도우 빌드가 없고 로드맵에만 올라 있다.

Q

Aside CLI와 REPL은 무엇이 다른가?

CLI는 터미널에서 에이전트 세션을 시작해 가입 절차나 스크린샷 같은 작업을 시킨다. REPL은 Playwright처럼 page·locator·스크린샷을 직접 다루는 결정론적 검사용이며, 에이전트가 쓰는 것과 같은 스냅샷과 요소 참조를 제공한다. MCP는 다른 코딩 도구에 서버로 붙일 때 쓴다.

Q

Hermes Agent에 Aside를 공식으로 붙일 수 있나?

Hermes 공식 문서의 브라우저 백엔드 목록에 Aside는 없다. Browser Use, 로컬 크로미움, CDP로 연결한 자기 크롬 등이 지원 대상이다. 터미널 도구나 MCP 로딩으로 aside 명령을 직접 연결하는 것은 사용자 몫이다.
