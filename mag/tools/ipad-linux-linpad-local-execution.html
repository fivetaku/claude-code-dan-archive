아이패드에서 리눅스 실행하기: LinPad는 진짜 OS인가, 화면 데모인가

M1 이상 아이패드에서 리눅스 앱을 실행하는 구조와 설치 순서, 메모리 한계를 구분해 살폈다.

2026-10-21논의 1회 정리

아이패드에 리눅스 데스크톱이 뜬 장면을 보면 두 질문이 따라온다. 화면만 흉내 낸 데모인가, 실제 프로그램을 조작할 수 있는가? M1 이상 아이패드를 지원하는 LinPad를 중심으로 실행 방식과 설치 조건, 아직 어려운 작업을 확인했다.

화면 아래에서 실제 리눅스 프로그램이 실행된다

공개된 코드와 설명에 따르면 LinPad는 Alpine Linux의 ARM64 프로그램을 아이패드 안에서 실행한다. 리눅스 프로그램의 시스템 호출을 iPadOS 쪽으로 변환하고 창은 SwiftUI로 만든 데스크톱에 표시한다. Firefox나 터미널 화면만 그려 놓은 HTML 데모와는 구조가 다르다. 다만 공개 화면 사진만으로 특정 영상의 작동 상태까지 검증할 수는 없다. (github.com)

커뮤니티에서는 조작 장면이 없는 화면을 두고 진위를 의심하는 의견이 나왔다. 타당한 검증 질문이지만 LinPad 프로젝트 자체가 가짜라는 근거는 아니다. 실제 기기에서 확인하려면 창의 모양보다 터미널 작업을 봐야 한다. 파일을 만들고 Alpine 패키지 관리자인 apk로 프로그램을 설치한 뒤 앱을 닫았다 다시 열어 결과가 남는지 확인할 수 있다. LinPad가 제공하는 파일·패키지 기능을 이용한 확인 절차다. (github.com)

리눅스 앱 실행과 아이패드 듀얼 부팅은 다르다

LinPad의 리눅스는 iPadOS를 대체하지 않는다. 프로젝트 FAQ는 별도의 리눅스 커널이나 하이퍼바이저 없이 하나의 아이패드 앱 안에서 프로그램을 실행한다고 명시한다. 아이패드를 켤 때 운영체제를 고르는 듀얼 부팅도 아니고, 하드웨어 위에 완전한 리눅스 가상 머신을 띄우는 방식도 아니다. 같은 M 계열 칩을 쓴다는 이유로 맥용 Asahi Linux 설치 절차를 아이패드에 적용할 수도 없다. Asahi Linux의 공식 지원 대상은 Apple Silicon 맥이다. (linpados.com)

LinPad에서는 지원되는 리눅스 앱을 로컬에서 열고 파일을 다룰 수 있다. 반면 리눅스 커널 기능에 의존하는 Docker는 실행할 수 없다고 프로젝트가 밝힌다. 네임스페이스와 cgroups 같은 기능이 없기 때문이다. 데스크톱 화면이 떠도 아이패드 전체가 범용 리눅스 컴퓨터로 바뀌는 것은 아니다. (linpados.com)

비교 대상으로 자주 거론되는 UTM SE는 다른 길을 택한다. UTM 공식 문서에 따르면 이 앱은 운영체제를 에뮬레이션하며 탈옥 없이 앱스토어에서 설치할 수 있다. 대신 JIT를 지원하지 않아 실행 속도가 느리고 가벼운 Alpine Linux 같은 운영체제에 적합하다. 집의 PC를 아이패드로 보는 Sunshine·Moonlight 조합은 또 다르다. 그 경우 프로그램은 아이패드가 아니라 원격 컴퓨터에서 실행된다. (docs.getutm.app)

M1 이상 아이패드에서 설치하는 순서

LinPad의 설치 안내가 제시한 조건은 M1 이상 아이패드와 iPadOS 17 이상이다. 앱스토어에서 검색해 설치하는 방식은 지원하지 않는다. 개발자 안내에 따르면 처음에는 컴퓨터와 케이블로 SideStore를 준비하고 아이패드에서 개발자 모드를 켜야 한다. 이어 LinPad 배포 페이지의 소스를 SideStore에 추가해 앱을 설치한다. 첫 실행 때 포함된 리눅스 시스템을 풀고 초기 설정을 진행한다. (linpados.com)

설치 과정에서 필요한 컴퓨터는 리눅스 작업을 대신 실행하는 서버가 아니다. 앱을 아이패드에 설치하기 위한 초기 준비물이다. LinPad 안내는 리눅스 시스템을 푼 뒤 약 2.3GB의 저장 공간이 필요하다고 적는다. 무료 Apple ID로 서명한 앱은 7일마다 갱신해야 한다. SideStore를 쓰면 아이패드에서 갱신할 수 있지만 이 유지 작업까지 포함해야 실제 사용 비용을 판단할 수 있다. (linpados.com)

속도를 높이는 ‘빠른 모드’는 별도 설정이다. LinPad 설명에 따르면 StikDebug로 JIT를 활성화하며 설정하지 않아도 느린 호환 모드로 실행된다. 개발자가 공개한 속도 비교치는 맥에서 측정한 값이지 아이패드 실측치가 아니다. 설치 직후 모든 앱이 노트북처럼 반응할 것이라고 기대해서는 안 된다. (linpados.com)

메모리 한계는 칩 이름만으로 판단할 수 없다

방 논의에서는 M1 이상이면 가능하다는 정보와 함께 메모리 부족을 걱정하는 의견도 나왔다. 지원 칩은 설치 가능성을 알려줄 뿐 실행할 작업의 크기까지 보장하지 않는다. LinPad 설치 안내는 VS Code 사용에 메모리 8GB 이상을 권장한다. 2026년 10월 3일 공개된 1.5.0 릴리스 노트는 8GB 아이패드에서도 큰 프로젝트를 열면 iPadOS가 작업을 종료할 수 있다고 경고한다. (linpados.com)

애플 개발자 문서도 앱이 쓸 수 있는 메모리 한도가 기기에 따라 다르며 한도를 넘으면 시스템이 앱을 종료한다고 설명한다. 기기의 전체 RAM과 리눅스 앱 하나가 안정적으로 쓸 수 있는 메모리를 같은 숫자로 취급하면 안 된다. M4 계열 기기라도 작업 종류, 열린 앱, iPadOS의 메모리 관리가 사용 경험에 영향을 준다. LinPad의 최신 릴리스 노트 역시 JIT와 GPU 경로를 실험적 기능으로 분류하고 페이지 로딩과 앱 실행이 실제 리눅스 컴퓨터보다 느리다고 명시한다. (developer.apple.com)

개인 개발자가 아이패드에서 파일을 고치고 작은 스크립트를 실행하는 일과 큰 프로젝트를 계속 빌드하는 일은 요구 조건이 다르다. LinPad FAQ에 따르면 iPadOS가 앱을 백그라운드에서 일시 중지할 수 있어 긴 작업도 끊길 수 있다. 아이패드 리눅스 화면의 진짜 쟁점은 화면을 띄울 수 있느냐에 그치지 않는다. 자신이 끝내려는 작업이 앱의 메모리와 실행 시간 안에 들어오느냐가 남는다. (linpados.com)

자주 묻는 질문

Q

LinPad를 설치하면 아이패드가 리눅스로 부팅되나요?

아니요. iPadOS 안의 LinPad 앱에서 리눅스 프로그램을 실행합니다. 별도 리눅스 커널로 부팅하거나 운영체제를 선택하는 방식은 아닙니다.

Q

아이패드에서 LinPad를 쓰려면 탈옥이 필요한가요?

탈옥은 필요하지 않지만 앱스토어 설치도 지원하지 않습니다. M1 이상 기기에서 SideStore 같은 도구로 앱을 설치해야 합니다.
