Fable을 코딩 도구에 붙이려면 브릿지 대신 API 키를 써라

석 달 새 수출통제로 끊기고 구독에서도 빠진 Fable, 클코단이 구상한 브릿지 대신 실제로 통하는 연결법을 짚었다

2026-08-22논의 1회 정리

클코단에서는 Fable을 Claude Code에 붙이는 브릿지를 직접 만들어보자는 이야기가 나왔다. 지금은 웹에서만 편하게 쓸 수 있으니 연결 통로를 뚫어보자는 계획이었다. 그런데 막상 만들면 사용성이 나빠져 차라리 웹을 그대로 쓰는 게 낫다는 의견도 나왔다. Fable은 지난 석 달 동안 접근 경로 자체가 여러 번 바뀐 모델이다. 방에서 나온 질문에 답하려면 그 석 달의 사정부터 봐야 한다.

석 달 새 한 번 중단되고 요금제가 바뀐 모델

Fable 5는 앤트로픽이 6월 9일 공개한 '미토스급' 최상위 모델이다. 오퍼스보다 위 등급으로 분류되고 토큰 100만 개 컨텍스트와 출력 12만8000토큰을 지원한다. 가격은 입력 100만 토큰당 10달러, 출력 100만 토큰당 50달러다. 앤트로픽 모델 중 가장 비싸다.

공개 사흘 만인 6월 12일, 미국 정부가 외국인의 접근 제한을 요구했고 앤트로픽은 접근을 전면 중단했다. 포브스와 CNN, CNBC 보도에 따르면 Fable이 알려지지 않은 소프트웨어 취약점을 스스로 찾아내고 공격 코드까지 만들어낼 수 있다는 점이 근거였다. 상용 AI 모델에 수출통제 권한이 발동된 첫 사례였다고 이들 매체는 전했다. Claude Code를 포함해 전 세계 접근이 한꺼번에 막혔다.

상무장관 하워드 러트닉이 6월 30일 통제를 풀었고 Fable은 7월 1일 Claude Code에 복귀했다. 더해커뉴스 보도로는 복귀한 모델에 해당 탈옥 기법을 99% 이상 차단하는 새 사이버보안 분류기가 붙었다. 차단된 요청은 자동으로 오퍼스 4.8로 넘어간다.

18일 동안 Fable은 사실상 존재하지 않는 모델이었다.

구독 포함 여부가 세 번 밀렸다

복귀 이후에도 접근은 안정되지 않았다. 앤트로픽 코드 저장소에는 6월 중순 "모델을 찾을 수 없다"거나 "맥스 요금제인데도 회색으로 비활성화돼 있다"는 버그 신고가 잇따라 올라왔다. Claude Code에서 Fable을 쓰려면 2.1.170 이상 버전에서 /model fable을 입력하면 된다. 다만 계정마다 접근 여부가 들쭉날쭉했다. 방에서 웹을 더 믿음직하게 느낀 배경도 여기 있다.

구독 요금제 포함 여부는 날짜가 세 번 밀렸다. 더디코더 집계에 따르면 앤트로픽은 프로 요금제의 Fable 무료 포함을 7월 7일 끝내려다 반발에 부딪혀 7월 12일로, 다시 7월 19일로 미뤘다. 실제로는 7월 20일 프로·팀 스탠더드의 구독 한도에서 Fable이 빠졌다. 대신 100달러 상당 1회성 크레딧을 지급했고 이후에는 입력 10달러·출력 50달러의 API 요금을 그대로 물렸다. 맥스·팀 프리미엄·엔터프라이즈는 남았다. 다만 Fable은 주간 한도의 절반까지만 포함된다.

브릿지를 지금 만들면 안 되는 이유

방에서 나온 계획은 웹 채팅 세션 인증을 그대로 Claude Code나 다른 도구로 흘려보내는 방식이었을 가능성이 크다. 이런 시도는 사용성부터 걸린다. 브라우저 세션을 코드 실행 환경으로 옮기는 과정에서 파일 접근이나 도구 호출 같은 에이전트 기능이 그대로 재현되지 않는 경우가 많다.

더 큰 문제는 약관이다. 앤트로픽은 지난 2월 19일 Claude Code 법률·컴플라이언스 문서에 '인증과 자격 증명 사용' 안내를 명시했다. 프리·프로·맥스 요금제의 OAuth 토큰을 Claude Code와 claude.ai 밖의 다른 제품·도구·서비스에서 쓰면 약관 위반이라는 내용이다. 다만 올해 서버 쪽 제한이 강화되면서 일부 서드파티 도구에서 접속 거부가 보고됐다.

Claude Code 안에서 구독 계정으로 Fable을 쓰는 것 자체는 문제가 없다. 같은 계정 인증을 다른 도구로 몰래 흘려보내는 시도가 약관 위반이다. 방에서 '사용성이 불편하다'고 표현한 그 브릿지는, 만들었다면 계정이 막힐 위험까지 함께 안았을 셈이다.

Codex에 Fable을 실제로 끼워 넣는 법

Codex에서 Fable을 작업용으로 쓰고 싶다는 수요에는 이미 답이 나와 있다.

설치 순서는 이렇다. 비용은 요청 규모와 API 사용량에 따라 달라진다.

오픈AI도 최근 Codex CLI·앱·SDK 전반에 걸쳐 model_provider 설정 블록을 공식 문서화했다. base_url과 env_key 등을 설정하면 OpenAI 호환 Responses API를 제공하는 모델 서버를 Codex에 등록할 수 있다. 호환 어댑터가 있다면 설정 파일로 연결할 수 있다.

커서는 고민이 없고, 값은 두 배다

커서에서는 이런 고민 자체가 없다. 프라이버시 모드를 끄고 쓰는 개인·팀 계정이라면 Fable이 기본으로 켜져 있고 별도 신청 없이 모든 에이전트 도구에 접근한다. 가격은 앤트로픽 API와 같은 입력 10달러·출력 50달러로, 커서 자체 사용량에서 그만큼 빠르게 깎여나간다. 커서 측은 CursorBench 기준으로 Fable이 모든 모델 중 1위지만 작업당 비용도 가장 비싸다고 밝혔다. 방에서 커서 구독 가치를 Fable 접근성과 연결 지은 배경이 여기 있다.

다만 성능 비교에서는 반대 결과도 나온다. 앤트로픽이 공개한 Frontier-Bench v0.1 결과에 따르면 오퍼스 5는 에이전트형 터미널 코딩 벤치마크에서 43.3%로 Fable의 33.7%를 앞선다. 가격은 입력 5달러·출력 25달러로 절반이다. 실사용자 사이에서도 후기는 엇갈린다. Fable을 계속 쓰다 오퍼스로 돌아갔는데 차이를 거의 못 느꼈다는 이야기가 있는가 하면, 매 단계를 직접 지시하던 방식에서 통째로 맡기는 방식으로 작업이 바뀌었다는 정반대 후기도 나왔다. 짧게 주어지는 무료 포함 기간은 설계나 어려운 문제에만 쓰고 나머지 구현은 값싼 모델에 맡기라는 조언이 나오는 이유다.

방에서 나온 질문은 브릿지를 만들 것인가였다. Claude Code는 이미 공식으로 Fable을 지원한다. Codex에서 Fable을 쓰려면 API 키와 호환 어댑터나 MCP 연동이 필요하다. 커서는 처음부터 켜져 있다. 손수 브릿지를 짜는 대신 어떤 작업에 어떤 모델의 비용을 쓸지 고르는 쪽이 남은 선택지다.

자주 묻는 질문

Q

Fable 5는 Claude Code에서 어떻게 켜나요?

Claude Code 2.1.170 이상 버전에서 /model fable 또는 /model claude-fable-5를 입력하면 된다. API 요금제나 맥스·팀 프리미엄·엔터프라이즈 종량제 계정이면 바로 선택할 수 있다.

Q

Fable 5를 OpenAI Codex에서 쓸 수 있나요?

공식 통합은 아니지만 fable-mcp 같은 MCP 서버를 앤트로픽 API 키로 연결하면 Codex가 구현을, Fable이 설계·검토를 맡는 구조로 쓸 수 있다. 구독 계정 인증을 다른 도구에 재사용하는 방식은 앤트로픽 약관 위반이다.

Q

Fable 5가 한동안 왜 사라졌었나요?

2026년 6월 12일 미국 상무부가 수출관리규정을 근거로 접근을 전면 중단시켰다가, 6월 30일 통제를 풀어 7월 1일 Claude Code에 복귀했다. 복귀한 모델에는 문제가 된 탈옥 기법을 차단하는 새 안전장치가 추가됐다.
