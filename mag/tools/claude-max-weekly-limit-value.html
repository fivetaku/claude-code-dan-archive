Claude Max 5x·20x, 주간 한도까지 따지면 가성비가 달라진다

다섯 시간 사용량과 주간 총량은 같은 배율이 아니다. Claude Code 이용자가 플랜을 고르는 기준을 다시 계산했다.

2026-09-24논의 1회 정리

Claude Max 5x와 20x는 이름만 보면 계산이 간단하다. 하지만 Claude Code를 오래 돌리는 이용자는 다섯 시간 한도보다 주간 한도에서 먼저 멈추기도 한다. 그렇다면 월 100달러와 200달러의 차이는 실제 작업량에도 그대로 반영될까?

5x와 20x는 주간 총량을 뜻하지 않는다

Anthropic은 Max 5x를 Pro의 다섯 배, Max 20x를 스무 배 사용량으로 설명한다. 여기서 배율은 5시간 단위 세션 한도에 적용된다. 두 플랜 모두 별도의 주간 한도를 두지만 주간 토큰 수나 플랜 간 배율은 공개하지 않는다. (support.claude.com)

세션 한도는 연속 작업에서 발생하는 짧은 병목을 줄인다. 주간 한도는 계정별로 정해진 시점에 초기화되는 전체 작업량에 가까운 제약이다. Max 20x가 Max 5x보다 세션 용량은 네 배지만 주간 용량도 네 배라고 단정할 공식 근거는 없다.

이 차이가 상위 플랜의 체감 가치를 흔든다. 긴 세션을 자주 끝내지 못했던 사람은 20x의 효과를 바로 느낀다. 이미 세션 한도보다 주간 한도에 자주 걸린다면 가격이 두 배로 올라도 작업 가능 시간이 그만큼 늘지 않을 수 있다.

써본 사람들 사이에서도 20x는 세션 중단을 크게 줄였지만 주간 잔량은 예상보다 빨리 소진됐다는 반응이 나온다. 반대로 여러 저장소를 오가며 하루 종일 작업하는 이용자는 5x로 낮추면 며칠 안에 막힌다고 말한다. 작업 방식에 따라 같은 플랜의 평가가 갈리는 이유다.

‘Pro의 6.25배’는 Max 5x가 아니라 Team Premium이다

플랜 비교에서 자주 섞이는 숫자가 6.25배다. 공식 도움말에 따르면 Team Standard 좌석은 Pro의 1.25배, Team Premium은 6.25배의 세션 사용량을 제공한다. Max 5x의 공식 배율은 그대로 다섯 배다. (support.claude.com)

미국 기준 Team은 최소 두 좌석이 필요하다. Standard는 월 결제 시 좌석당 25달러, Premium은 125달러다. Team의 목적도 개인 사용량 확대에만 있지 않다. 중앙 결제와 관리자 제어, SSO, 조직 데이터 정책이 가격에 포함된다. (claude.com)

1인 개발자에게 Team Premium이 Max 5x보다 무조건 유리하다고 말하기 어려운 이유다. 최소 좌석 비용을 부담해야 하며 Team에도 공개되지 않은 주간 한도가 있다. 소규모 팀이라면 사용량보다 계정 관리와 조직용 보안이 필요한지 먼저 구분해야 한다.

Claude Code는 대화 길이와 모델에 따라 한도를 다르게 태운다

Claude의 사용량은 메시지 개수로 계산되지 않는다. 현재 대화의 길이, 읽은 파일, 첨부 자료, 도구 호출, 모델과 작업 강도가 함께 영향을 준다. 웹과 데스크톱, 모바일, 대화형 Claude Code도 같은 구독 사용량 풀을 공유한다. (claude.com)

특히 긴 Claude Code 세션은 이전 대화와 프로젝트 문맥을 매 요청마다 다시 다룬다. Anthropic은 새 작업을 시작할 때 /clear를 쓰고 이어갈 문맥만 필요하면 /compact를 권한다. 일반 구현에는 Sonnet, 복잡한 설계와 디버깅에는 Opus를 쓰는 방식도 제시한다. Opus는 더 많은 할당량을 소비한다. (support.claude.com)

플랜을 비교하려면 느낌보다 같은 조건의 기록이 필요하다. Settings의 Usage 화면에서 작업 전후 세션·주간 비율을 적고 모델과 저장소를 고정한다. 새 작업마다 /clear를 실행한 뒤 구현, 테스트, 리팩터링처럼 작업 유형도 함께 남긴다.

적어도 한 주 동안 이 기록을 모으면 병목이 드러난다. 다섯 시간 막대만 자주 차면 상위 Max가 맞다. 세션 잔량은 충분한데 주간 막대가 먼저 끝난다면 20x 업그레이드의 효과를 사전에 계산할 공식 수치는 없다.

월 200달러라면 Max 20x와 Max 5x 두 계정은 같지 않다

Max 5x 두 개가 Max 20x 하나보다 낫다는 계산도 등장한다. 비용은 모두 월 200달러지만 Anthropic은 복수 구독의 용량을 합산해 보장하지 않는다. 계정마다 기록과 프로젝트, 로그인 상태, 주간 초기화 시간이 갈리므로 하나의 10x 플랜처럼 작동하지도 않는다.

Max 20x는 한 계정에서 Pro 대비 20배의 세션 한도를 제공한다. 병렬 에이전트와 긴 리팩터링을 돌릴 때 관리가 단순하다. 두 계정 방식은 한쪽 한도가 끝나도 다른 계정을 쓸 수 있지만 문맥을 옮기고 인증을 관리하는 비용이 생긴다.

주간 배율이 공개되지 않은 상태에서는 어느 쪽이 더 많은 토큰을 준다고 확정할 수 없다. 두 계정 전략은 공식 가격표의 우위를 이용하는 방법이 아니라 불투명한 주간 제한을 운영으로 우회하려는 선택에 가깝다.

구독 한도를 넘는 작업은 사용 크레딧과 API로 분리할 수 있다

현재 Pro와 Max 이용자는 포함 한도를 다 쓰면 사용 크레딧을 켤 수 있다. 이후 작업은 표준 API 요금에 따라 과금된다. 갑작스러운 배포나 장애 대응 때문에 한 주 전체를 상위 플랜으로 바꾸는 대신 초과분만 결제할 수 있다. (support.claude.com)

Agent SDK와 claude -p는 현재도 구독 사용 한도에서 차감된다. (support.claude.com)

자동화가 많은 1인 사업자는 여기서 계산이 달라진다. 터미널에서 사람이 계속 대화한다면 세션과 주간 한도가 중요하다. 반복 실행을 Agent SDK로 옮겨도 현재는 구독 사용 한도에 포함된다.

Claude Max의 가성비를 가르는 숫자는 플랜 이름의 5와 20이 아니다. 실제 질문은 작업이 다섯 시간 창에서 멈추는지, 주간 총량에서 멈추는지다. Anthropic이 주간 용량을 수치로 공개하지 않는 한 Usage 기록이 가격표보다 더 정확한 구매 기준으로 남는다.

자주 묻는 질문

Q

Claude Max 20x는 Max 5x보다 주간 사용량도 네 배인가요?

공식 문서는 네 배 차이를 보장하지 않습니다. 20x와 5x는 Pro 대비 5시간 세션 한도의 배율이며, 별도로 적용되는 주간 한도의 정확한 수치는 공개되지 않았습니다.

Q

Claude Max 5x와 Team Premium 중 어느 플랜이 더 많은가요?

세션 기준으로 Max 5x는 Pro의 5배, Team Premium은 6.25배입니다. Team은 최소 두 좌석과 조직 관리 기능을 전제로 하므로 개인 이용자는 총비용과 필요한 기능을 함께 비교해야 합니다.

Q

Claude Code 사용량을 줄이는 가장 실용적인 방법은 무엇인가요?

새 작업마다 /clear를 실행하고 긴 대화는 /compact로 줄이는 방법이 효과적입니다. 일상적인 구현은 Sonnet으로 처리하고, Opus는 어려운 설계나 디버깅에 제한해 쓰는 편이 낫습니다.
