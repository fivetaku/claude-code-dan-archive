Manus Flex에 내 API 키를 연결하면 Manus 크레딧은 얼마나 줄어들까

Claude Max의 월간 API 크레딧을 Manus에 쓸 수 있는지, 모델 요금과 도구 사용료가 어디서 갈리는지 살펴봤다.

2026-10-17논의 1회 정리

Manus Flex에 외부 API 키를 넣으면 에이전트 작업을 Manus 크레딧 없이 돌릴 수 있을까? 특히 Claude Max의 월간 API 크레딧을 연결하려는 사람에게 중요한 질문이다. 모델 비용과 Manus의 실행 비용을 나눠 보면 돈이 어디서 빠져나가는지 드러난다.

Flex가 바꾸는 것은 모델 비용의 결제처다

Manus는 2026년 9월 29일 Flex를 발표했다. 지원하는 추론 제공업체의 API 키를 연결하고, 사용할 모델과 추론 강도를 설정하는 방식이다. 연결한 뒤에도 기존 프로젝트와 자동화, 에이전트 작업 환경을 이용할 수 있다고 Manus는 설명한다. 모델 추론료는 연결한 제공업체가 청구한다. (manus.im)

방 논의에서는 이 기능을 Manus 크레딧을 쓰지 않는 방법으로 받아들이는 의견이 있었다. 하지만 공식 설명은 범위를 더 좁힌다. 모델 추론 외의 서비스와 실행 인프라는 여전히 Manus 크레딧을 쓴다. 외부 키를 넣는다고 Manus의 도구 사용료까지 외부 API 잔액으로 옮겨가지는 않는다. (manus.im)

설정 순서도 복잡하지 않다. 먼저 Manus Flex에서 지원하는 제공업체를 고른다. 해당 업체에서 발급받은 API 키를 연결한 뒤 기본 모델과 추론 강도를 정한다. Manus가 최초 파트너로 밝힌 곳은 OpenRouter, Fireworks, Modal이다. 다만 발표문만으로 모든 제공업체와 모델의 현재 지원 여부를 확정할 수는 없다. 연결 화면에서 선택 가능한 항목을 확인해야 한다. (manus.im)

브라우저와 영상 작업에는 다른 비용이 남는다

방에서는 영상 제작이나 컴퓨터·브라우저 사용도 외부 API 크레딧으로 실행할 수 있다는 기대가 나왔다. 작업에 Flex 모델을 쓸 수 있다는 말과 작업 전체를 외부 크레딧만으로 결제한다는 말은 다르다.

Manus의 크레딧 안내에 따르면 사용량에는 LLM 토큰뿐 아니라 가상 머신과 외부 서비스 이용도 반영된다. 가상 머신은 브라우저 자동화, 파일 작업, 코드 실행에 쓰인다. 브라우저를 열어 자료를 찾고 결과물을 만드는 작업이라면 모델 호출 밖의 실행 비용도 따로 봐야 한다. (manus.im)

영상도 한 번의 텍스트 응답으로 끝나지 않는다. Manus 2.0의 Video Editor는 클립·이미지·오디오를 타임라인에서 다루고, 사용자가 다시 편집할 수 있게 한다. Flex 발표는 이런 제작 과정을 통째로 외부 API 잔액으로 결제한다고 약속하지 않는다. 영상 작업 전에는 모델 제공업체의 사용량과 Manus 크레딧 변동을 각각 확인해야 한다. (manus.im)

예를 들어 짧은 제품 소개 영상을 의뢰한다면 요청 문장만 기록하지 말고 생성과 수정에 든 사용량을 따로 적어둘 수 있다. 같은 길이의 영상이라도 자료 탐색, 소재 생성, 수정 횟수가 달라지면 작업량도 달라진다. 가격 비교의 단위는 ‘영상 한 편’보다 실제로 수행한 단계에 가까워야 한다.

Claude Max의 200달러는 어떤 잔액인가

2026년 10월 7일부터 Claude Max와 Team에는 월간 Claude API 크레딧이 포함됐다. Anthropic의 도움말에 따르면 Max 5x는 월 100달러, Max 20x는 월 200달러다. 이 크레딧은 Claude 앱이나 대화형 Claude Code의 이용 한도가 아니다. Claude Console 조직에 지급되는 별도의 API 잔액이며 사용하지 않으면 해당 결제 주기가 끝날 때 소멸한다. (support.claude.com)

크레딧을 받으려면 자격을 갖춘 구독자가 Claude의 결제 설정에서 Console 조직을 연결해야 한다. Anthropic은 신규 구독자가 해당 플랜을 7일간 유지한 뒤 신청할 수 있다고 안내한다. 연결된 조직에서 API 키를 발급받더라도 그 키를 Manus Flex에 직접 넣을 수 있는지는 Manus의 지원 제공업체 목록으로 확인해야 한다. (support.claude.com)

여기서 우회 연결을 혼동하기 쉽다. OpenRouter에서 Claude 모델을 선택할 수 있다는 사실만으로 Anthropic이 Claude Console 조직에 지급한 크레딧이 OpenRouter 청구액에 적용되는 것은 아니다. 두 업체의 결제 계정은 구분된다. 따라서 ‘Max 20x에 200달러가 있으니 OpenRouter 키를 연결하면 그 잔액부터 쓰인다’고 가정해서는 안 된다. (support.claude.com)

이미 쓰는 개발 도구가 있다면 무엇을 비교할까

방에서는 Claude Code나 Codex로 작업하는 사람에게 Manus 구독의 추가 가치가 작다는 의견도 나왔다. 코드 수정과 테스트가 중심인 사람이라면 타당한 비교 출발점이다. Codex는 로컬 개발 작업과 위임한 클라우드 코딩 작업을 제공한다. Manus가 내세우는 범위는 프로젝트 안에서 웹 조사, 제작 도구, 자동화와 실행 환경을 잇는 데까지 넓다. 두 제품을 같은 프롬프트의 답변 품질만으로 비교하면 작업 범위 차이가 빠진다. (help.openai.com)

가령 출장 자료를 바탕으로 현장에서 열어볼 일정 앱을 만들거나 로컬 자료를 다루는 업무 앱을 계속 수정하는 경우를 생각해 보자. 영상 참고 자료에는 그런 결과물을 사용했다는 경험이 담겨 있다. 다만 제작 시간과 완성도는 독립적으로 확인된 성능 지표가 아니다. 비교할 때는 같은 입력 자료와 요구 기능을 정하고, 결과물을 고치는 데 든 단계까지 살펴야 한다.

Manus에는 로컬 폴더를 승인해 작업하는 My Computer와 승인한 브라우저 세션에서 작동하는 Browser Operator가 있다. 전자는 폴더를 지정한 뒤 명령 실행을 승인하는 흐름이다. 후자는 브라우저 작업을 허용하고 진행 상황을 지켜볼 수 있다. 고객 자료나 로그인된 서비스가 얽힌 작업에서는 비용만큼 접근 범위도 선택 기준이 된다. (manus.im)

구매 판단은 두 잔액을 함께 볼 때 가능하다

Manus의 공식 요금 안내에는 무료 플랜과 월 20달러부터 시작하는 Pro 플랜이 나뉘어 있다. 무료 플랜의 에이전트 모델 접근 범위도 Pro와 다르다. 외부 키가 있다는 이유만으로 구독 조건이나 기능 제한이 사라진다고 볼 근거는 없다. (help.manus.im)

개인 개발자나 소규모 팀이라면 반복할 작업 하나를 정해 비용을 비교할 수 있다. 같은 입력으로 한 번은 기존 도구에서, 한 번은 Flex에서 실행하고 결과물과 수정 횟수를 기록하는 방식이다. Flex 쪽에서는 제공업체의 API 사용액과 Manus 크레딧 감소량을 별도 항목으로 남겨야 한다. 외부 사용 후기에는 모델을 바꿔 쓰기 편해졌다는 반응과 크레딧 이중 사용을 묻는 반응이 함께 나온다. 어느 쪽도 모든 작업의 실제 비용을 대신 계산해 주지는 않는다.

Flex의 매력은 Manus의 작업 환경을 유지하면서 모델 결제처를 선택할 수 있다는 데 있다. 반면 브라우저 조작과 제작 도구까지 공짜로 만드는 기능은 아니다. 이미 API 잔액이 있는 사람에게 남는 질문은 하나다. 자주 하는 작업에서 Manus의 실행 환경이 추가 크레딧만큼의 수고를 덜어주는가?

자주 묻는 질문

Q

Manus Flex에 API 키를 넣으면 Manus 크레딧을 전혀 쓰지 않나요?

아닙니다. 모델 추론은 연결한 제공업체가 청구하지만, Manus의 다른 서비스와 실행 인프라는 여전히 Manus 크레딧을 사용할 수 있습니다.

Q

Claude Max 20x의 월 200달러 API 크레딧을 Manus Flex에서 쓸 수 있나요?

Claude Max 20x에는 Claude Console 조직에 지급되는 월 200달러 API 크레딧이 있습니다. 이를 Flex에서 쓰려면 해당 조직의 API 키를 Manus가 직접 지원해야 하므로, Flex의 제공업체 목록과 연결 방식을 확인해야 합니다.

Q

OpenRouter에서 Claude 모델을 고르면 Claude Max API 크레딧이 차감되나요?

그렇게 가정하면 안 됩니다. Claude Console에 지급된 크레딧과 OpenRouter의 청구 계정은 별개이므로, 연결하려는 키의 발급처와 실제 청구처를 확인해야 합니다.
