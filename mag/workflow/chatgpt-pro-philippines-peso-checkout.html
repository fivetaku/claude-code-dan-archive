챗GPT Pro 20x 필리핀 페소 결제 '필쫀쿠', 22만 원에 되는 이유와 걸리는 것

8,919페소는 필리핀 정가에서 부가세를 뺀 숫자다. 콘솔 스크립트 한 번으로 한국 정가 29만9천 원이 22만 원대가 되지만, 카드 거절과 약관 위반 위험이 따라온다.

2026-09-06논의 3회 정리

ChatGPT Pro 20x의 한국 앱스토어 정가는 월 299,000원이다. 그런데 같은 플랜을 8,919페소, 요즘 환율로 22만 원 안팎에 결제했다는 보고가 클코단에서 9월 초까지 이어졌다. 방에서는 이 방법을 '필쫀쿠'라고 부른다. 이전에 돌던 카카오 프로모션 은어 '카쫀쿠'를 필리핀으로 바꿔 단 말이다. 이 기사는 세 가지에 답한다. 그 숫자가 어디서 나오는지, 실제로 어떤 순서로 하는지, 그리고 무엇을 걸고 하는 일인지다.

9,990페소를 1.12로 나누면 약 8,919.64페소다

OpenAI는 나라별로 현지통화 정가를 따로 정한다. 가격 추적 사이트 OpenTheRank가 2026년 9월 기준으로 확인한 필리핀 앱스토어 정가는 Plus 999페소, Pro 20x 9,990페소다. 두 값 모두 12% 부가세를 포함한 금액이다. 같은 사이트는 이 값이 환율 환산이 아니라 OpenAI가 일부러 낮게 잡은 현지 티어라고 설명한다. 미국 정가 200달러와 견주면 달러 환산으로 159달러 정도다.

9,990페소를 1.12로 나누면 8,919.64페소가 나온다. 방에서 결제 성공자가 본 금액 8,919.64페소와 소수점까지 일치한다. 즉 보고된 결제액은 필리핀 앱스토어 가격에서 12% 부가세를 빼고 계산한 값과 같다.

필리핀은 2025년 6월 2일부터 해외 디지털 서비스에 12% 부가세를 매기는 법을 시행했다. 현지 매체 Wazzup Pilipinas 보도에 따르면 OpenAI는 2025년 8월 1일부터 필리핀 이용자에게 이 세금을 청구하기 시작했다. 원글이 권하는 방식은 결제 주소를 판매세가 없는 미국 주로 넣어 세금 항목을 비우는 것이다. 킵링어 정리로는 2026년 현재 주 판매세가 없는 곳은 알래스카·델라웨어·몬태나·뉴햄프셔·오리건 다섯 곳이다.

방에서는 '델라웨어 주소를 넣고 사업자 체크를 해야 하느냐'는 질문도 나왔다. 필리핀 사업자 거래에서는 판매자가 부가세를 청구하는 대신 구매자가 직접 신고·납부하는 방식이 적용된다. 다만 무세금 주 주소를 넣은 결제에는 필리핀 부가세 항목 자체가 없어 사업자 체크와 만나지 않는다. 방에서 이 질문에 확답은 나오지 않았다.

환율은 매달 다르다. 2026년 9월 1일 기준 1페소가 약 22원이라 8,919페소는 19만6천 원 정도다. 여기에 카드 해외결제 수수료가 얹힌다. 방에서는 실제 청구액이 215,184원이었다는 보고도 나왔다.

실행 순서는 로그인, 콘솔, 결제 페이지 세 단계다

준비물은 둘이다. 해외 결제가 되는 카드, 그리고 현재 유료 구독이 없는 ChatGPT 계정이다. 한국 계정이어도 되고 VPN은 기본적으로 필요 없다.

순서는 이렇다. chatgpt.com에 평소처럼 로그인한다. F12로 개발자도구를 열어 Console 탭에 스크립트를 붙여 넣고 실행한다. 크롬이 붙여넣기를 막으면 콘솔에 allow pasting을 입력한 뒤 다시 붙여 넣는다. 잠시 뒤 결제 페이지로 넘어가면 카드 정보와 결제 주소를 넣는다.

아래가 그 스크립트다. 원본 대신 카드 거절 대응판을 실었다. country는 기본 KR이고, 결제 국가 불일치 오류가 나면 PH로 바꿔 다시 실행한다.

(async function () {
    const LOCK_KEY = "__chatgptCheckoutCreating";
    if (window[LOCK_KEY]) {
        alert("체크아웃 생성이 이미 진행 중입니다.");
        return;
    }
    window[LOCK_KEY] = true;
    async function fetchJson(url, options = {}, timeoutMs = 15000) {
        const controller = new AbortController();
        const timer = setTimeout(() => controller.abort(), timeoutMs);
        try {
            const response = await fetch(url, {
                credentials: "include",
                cache: "no-store",
                ...options,
                signal: controller.signal
            });
            const raw = await response.text();
            let data = {};
            if (raw) {
                try {
                    data = JSON.parse(raw);
                } catch {
                    data = { message: raw.slice(0, 500) };
                }
            }
            if (!response.ok) {
                const detail = data?.detail ?? data?.error?.message ?? data?.message ?? raw.slice(0, 300) ?? response.statusText;
                const message = typeof detail === "string" ? detail : JSON.stringify(detail);
                throw new Error(`${response.status} ${response.statusText}: ${message}`);
            }
            return data;
        } finally {
            clearTimeout(timer);
        }
    }
    try {
        if (location.origin !== "https://chatgpt.com") {
            throw new Error("chatgpt.com에 로그인한 상태에서 실행해 주세요.");
        }
        const session = await fetchJson("/api/auth/session");
        const accessToken = session?.accessToken;
        if (typeof accessToken !== "string" || !accessToken) {
            throw new Error("로그인 세션을 찾지 못했습니다. 다시 로그인해 주세요.");
        }
        const payload = {
            billing_details: {
                country: "KR", // 필요에 따라 "PH"로 변경
                currency: "PHP"
            },
            checkout_ui_mode: "hosted",
            entry_point: "all_plans_pricing_modal",
            plan_name: "chatgptpro"
        };
        const checkout = await fetchJson(
            "/backend-api/payments/checkout",
            {
                method: "POST",
                headers: {
                    Authorization: `Bearer ${accessToken}`,
                    "Content-Type": "application/json",
                    Accept: "application/json"
                },
                body: JSON.stringify(payload)
            }
        );
        const checkoutId = checkout?.checkout_session_id;
        if (typeof checkoutId !== "string" || !/^[A-Za-z0-9_-]+$/.test(checkoutId)) {
            throw new Error(`유효한 체크아웃 세션이 반환되지 않았습니다: ${JSON.stringify(checkout)}`);
        }
        const checkoutUrl = new URL(
            `/checkout/openai_llc/${encodeURIComponent(checkoutId)}`,
            location.origin
        );
        location.assign(checkoutUrl.href);
    } catch (error) {
        const message = error?.name === "AbortError"
            ? "요청 시간이 초과되었습니다."
            : error instanceof Error
                ? error.message
                : String(error);
        alert(`체크아웃 생성 실패:\n${message}`);
    } finally {
        window[LOCK_KEY] = false;
    }
})();

스크립트가 하는 일은 단순하다. 먼저 /api/auth/session에서 로그인 토큰을 읽는다. 그 토큰으로 결제 백엔드(/backend-api/payments/checkout)에 플랜 chatgptpro, 통화 PHP를 지정한 체크아웃 요청을 보낸다. 응답으로 받은 체크아웃 세션 ID로 결제 페이지 주소를 만들어 이동한다. 대응판은 여기에 중복 실행 잠금, 15초 타임아웃, chatgpt.com 도메인 확인, 오류 메시지 표시를 더했다.

결제 주소 칸에는 위에서 말한 무세금 주 주소를 넣는다. 다른 지역 주소를 넣으면 세금이 붙어 9,990페소 근처로 올라간다는 사례가 원글 댓글에도 있다.

Pro 5x도 같은 방식이 통한다. 원글은 이 플랜을 유출 당시 이름인 Pro Lite로 적고 5,794페소, 약 146,000원이라고 썼다. OpenAI가 2026년 4월 9일 100달러 플랜으로 정식 출시한 그 티어다. 한국 앱스토어 정가가 159,000원이라 차액이 만 원대에 그친다. 원글도 20x가 아니면 이득이 크지 않다고 적었다.

카드 거절과 국가 불일치 오류도 보고됐다

방에서 가장 많이 막힌 지점은 결제 단계였다. 카드가 거절되거나 'Billing country must match request country'라는 오류가 떴다는 사람이 여럿이었다.

원본 스크립트는 결제 국가를 PH로 보낸다. 한국에서 발급한 카드로 결제하면 카드 발급국과 요청 국가가 어긋나 이 오류가 난다는 게 대응판을 올린 글의 설명이다. 대응판은 country를 KR로 두고 currency만 PHP로 넘겨 불일치를 피한다. 그래도 막히면 country를 PH로 되돌리고 필리핀 VPN을 켜는 게 다음 수순이다.

그래도 안 되는 경우가 있었다. 삼성카드로 성공했다는 사례가 있는 한편, 가진 카드사를 다 돌려도 실패했다는 사람도 있었다. 국가 불일치 경고가 계속 뜨던 사람은 크롬에서 필리핀 IP VPN을 켜고 시도해 8,919.64페소 결제에 성공했다.

카드사 쪽 사정도 있다. 코리아타임스의 2026년 6월 12일 보도에 따르면 그달 들어 국내에서 처리된 ChatGPT Pro 결제 1,368건 중 858건이 도난 카드 정보를 쓴 부정 결제로 의심됐다. 금융감독원이 카드사에 부정 결제 감시 강화를 요청했다. OpenAI는 자사가 무단 청구한 게 아니라 제3자가 훔친 카드 정보를 쓴 사건이며 해당 결제수단을 비활성화했다고 밝혔다. 이 사건 뒤 카드사가 OpenAI 결제 심사를 어떻게 바꿨는지는 공개된 자료가 없다. 다만 소액도 아닌 해외 결제가 카드사마다 다르게 승인되는 배경으로는 짚어둘 만하다.

델라웨어 주소를 넣었는데도 20만 원 안팎이 찍혔다는 사람은 카드 수수료 차이로 봤다. 소비자가 만드는 신문 조사에 따르면 해외결제 수수료는 비자·마스터 브랜드 수수료 1~1.1%에 카드사 해외서비스 수수료 0.18~0.3%가 더해진다. 트래블로그나 삼성 iD GLOBAL처럼 이 수수료를 면제하는 카드도 있다. 같은 8,919페소라도 카드에 따라 2~3천 원이 갈린다.

기존 구독자는 만료 뒤 같은 계정으로 갈아탈 수 있다

Pro 구독이 살아 있는 계정에서는 이 방법이 통하지 않는다. OpenAI 헬프센터의 다중 통화 청구 문서가 이유를 설명한다. 이미 구독 중이면 기존 통화로 계속 청구된다. 다른 통화로 바꾸려면 구독을 해지한 뒤 현재 결제 기간이 끝나고 나서 다시 구독해야 한다.

방의 사례도 여기에 맞는다. 만료일에 해지를 걸어두고 만료 직후 같은 계정에서 스크립트를 실행해 페소 결제에 성공했다. 새 계정을 파야 한다는 말이 돌았지만 그럴 필요는 없다. 가입 자체를 필리핀 VPN으로 새로 한 사람도 있었지만 그건 선택이지 조건이 아니다.

갈아타기 전에 코덱스 뱅크드 리셋권을 다 써야 하느냐는 걱정도 나왔다. 뱅크드 리셋은 코덱스 사용량 한도를 한 번 초기화하는 권리를 계정에 저장해 두는 것으로, OpenAI 헬프센터에 따르면 안내된 유효기간이 지나면 사라진다. 9월 초에는 Plus·Pro·Business 이용자를 대상으로 리셋권 지급이 발표됐다. 방에서는 구독이 만료돼도 리셋권이 그대로 남아 있었다는 확인이 나왔다. 공식 문서는 구독 해지 뒤 리셋권이 어떻게 되는지 따로 적지 않고 있다. 이 부분은 방의 실측에 기대는 이야기다.

페소로 결제한 Pro 20x가 원화 결제와 사용량이 다르냐는 의문도 있었다. 플랜 이름이 같으면 한도가 같다는 게 OpenAI의 코덱스 요금 안내다. 방에서 다르다는 보고는 없었다. 참고로 9to5Mac 보도에 따르면 Plus는 8월 25일부터 5시간 한도가 다시 켜졌지만 Pro 두 티어는 당분간 5시간 한도 없이 주간 한도만 적용된다.

아끼는 돈은 월 7만 원대, 거는 것은 계정이다

원화 정가 299,000원과 22만 원대 청구액의 차이는 한 달에 7만 원 남짓, 1년이면 90만 원 가까이 된다. 개인 개발자가 코덱스를 하루 종일 돌리는 용도로 Pro 20x를 쓴다면 작은 돈이 아니다.

대가는 약관에 적혀 있다. OpenAI 이용약관은 계정 등록과 결제에 정확하고 완전한 정보를 제공하라고 요구한다. 필요한 경우 세금을 부과한다고 명시한다. 살지도 않는 델라웨어 주소를 넣는 행위는 이 조항과 정면으로 부딪친다. 약관은 또 서비스 제한을 우회하는 행위를 금지하며 위반 시 계정을 정지하거나 삭제할 수 있다고 적는다. 필리핀과 한국이 모두 지원 국가라 접속 자체는 문제가 아니지만 결제 국가를 꾸미는 건 별개 문제다.

방의 온도는 둘로 갈렸다. 기기 단위로 막히면 어쩌냐, 정지되면 피눈물이라는 걱정과, 돈 낸 사용자를 굳이 내치겠느냐는 낙관이 같은 날 오갔다. 원글도 본인 책임을 못 박았고 정지가 걱정되면 정가로 내라고 썼다.

써본 사람들 사이에서는 지금까지 구독이 취소된 사례는 있어도 계정이 통째로 막힌 경우는 드물다는 분위기다. 원글 작성자는 두 달 가까이 갱신 결제까지 문제없이 이어졌다고 밝혔다. 반대로 결제 안내 업체들은 OpenAI가 카드 발급국과 기기 정보를 대조하는 부정 결제 감지를 강화하고 있어 지역 우회가 갈수록 어렵다고 경고한다. 두 이야기 모두 개별 경험이다. OpenAI가 이 방식을 어떻게 다루는지 공식적으로 밝힌 적은 없다.

이력도 그걸 말해 준다. 6월 9일에 막혔다는 제보가 올라왔다가 10일에 다시 된다고 갱신됐다. 9월 초에도 성공과 실패가 섞여 보고됐다. 오늘 되는 방법이 다음 달 갱신 때도 된다는 보장은 어디에도 없다. 갱신이 실패하면 결제를 다시 확인해야 하는 계정이 하나 남는다.

Q

필쫀쿠가 뭔가요?

ChatGPT Pro 20x를 필리핀 페소 가격으로 결제하는 방법을 부르는 커뮤니티 은어입니다. 필리핀 정가 9,990페소에서 12% 부가세를 뺀 8,919페소, 약 22만 원에 결제되며 한국 웹 정가 299,000원보다 7만 원 이상 쌉니다.

Q

필리핀 페소 결제에 VPN이 필요한가요?

기본 절차에는 필요 없습니다. 한국 계정으로 로그인한 뒤 개발자도구 콘솔에서 스크립트를 실행하면 페소 결제 페이지가 열립니다. 다만 국가 불일치 오류가 계속 뜨는 경우 필리핀 IP VPN을 켜고 성공한 사례가 있습니다.

Q

카드가 거절되거나 Billing country must match request country 오류가 나면 어떻게 하나요?

스크립트가 보내는 청구 국가를 카드 발급국인 KR로 두고 통화만 PHP로 보내는 개선판을 씁니다. 그래도 안 되면 카드사를 바꿔 보거나 필리핀 VPN을 켜고 다시 시도한 사례가 있습니다.

Q

이미 Pro를 구독 중인데 갈아탈 수 있나요?

구독이 살아 있는 동안은 통화를 바꿀 수 없습니다. OpenAI 정책상 해지 후 결제 기간이 끝나야 다른 통화로 재구독할 수 있으며, 만료 직후 같은 계정에서 성공한 사례가 있어 새 계정은 필요 없습니다.

Q

계정이 정지될 위험이 있나요?

있습니다. OpenAI 약관은 정확한 결제 정보 제공을 요구하고 제한 우회 시 계정 정지가 가능하다고 명시합니다. 지금까지 정지 사례 보고는 드물지만 공식 입장이 없으므로 본인 책임으로 판단해야 합니다.
