클로드 코드 스킬로 인스타 카드뉴스·릴스 직접 만들기

카드뉴스·릴스를 뽑아주는 AI 서비스가 넘치는데도 클로드 코드로 스킬을 직접 짠 이유를 따라가 본다

2026-08-20논의 1회 정리

캔코단에서 한 참여자가 gptaku 플러그인 덕분에 인스타그램 카드뉴스 제작 스킬을 완성했다며 감사 인사를 남겼다. 오픈소스 프로젝트 두 개를 조합해 반복 프롬프트로 다듬었다. 지금은 대본과 영상 목록만 넣으면 릴스 결과물까지 뽑아낸다고 했다. 카드뉴스와 릴스를 만들어주는 상용 AI 서비스가 이미 여럿인 상황에서, 굳이 직접 스킬을 짜서 얻는 게 무엇인지 따져볼 만하다.

카드뉴스 AI는 이미 넘치는데 왜 직접 만들었나

캔바는 AI로 소셜미디어 게시물 초안을 만드는 기능을 제공한다. 국내 서비스인 미라(Mirra)나 레비오사 AI도 카드뉴스나 숏폼 콘텐츠 제작을 지원한다. 값도 싸다. 레비오사 쪽은 카드뉴스·숏폼 마케팅 자동화를 홍보한다.

그런데도 방에서는 기존 서비스 대신 클로드 코드 위에서 스킬을 직접 짰다. 상용 서비스는 정해진 템플릿과 톤 안에서만 움직인다. 스스로 짠 스킬은 본인 브랜드 목소리와 카드 장수, 문구 규칙을 코드 수준에서 고정해 둘 수 있다는 차이가 있다. 구독료 없이 이미 쓰던 클로드 코드 세션 안에서 끝난다는 점도 크다.

오픈소스 두 개를 엮어 반복 프롬프트로 완성한 과정

방에서 언급된 방식은 깃허브에 공개된 오픈소스 프로젝트 두 개를 골라 조합하고 원하는 결과가 나올 때까지 클로드에게 반복해서 프롬프트를 주는 식이었다. 바이브 코딩 실전에서 흔히 권하는 접근과 맞닿아 있다. 프롬프트를 잘 쓰는 사람들은 반복되는 기준을 문서로 고정해 둔다는 지적처럼, 이 방식도 결과물이 마음에 들 때까지 대화를 반복하면서 규칙을 다듬었다. 그렇게 다듬은 규칙을 SKILL.md라는 지침 파일로 굳히는 흐름이었다.

Anthropic이 2025년 10월 정식 출시한 Agent Skills는 정확히 이 구조를 위한 기능이다. SKILL.md 파일에 지침과 참고 자료를 담아두면, 클로드가 관련 작업이라고 판단할 때만 그 내용을 불러와 적용한다. 슬래시 명령으로 직접 호출할 수도 있고 맥락에 맞으면 자동으로 트리거되기도 한다. 매번 처음부터 프롬프트를 새로 쓰는 대신, 한 번 완성한 지침을 계속 재사용할 수 있다는 게 핵심이다.

gptaku 플러그인이 하는 역할

방에서는 이 스킬 제작을 가능하게 한 도구로 gptaku 플러그인을 꼽았다. 클로드 코드용 오픈소스 플러그인 모음으로, 깃허브 저장소를 마켓플레이스로 등록해 슬래시 명령 한 줄로 설치할 수 있다. 검색이 막힌 페이지를 우회해서 읽어오는 기능처럼 클로드 코드 기본 기능만으로는 막히는 지점을 뚫어주는 플러그인들을 묶어 배포한다. 플러그인은 슬래시 명령, 서브 에이전트, 훅, MCP 서버, 스킬을 한 패키지로 묶어 설치와 공유를 쉽게 만든 단위다.

클로드 코드 플러그인 생태계 자체도 빠르게 커지는 중이다. 오픈 SKILL.md 표준을 쓰는 한 스킬 마켓플레이스에는 이미 1만 2천 개가 넘는 스킬이 올라와 있다. Claude Code뿐 아니라 Codex CLI나 Cursor 같은 다른 코딩 에이전트에서도 같은 형식을 그대로 쓸 수 있다. 개인이 짠 스킬 하나가 방 밖에서도 재사용될 여지가 있다는 뜻이다.

대본부터 영상까지, 어디까지 믿고 맡길 수 있나

완성된 스킬은 영상 목록만 넣으면 대본 작성과 릴스 결과물까지 이어서 처리한다고 소개됐다. 비슷한 목표를 가진 상용 도구로는 브루(Vrew)가 있는데, 주제만 입력하면 스크립트와 이미지 요소를 함께 생성해 릴스나 유튜브 쇼츠용 영상을 만들어낸다. 캡컷도 사진과 영상을 자동 편집해 릴스로 바꿔주는 기능을 무료로 제공한다.

다만 자동 생성 콘텐츠를 실제로 운영에 써본 쪽에서는 불만도 적지 않다. 매번 결과물이 고만고만한 "AI 느낌"으로 나온다거나 브랜드 톤을 유지하기 어렵다는 지적이다. 인스타그램은 2026년 5월부터 AI로 콘텐츠를 자주 만드는 계정이 스스로 켤 수 있는 "AI 크리에이터" 라벨 테스트를 시작했다. 사실적으로 생성하거나 변형한 영상 또는 음성에는 AI 제작 사실을 표시하도록 요구하고 있다. 표시 의무를 지키지 않으면 제재로 이어질 수 있다. 관건은 자동화 자체가 아니라 그 결과물에 크리에이터 개성이 얼마나 남아 있는지다.

혼자서 여러 채널을 굴려야 하는 사람에게 남는 몫

1인 사업자나 소규모 팀이 이런 자동화로 얻는 가장 뚜렷한 변화는 시간이다. 통합 워크플로우를 구축하면 SNS 콘텐츠 준비 시간을 줄일 수 있다. 하나의 원본 콘텐츠를 블로그와 카드뉴스, 릴스로 동시에 뽑아내는 원소스 멀티유즈 전략의 실제 사례이기도 하다.

방에서 완성된 스킬을 두고 나온 반응은 결과물의 품질보다 "이렇게도 만들 수 있다"는 확인에 가까웠다. 상용 서비스가 이미 비슷한 기능을 훨씬 다듬어진 인터페이스로 제공하는 상황에서, 클로드 코드 스킬을 직접 짜는 선택이 갖는 값어치는 완성도가 아니라 통제권에 있다. 어떤 문구 규칙을 쓸지, 몇 장짜리로 만들지, 어떤 톤을 지킬지를 코드로 고정해 두면 그다음부터는 새 콘텐츠마다 처음부터 설명하지 않아도 된다. 그 격차가 실제 피드 운영에서 얼마나 버텨줄지는 다음 콘텐츠 몇 개를 더 뽑아봐야 드러날 문제다.

자주 묻는 질문

Q

클로드 코드 스킬(Agent Skills)이 뭔가요

SKILL.md 파일에 작업 지침과 참고 자료를 담아두면 클로드가 관련 작업이라고 판단할 때 불러와 적용하는 기능이다. Anthropic이 2025년 10월 정식 출시했고, 슬래시 명령으로 직접 호출하거나 맥락에 맞춰 자동으로 트리거된다.

Q

gptaku 플러그인은 무엇인가요

클로드 코드용 오픈소스 플러그인 모음으로, 깃허브 저장소를 마켓플레이스로 등록해 슬래시 명령으로 설치한다. 검색 우회 등 클로드 코드 기본 기능이 막히는 지점을 뚫어주는 여러 플러그인을 묶어 배포한다.

Q

AI로 만든 카드뉴스·릴스도 인스타그램에서 라벨이 붙나요
