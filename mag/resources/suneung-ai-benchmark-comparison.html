수능 AI 벤치마크, 모델별 점수보다 중요한 비교 조건

국어·수학 만점 주장부터 영어 듣기 평가까지, 수능냥이를 계기로 AI 성적표의 입력 방식과 추론 예산, 채점 기준을 살펴본다.

2026-11-20논의 1회 정리

수능 문제로 AI를 겨뤄보면 어떤 모델을 선택할지 알 수 있을까. 클코단에서는 페이블의 성적을 놓고 상반된 설명이 나왔다. Qwen 27B와 테라의 비교도 국어에 한정됐다는 정정이 뒤따랐다.

같은 시험을 풀었다는 이유만으로 AI 점수를 나란히 비교해도 될까.

수능냥이의 순위는 무엇을 합산하는가

공유된 수능냥이는 2027학년도 수능을 대상으로 하는 모델 리더보드다. 공개 화면은 선택과목별 원점수의 평균으로 순위를 정하고 동점에서는 처리 시간이 짧은 모델을 우선한다고 설명한다. 다만 이번 조회에서는 동적 성적표를 불러오지 못해 개별 모델의 점수와 순위를 검증하지 못했다. (suneung-cat.vercel.app)

커뮤니티에서는 페이블이 높은 성적을 냈다는 평가와 수학에서 기대에 못 미쳤다는 설명이 함께 등장했다. 같은 실행을 가리킨 것인지, 선택과목이나 설정이 달랐는지는 제공된 기록만으로 알 수 없다. 어느 쪽을 확정 성적으로 채택하기보다 검증되지 않은 결과로 남겨야 한다.

시험 연도와 채점 시점도 구별해야 한다. 한국교육과정평가원은 2027학년도 문제와 정답을 2026년 11월 19일부터 공개했다. 최종 정답 확정은 12월 1일 예정이므로 최초 공개 답안을 사용한 AI 성적표에는 잠정 채점이라는 조건이 붙는다. (cdn2.kice.re.kr)

순위표의 숫자를 보기 전에 그 숫자의 분모부터 확인해야 한다.

국어에서 비슷해도 수학까지 동급은 아니다

Qwen을 추론이나 수학에 활용할 만하다는 의견은 모델을 시험할 이유가 된다. 그러나 Qwen 27B와 테라가 비슷하다는 비교는 커뮤니티에서도 국어에 국한해 설명됐다. 이를 전체 능력이 비슷하다는 주장으로 넓히면 원래 평가 범위를 벗어난다.

수학 점수조차 모두 같은 척도는 아니다.

충남대학교 ISoft 연구실의 2026학년도 수능 평가에서는 세 선택과목을 모두 포함해 46문항을 사용했다. 총 배점 152점을 100점으로 환산했으며 수험생이 선택과목 하나를 응시하는 방식과 구분했다. (isoft.cnu.ac.kr)

이 연구는 텍스트·이미지 입력과 프롬프트 언어를 나눠 비교했다. 연구진은 텍스트 입력이 이미지 입력보다 전반적으로 유리했다고 보고했다. 추론 강도를 높일 때 성적과 토큰 사용량이 함께 증가했다고도 밝혔다. 같은 모델 이름 옆에 붙은 점수라도 입력과 계산 예산이 다르면 다른 실험이다. (isoft.cnu.ac.kr)

개인 개발자에게 필요한 해석도 여기서 달라진다. 문서 사진을 읽는 서비스를 만들려는 경우라면 텍스트로 정리한 문제의 고득점만으로 모델을 결정하기 어렵다. 해당 연구의 입력별 차이는 실제 서비스와 닮은 조건에서 후보를 다시 평가해야 한다는 근거가 된다. (isoft.cnu.ac.kr)

OpenRouter를 써도 실행 조건은 남는다

비교자는 개인 장비의 영향을 덜 받으려고 OpenRouter를 이용했고 호출 비용도 직접 부담했다고 설명했다. 로컬 실행 환경을 비교에서 제외하려는 선택이다. 다만 API 창구를 하나로 맞추는 것과 모델의 실행 조건을 같게 만드는 것은 별개다.

OpenRouter 공식 문서에 따르면 요청은 여러 제공업체로 라우팅될 수 있다. 기본 선택에는 가격뿐 아니라 처리량, 지연, 신뢰성 등이 반영된다. provider.order와 provider.only로 대상 제공업체를 지정하고 allow_fallbacks로 대체 제공업체 사용 여부를 제어할 수 있다. (openrouter.ai)

비교 실험에서는 모델 ID와 실제 제공업체를 함께 기록하는 편이 적절하다. 제공업체를 고정하지 않은 실험은 자동 라우팅을 포함한 서비스 평가로 구별하면 된다. 어느 설계든 실패한 요청을 다른 제공업체에서 다시 처리했는지 남겨야 결과를 해석할 수 있다. (openrouter.ai)

추론 예산도 비용과 채점에 직접 영향을 준다.

OpenRouter는 추론 토큰을 출력 토큰으로 과금하며 많은 제공업체에서 출력 한도에 추론과 최종 답변을 함께 포함한다. 한도를 추론에 모두 사용하면 최종 답이 비어 있을 수 있다는 설명도 있다. (openrouter.ai)

오답, 응답 중단, 답안 추출 실패를 같은 이유로 처리하면 분석이 흐려진다. 소규모 팀의 비교표에는 총점과 함께 완성된 답변 수, 재시도 횟수, 실제 사용량을 별도 항목으로 두는 편이 유용하다. 단 한 번의 최고점보다 정해진 비용 안에서 반복적으로 답을 제출하는지가 운영 판단에 가깝다.

영어 듣기는 대본 풀이와 따로 측정해야 한다

커뮤니티에서는 영어 음성을 GPT나 Gemini 계열에 전달해보자는 제안이 나왔다. 탐구 과목으로 범위를 넓힐 때는 그림을 읽는 능력과 추가 비용이 문제로 거론됐다. 두 이야기는 AI에게 어떤 형태의 시험지를 주었는지 공개해야 한다는 질문으로 이어진다.

Google의 Gemini 공식 문서는 오디오 입력을 분석하고 텍스트로 응답하는 기능을 안내한다. 예제에서는 client.files.upload로 MP3를 올린 뒤 파일 URI와 질문을 함께 전달한다. 음성 파일을 넣어 내용을 질문하는 절차 자체는 공식적으로 지원된다. (aistudio.google.com)

수능 듣기에 적용한다면 음성과 해당 문항의 질문·선택지를 입력하고 문항별 답을 받아 정답표와 대조하는 실험을 설계할 수 있다.

대본을 제공하는 실험은 별도 항목으로 분리해야 한다. 음성을 이해하는 과정과 이미 문자로 변환된 내용을 읽는 과정은 평가하는 입력 능력이 다르기 때문이다. (aistudio.google.com)

별도 공개 프로젝트인 KSAT AI Benchmark는 이 차이를 명시한다. 저장소 README는 영어 듣기 문항을 공식 대본 이미지로 평가하며 음성 청취 평가와 구별한다고 설명한다. 영어 점수가 있다는 사실만으로 듣기까지 시험했다고 해석할 수 없는 구체적인 사례다. (github.com)

재현 가능한 성적표에는 답안과 설정이 함께 남는다

수능냥이의 제작 과정과 실행 코드는 이번 조사에서 확인하지 못했다. 커뮤니티에서 언급된 자동 업데이트를 구현 안내로 확대할 수는 없다. 대신 KSAT AI Benchmark의 공개 README에서 비교 절차를 살펴볼 수 있다.

이 저장소는 문제 PDF를 200 DPI 이미지로 바꾸고 같은 픽셀을 유지하는 무손실 WebP로 인코딩한다고 설명한다. 정답은 모델 요청에 넣지 않으며 도구와 검색을 비활성화한다. 입력 이미지에서 답안을 생성한 뒤 채점하는 과정과 정답을 미리 제공하는 과정을 분리한 구성이다. (github.com)

문서상 실행 순서는 모델별 평가, 데이터 내보내기, 웹 빌드다. node benchmark/run.mjs --model …로 평가하고 node benchmark/export.mjs를 거쳐 npm run build --prefix web으로 결과 화면을 만든다. 이 명령은 해당 저장소의 환경과 모델 접근 권한을 갖췄을 때 사용하는 절차이며 수능냥이의 구현 방식은 아니다. (github.com)

운영에서 더 중요한 원칙은 확정 정답이 바뀌어도 모델을 다시 호출하지 않는 것이다.

저장된 답안을 새 정답표로 재채점하면 모델 응답의 변화와 채점 기준의 변화를 섞지 않을 수 있다. 해당 프로젝트도 최초 정답에 따른 잠정 결과와 최종 재채점을 구분한다. (github.com)

페이블의 상반된 평가나 Qwen의 과목별 비교를 해결하는 데 필요한 것도 이런 기록이다. 원본 답안과 실행 조건을 확인하지 못한 상태에서는 승자를 선언할 근거가 부족하다. 수능 AI 비교의 실익은 만점 모델의 이름보다 그 점수를 다시 설명할 수 있는 성적표에 있다.

자주 묻는 질문

Q

수능 AI 벤치마크 점수는 서로 바로 비교할 수 있나요?

시험 학년도, 선택과목, 입력 형식과 배점 기준이 같은지 확인해야 합니다. 충남대 평가처럼 모든 수학 선택과목을 합산한 뒤 100점으로 환산하는 방식도 있습니다. (isoft.cnu.ac.kr)

Q

OpenRouter를 쓰면 모델 비교 조건이 같아지나요?

같은 API를 사용해도 실제 제공업체와 추론 설정은 다를 수 있습니다. OpenRouter는 제공업체 지정과 대체 라우팅 제어 기능을 제공합니다. (openrouter.ai)

Q

AI 수능 영어 점수에는 듣기 평가도 포함되나요?

평가마다 다릅니다. KSAT AI Benchmark는 듣기 문항을 대본 이미지로 풀게 하므로, 실제 음성을 입력한 평가와 구별합니다. (github.com)
