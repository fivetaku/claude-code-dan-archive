서울 Claude Builder Summit, 5시간 해커톤인가

발표 행사와 제작 해커톤의 차이부터 API 크레딧, 네트워킹, 짧은 빌드 준비법까지 짚었다

2026-09-24논의 1회 정리

Claude Builder Summit에 가면 5시간 동안 제품을 만들어야 할까. API 크레딧은 실제 개발에 얼마나 도움이 되며 현장 네트워킹은 누구에게 유효할까. 서울 행사의 기록과 2026년 후속 프로그램을 살펴보려면 ‘서밋’과 ‘빌드 행사’를 먼저 구분해야 한다.

서울 Builder Summit은 5시간 제작 행사가 아니었다

Anthropic 공식 페이지에 남아 있는 Seoul Builder Summit은 2025년 3월 19일 행사다. 시그니엘 서울에서 오후 2시 30분부터 7시까지 열렸으며 Coxwave가 공동 주최했다. 전체 운영 시간이 약 4시간 30분이라 ‘5시간 빌드’로 잘못 읽히기 쉽지만 공식 소개에는 현장 해커톤이 없다. ([anthropic.com](https://www.anthropic.com/events/seoul-builder-summit))

프로그램의 중심은 Anthropic 리더십 발표와 국내 스타트업 사례였다. Claude의 프로덕션 활용법과 연구 동향, Mike Krieger와의 대화, 기업 패널이 이어졌다. 공식 페이지는 Coxwave, WRTN, LinqAlpha, KLleon 등을 참여 기업으로 안내했다. ([anthropic.com](https://www.anthropic.com/events/seoul-builder-summit))

행사 이름의 ‘Builder’는 참가자가 그날 코드를 완성한다는 의미가 아니었다. 이미 Claude로 제품을 만들고 있거나 도입을 검토하는 창업자와 기술 책임자가 주요 대상이었다.

현장에서 얻는 것은 코드보다 제품 판단과 연결이었다

행사 안내에는 동료 창업자와 교류하고 Anthropic 연구·스타트업 팀에 질문하는 시간이 명시됐다. 보도된 일정에도 마지막 네트워킹 세션과 다과가 포함됐다. 참가 신청은 마감됐고 공식 페이지는 온라인 생중계를 대안으로 제시했다. 공식 페이지는 마감 뒤 온라인 생중계를 대안으로 제시했다. ([anthropic.com](https://www.anthropic.com/events/seoul-builder-summit))

현장 경험을 나눈 사람들 사이에서는 발표 자체보다 세션 사이의 짧은 대화가 유용했다는 의견이 많았다. 다만 초대된 기업과 관계자가 많은 행사라 처음 참석한 개인 개발자는 대화를 시작하기 어렵다는 반응도 있었다.

이런 형식에서는 막연한 자기소개보다 구체적인 질문이 효과적이다. ‘Claude를 쓰고 있다’고 말하기보다 입력 데이터, 모델 선택, 비용 병목, 평가 방법을 30초 안에 설명해야 한다. 화면 하나로 시연할 수 있는 프로토타입이나 저장소 구조도가 있으면 기술 대화로 넘어가기 쉽다.

제공 크레딧은 금액보다 조건을 확인해야 한다

공동 주최 측의 사전 안내와 행사 보도에는 참가자 대상 Claude 크레딧 제공이 언급됐다. 그러나 공개된 공식 행사 페이지에는 금액과 만료일이 적혀 있지 않다. 특정 액수나 사용 기간을 당시 행사의 공통 조건으로 단정할 수 없는 이유다. ([kr.linkedin.com](https://kr.linkedin.com/posts/coxwave_koreabuildersummit-anthropic-coxwave-activity-7300339643579871233--uyb?utm_source=openai))

현재 Claude Console의 사용 크레딧은 API, 플레이그라운드, Claude Code에 쓸 수 있다. 구매한 크레딧은 결제일로부터 1년 뒤 만료되지만 행사에서 받은 프로모션 크레딧에는 별도 조건이 붙을 수 있다. 잔액과 사용량은 Console의 Billing 화면에서 확인한다. ([support.anthropic.com](https://support.anthropic.com/en/articles/8977456-how-do-i-pay-for-my-api-usage?utm_source=openai))

크레딧의 실질 가치는 프로젝트 구조에 달렸다. 제품이 Claude API를 계속 호출한다면 추론 비용을 줄여주는 운영 자금이 된다. 웹이나 앱에서 Claude와 대화하는 용도만 기대했다면 체감 가치는 낮을 수 있다. 써본 사람들 사이에서도 ‘초기 제품에는 유용하다’는 평가와 ‘현금성 혜택은 아니다’라는 불만이 함께 나온다.

행사 등록 뒤에는 지급 방식, 사용할 조직과 워크스페이스, 만료일, 적용 제품 등 네 가지를 확인해야 한다. Claude 구독 한도와 API 크레딧은 같은 개념이 아니므로 둘을 섞어 계산하면 안 된다.

짧은 빌드에서는 완성 범위를 먼저 줄인다

2026년 서울에서는 Builder Summit과 다른 형식의 행사가 이어졌다. Anthropic은 6월 Claude Build Day에 국내 창업자와 개발자 100여 명이 참여했다고 밝혔다. 이어 Replit, 한국투자파트너스, 한국투자액셀러레이터와 Push to Prod Seoul을 열고 Claude Code로 제품을 만드는 해커톤을 진행했다. ([anthropic.com](https://www.anthropic.com/news/seoul-office-partnerships-korean-ai-ecosystem?utm_source=openai))

이런 짧은 빌드에서는 새 기술을 많이 넣는 팀보다 하나의 사용자 흐름을 끝까지 연결한 팀이 유리하다. 시작 전에 `README.md`에 문제, 사용자, 입력, 기대 출력을 적는다. `CHECKPOINT.md`에는 완료한 작업과 다음 순서를 남겨 Claude Code가 같은 일을 반복하지 않게 한다.

작업 순서는 단순해야 한다. 빈 저장소에 검증된 프레임워크를 설치한 뒤 가짜 데이터로 화면과 API부터 연결한다. 그다음 Anthropic SDK와 `ANTHROPIC_API_KEY`를 서버에 넣고 Messages API 호출 하나만 붙인다. 브라우저 코드에 키를 넣지 말고 백엔드 프록시를 거쳐야 한다. API 키는 Console에서 만들며 SDK는 환경변수에 저장된 키를 읽을 수 있다. ([platform.claude.com](https://platform.claude.com/docs/en/manage-claude/authentication?utm_source=openai))

첫 산출물은 로그인이나 관리 화면이 아니다. 사용자가 값을 넣고 Claude의 결과를 받아 다시 행동하는 하나의 경로다. 남은 시간에는 오류 메시지, 로딩 상태, 데모 데이터, 2분짜리 시연 순서를 다듬는다. 멀티에이전트나 복잡한 MCP 연결은 그 경로가 완성된 뒤에 넣어야 한다.

서울 행사는 발표회에서 제작 현장으로 넓어졌다

2025년 Builder Summit은 Anthropic이 한국 시장과 처음 공식적으로 만나는 발표·교류 행사에 가까웠다. 2026년 6월에는 서울 사무소가 문을 열었다. Claude for Startups와 개발자 밋업, Build Day, Push to Prod도 함께 운영됐다. Anthropic은 2025년 9월 이후 국내 밋업에 수백 명이 참여했다고 밝혔다. ([anthropic.com](https://www.anthropic.com/news/seoul-office-partnerships-korean-ai-ecosystem?utm_source=openai))

행사명만 보고 신청 여부를 정하면 형식을 오해하기 쉽다. Summit은 발표자와 참가자 구성을, Build Day는 실습 범위를, Hackathon은 제출물과 심사 조건을 먼저 읽어야 한다. 개인 개발자에게 Builder Summit은 제품 방향을 검증하는 자리였다. 후속 빌드 행사는 실제 작동물을 보여주는 무대로 바뀌었다.

서울에서 열린 첫 Builder Summit의 핵심 산출물은 다섯 시간짜리 앱이 아니었다. 그날 만들어진 것은 Anthropic과 국내 빌더 사이의 접점이었다. 실제 제작 경쟁은 다음 단계의 행사에서 시작됐다.

자주 묻는 질문

Q

서울 Claude Builder Summit은 해커톤인가요?

2025년 3월 행사는 발표, 기업 사례, 질의응답, 네트워킹 중심의 서밋이었다. 실제 제작 행사는 2026년 Claude Build Day와 Push to Prod Seoul 같은 별도 프로그램에서 진행됐다.

Q

행사에서 받은 Claude API 크레딧은 어디에 쓰나요?

일반적인 사용 크레딧은 Claude API, Workbench, Claude Code에 적용할 수 있다. 행사 크레딧은 지급 조직과 만료일, 적용 제품이 다를 수 있으므로 안내 메일과 Console Billing 화면을 확인해야 한다.

Q

5시간 AI 해커톤에서는 무엇부터 만들어야 하나요?

입력 하나와 결과 하나가 연결되는 핵심 사용자 흐름부터 완성해야 한다. 검증된 스택으로 화면과 API를 연결한 뒤 Claude 호출을 붙이고, 마지막에는 오류 처리와 짧은 시연을 준비하는 편이 안전하다.
