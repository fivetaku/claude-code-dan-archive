Claude Max와 ChatGPT Pro, 월 100달러 사용 한도 비교

Claude Max에서 자주 막힌다면 ChatGPT Pro가 대안일까. 같은 가격의 한도 구조와 추가 과금, 실제 개발 과제로 비교하는 방법을 짚는다.

2026-09-06논의 1회 정리

Claude Max를 결제했는데도 작업 도중 한도가 닳는다면, 같은 월 100달러를 ChatGPT에 쓰는 편이 나을까. 클코단에서 나온 질문의 핵심은 모델 선호보다 필요한 시간 동안 개발을 이어갈 수 있느냐다. 현재 공식 요금과 한도 구조를 바탕으로, 구독을 바꾸면 해결되는 문제와 그대로 남는 문제를 나눠 살펴본다.

월 100달러끼리 비교해도 사용량은 같지 않다

2026년 9월 확인한 Anthropic의 Max 안내에 따르면, Max 5x는 월 100달러, Max 20x는 월 200달러다. 각각 Claude Pro보다 세션당 사용량을 5배, 20배 제공한다. 웹 구독 기준이며 모바일 결제 가격은 다를 수 있다.

OpenAI의 공식 가격 문서에도 월 100달러인 ChatGPT Pro 5x와 월 200달러인 Pro 20x가 있다. Codex 사용량은 각각 ChatGPT Plus 대비 5배와 20배다. 따라서 같은 예산의 비교는 Max 5x와 Pro 5x를 맞춰야 한다.

하지만 두 회사의 '5배'를 같은 토큰 수로 읽으면 안 된다. 기준이 되는 기본 요금제부터 다르다. 모델과 작업에 따라 사용량을 소모하는 방식도 달라진다. Max 5x와 Pro 5x의 가격이 같다는 사실만으로 어느 쪽이 더 오래 일하는지는 판정할 수 없다.

클코단에서는 대기 때문에 흐름이 끊기는 문제라면 GPT를 대안으로 검토하자는 의견이 나왔다. 이 경험은 비교할 이유를 제공하지만 모든 이용자에게 적용되는 사용량 우위의 증거는 아니다.

초기화 시각보다 어떤 한도에 걸렸는지가 중요하다

Anthropic은 Max의 세션 한도가 5시간마다 초기화된다고 설명한다. 여기에 모든 모델 사용에 적용되는 주간 한도가 별도로 붙는다. 주간 초기화 시각은 계정에 배정되므로, 세션 한도가 돌아왔다고 주간 한도까지 회복되지는 않는다.

Claude 웹에서 문서를 분석하고 Claude Code에서 개발했다면 두 작업은 같은 구독 한도를 쓴다. Anthropic의 Pro·Max 지원 문서는 Claude와 Claude Code의 사용량을 합산한다고 명시한다. 브라우저를 닫고 터미널로 옮기는 것만으로 새 할당량이 생기지 않는다.

Codex도 한도가 있다.

OpenAI는 5시간 기준의 메시지 추정 범위를 안내하며 주간 제한도 적용될 수 있다고 밝힌다. 로컬 작업과 클라우드 작업은 한도를 공유한다. 현재 ChatGPT Work 역시 Codex와 사용량을 나눠 쓴다.

GPT로 전환하면 초기화가 항상 더 자주 일어난다는 일반화는 공식 문서가 뒷받침하지 않는다. 단시간에 몰아서 일하다 막히는지, 여러 날 누적한 사용량 때문에 막히는지를 구분해야 전환 효과를 설명할 수 있다.

구독을 올리기 전에 줄일 수 있는 소모가 있다

'토큰이 부족하다'는 표현에는 서로 다른 문제가 섞인다. Anthropic 문서는 기간별 사용 한도와 대화에 담을 수 있는 길이 제한을 구분한다. Claude Code의 대화 압축 안내가 떴다는 이유만으로 더 비싼 구독이 필요한 것은 아니다.

현재 Claude Code에서는 `/usage`로 구독 사용량과 활동 통계를 확인할 수 있다. 웹의 Settings > Usage에서는 다음 초기화 시각을 확인한다. `/usage`의 세션 달러 표시는 API 요율로 계산한 비용 추정치여서 Max 구독자의 실제 청구액으로 읽으면 안 된다.

Anthropic의 비용 관리 문서는 관계없는 작업으로 넘어갈 때 `/clear`로 새 대화를 시작하라고 권한다. 긴 대화의 핵심을 남겨야 한다면 `/compact`를 쓰고 `/context`로 무엇이 대화 공간을 차지하는지 살필 수 있다. 이런 명령은 문맥을 관리하며 구독 한도를 초기화하지는 않는다.

작업 지시도 소모량에 영향을 준다. 저장소 전체를 개선하라는 요청보다 수정할 함수, 재현 조건, 통과해야 할 테스트를 지정하는 편이 탐색 범위를 좁힌다. 공식 문서는 모델 선택과 긴 문맥, 여러 에이전트의 동시 실행도 비용을 좌우한다고 설명한다.

개인 개발자에게는 새 구독을 하나 더 사기 전에 적용할 수 있는 변화다. 다만 탐색을 줄였는데 수정 실패가 늘었다면 절약에 성공했다고 할 수 없다.

Codex로 옮겨볼 때는 같은 작업의 완료 비용을 잰다

Claude Code를 대체하려는 비교라면 ChatGPT의 대화창만 시험해서는 충분하지 않다. OpenAI의 Codex CLI는 로컬 저장소를 읽고 파일을 수정하고 명령을 실행한다. 평소 Claude Code에 맡기는 개발 과제를 이 환경에서도 수행해야 비교 대상이 맞는다.

공식 설치 안내에 따라 `npm install -g @openai/codex`로 설치한 뒤, 프로젝트 디렉터리에서 `codex`를 실행한다. 구독에 포함된 사용량을 시험할 때는 ChatGPT 계정으로 로그인한다. API 키로 이용하면 구독과 별개인 API 요금이 적용된다.

비교용 과제에는 같은 시작 상태의 코드, 버그 재현 절차, 기대 동작과 테스트 명령을 넣는다. 두 도구가 수정한 코드를 각각 실행하고 완료까지 걸린 시간과 다시 설명한 횟수를 기록한다. Codex의 남은 한도는 `/status` 또는 사용량 대시보드에서 확인할 수 있다.

한 번의 답변 길이보다, 받아들일 수 있는 수정 한 건에 얼마의 한도와 시간이 들었는지가 중요하다. OpenAI도 작업의 복잡도와 문맥, 모델, 추론, 도구 사용과 캐시가 소모량에 영향을 준다고 설명한다. 메시지 수를 고정된 작업 가능 횟수로 간주하지 않는 이유다.

소규모 팀이라면 기능 추가와 오류 수정처럼 실제 반복하는 과제를 비교하는 편이 유용하다. 대기 시간은 줄었어도 사람이 검토하고 고치는 시간이 늘었다면, 구독료 밖에서 비용이 발생한 것이다.

가끔 막히는 달과 매일 막히는 달은 선택이 다르다

상위 구독만이 공식적인 해결책은 아니다. Anthropic은 유료 구독의 한도를 넘겨 계속 쓸 수 있는 Usage credits를 제공한다. 구독료와 별도로 청구되며 월 지출 한도를 설정할 수 있다.

OpenAI 역시 Plus·Pro 이용자가 추가 크레딧을 구매해 기존 요금제를 유지하면서 Codex를 더 쓰도록 한다. 양사 모두 추가 사용 경로가 있으므로, 한 차례의 마감 때문에 막혔다고 반드시 월 고정비를 높일 필요는 없다. 다만 추가 결제가 가능한 상태의 작업 지속 시간을 기본 구독의 넉넉함과 혼동해서는 안 된다.

클코단에는 Claude 사용을 이어가기 위해 더 높은 등급이나 계정을 추가로 쓰는 경험담도 있었다. 하지만 그 경험만으로 비용 효율을 입증할 수는 없다. 기존 도구에서 막히는 시간과 다른 도구로 전환하며 발생하는 재작업을 함께 계산해야 한다.

월 100달러의 선택을 가르는 것은 제공 토큰의 추상적인 많고 적음이 아니다. 필요한 품질을 유지한 채 끝낸 작업 수와, 그 과정에서 실제로 멈춘 시간이다. GPT가 더 여유롭다는 체감이 자신의 개발 과제에서도 재현될 때, 비로소 구독을 옮길 경제적 근거가 생긴다.

자주 묻는 질문

Q

Claude Max와 ChatGPT Pro의 월 100달러 요금제는 사용량이 같나요?

같다고 볼 수 없습니다. Claude Max 5x는 Claude Pro 대비 세션당 사용량이며, ChatGPT Pro 5x의 Codex 사용량은 ChatGPT Plus를 기준으로 합니다. 모델과 작업에 따른 소모량도 달라 동일 과제로 비교해야 합니다.

Q

Claude Code 사용량은 Claude 웹과 별도로 제공되나요?

Pro·Max 구독에서는 Claude와 Claude Code가 사용 한도를 공유합니다. 웹에서 대화한 뒤 Claude Code를 실행해도 별도의 할당량이 새로 생기지 않습니다.

Q

Claude Code와 Codex의 남은 사용량은 어떻게 확인하나요?

현재 Claude Code에서는 `/usage`, Codex CLI에서는 `/status`로 확인할 수 있습니다. 정확한 초기화 시각과 계정 한도는 각 서비스의 사용량 화면에서도 확인할 수 있습니다.

Q

사용 한도에 도달하면 반드시 상위 요금제로 바꿔야 하나요?

Claude와 Codex 모두 대상 유료 구독자에게 추가 크레딧 경로를 제공합니다. 추가 사용은 기본 구독료 밖의 지출이므로, 간헐적인 초과 비용과 상위 요금제의 월 고정비를 비교할 수 있습니다.
