제미나이 CLI 개인 서비스는 끊겼어도 저장소는 여전히 매일 릴리즈되고 있다

프로·울트라 개인 요청은 6월에 끊겼지만 엔터프라이즈는 그대로, 안티그래비티와도 별개로 매일 새 버전이 올라온다

2026-08-07논의 1회 정리

방에서 누군가 "제미나이 CLI 이제 안되는 거 아니냐"고 물으면서 이야기가 시작됐습니다. 확인해보니 완전히 틀린 말은 아니었어요. 구글은 2026년 6월 18일부로 제미나이 CLI와 제미나이 코드 어시스트 IDE 확장에서 구글 AI 프로·울트라 구독자와 무료 사용자, 개인용 코드 어시스트 사용자의 요청 처리를 끊었습니다. 터미널에 명령어를 쳐도 응답이 안 오는 사람들이 실제로 생긴 거죠.

종료 소문의 절반만 진짜였다

그런데 이게 전부가 아니었습니다. 제미나이 코드 어시스트 스탠다드나 엔터프라이즈 라이선스를 쓰는 조직, 유료 제미나이 API 키나 제미나이 엔터프라이즈 에이전트 플랫폼 API 키로 붙는 사용자는 그대로 접근이 유지됩니다. 서비스가 죽은 게 아니라 무료·개인 요금제로 들어가는 문 하나가 닫힌 거였어요.

저장소는 오늘도 릴리즈 중

더 흥미로운 건 깃허브 저장소 쪽입니다. google-gemini/gemini-cli 저장소를 열어보면 오늘 날짜로 정식판 v0.54.4가 올라와 있고, 프리뷰 버전과 야간 빌드까지 하루이틀 간격으로 계속 찍히고 있었어요. 스타는 10만 6천 개를 넘었고 포크가 1만 4천 개, 병합된 풀 리퀘스트만 수백 건입니다. 공개된 지 1년 남짓 된 오픈소스 프로젝트치고는 만만치 않은 규모죠. 개인 사용자 요청 처리는 멈췄어도 코드베이스 자체는 여전히 활발하게 굴러갑니다.

안티그래비티로 흡수된 게 아니다

방에서는 제미나이 CLI가 안티그래비티에 통합된 줄 알았다는 이야기도 나왔는데, 찾아보니 그것도 정확하진 않았습니다. 구글 개발자 블로그는 "제미나이 CLI를 안티그래비티 CLI로 전환한다"는 표현을 썼지만, 실제로는 둘이 다른 코드베이스예요. 안티그래비티 CLI는 Go로 새로 짠 클로즈드소스 도구로, IDE형 에이전트 관리 플랫폼인 안티그래비티의 일부로 움직입니다. 백그라운드에서 여러 에이전트를 비동기로 돌릴 수 있다는 게 강점으로 꼽히고요. 구글이 직접 공개한 안티그래비티 CLI 자체 저장소는 스타가 1800개 정도로, 제미나이 CLI의 10만 스타에는 한참 못 미칩니다. 이름값과 실제 커뮤니티 규모가 따로 노는 셈이죠. 숫자로 보면 오히려 안티그래비티보다 제미나이 CLI 쪽이 더 활발합니다.

구글이 만들고 방치하는 습관

이 흐름을 보면서 구글이 이것저것 벌여놓고 방치하는 경향이 있다는 이야기도 방에서 나왔습니다. 아주 근거 없는 인상은 아닙니다. 단종된 구글 서비스와 제품을 모아놓은 아카이브 사이트에는 지금까지 서비스 193개, 앱 50개, 하드웨어 21개가 올라 있어요. 제미나이 CLI가 그 목록에 온전히 들어간 건 아니지만, 개인 사용자 접근을 끊고 새 도구로 갈아타라고 안내하는 방식 자체는 익숙한 패턴이라는 반응이 많았습니다. 이어서 구글이 검색·유튜브·안드로이드에서 쌓아온 데이터를 AI 쪽에 어떻게 풀어낼지를 두고도 이런저런 잡담이 오갔고요.

정리

제미나이 CLI는 죽지 않았습니다. 개인 무료·프로·울트라 사용자용 문만 닫혔을 뿐, 엔터프라이즈 라이선스와 API 키 사용자에게는 그대로 열려 있고 저장소는 매일 릴리즈를 찍고 있어요. 안티그래비티 CLI는 그 후속작이 아니라 별개의 클로즈드소스 프로젝트고요. 터미널에서 제미나이를 계속 쓰고 싶다면 지금 붙어 있는 요금제와 인증 방식부터 확인해보는 게 순서일 것 같습니다.

Q

제미나이 CLI는 완전히 종료됐나요?

아니요. 2026년 6월 18일부로 구글 AI 프로·울트라 구독자와 무료 사용자용 요청 처리만 중단됐습니다. 엔터프라이즈 라이선스나 유료 API 키 사용자는 계속 쓸 수 있고, 깃허브 저장소도 매일 새 버전을 릴리즈하고 있습니다.

Q

안티그래비티 CLI가 제미나이 CLI의 후속작인가요?

공식적으로는 "전환"이라는 표현을 썼지만 실제로는 별개 프로젝트에 가깝습니다. 안티그래비티 CLI는 Go로 새로 작성된 클로즈드소스 도구로, 오픈소스에 스타 10만 개가 넘는 제미나이 CLI보다 자체 저장소 규모가 훨씬 작습니다.
