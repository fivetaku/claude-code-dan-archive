키쫀쿠 5.5는 무제한일까, Claude Opus 프로모션의 실제 조건

별칭의 정체부터 계정별 리셋, 5시간·주간 한도까지 공식 문서로 사용 조건을 확인했다

2026-09-28논의 1회 정리

Claude Opus 5.5 출시 직후 ‘키쫀쿠 5.5를 사실상 무제한으로 쓸 수 있느냐’는 질문이 퍼졌다. 그러나 별칭과 프로모션, 구독 한도가 한 문장에 섞이면서 답변도 뒤엉켰다. 공식 자료를 기준으로 보면 핵심은 간단하다. Opus 5.5는 무제한 상품이 아니다. 추가 사용 기회는 계정의 Usage 화면에서 확인해야 한다.

키쫀쿠는 공식 제품명이 아니다

‘키쫀쿠’라는 이름은 Anthropic의 제품 페이지, 지원 문서, 개발자 문서에서 확인되지 않는다. Claude 모델이나 구독 플랜, 공개 프로모션의 공식 명칭으로 볼 근거도 찾기 어렵다. 현재 확인되는 제품명은 2026년 9월 22일 공개된 Claude Opus 5.5다.

따라서 키쫀쿠의 뜻을 쿠키나 별도 AI 서비스로 단정한 자동 응답은 신뢰할 수 없다. 검색 결과가 없을 때 익숙한 단어를 끼워 맞춘 전형적인 오답에 가깝다. 커뮤니티 안에서만 통하는 별칭이라면 최초 사용 맥락 없이는 그 의미를 검증할 수 없다.

이 구분은 사소하지 않다. 비공식 별칭을 공식 상품처럼 받아들이면 가입 조건과 종료일도 함께 지어내기 쉽다. 결제 전에는 별칭 대신 모델명과 플랜명, 계정 화면에 표시된 혜택을 각각 확인해야 한다.

Opus 5.5 접근권과 추가 리셋은 다른 혜택이다

Anthropic에 따르면 Opus 5.5는 Pro, Max, Team, Enterprise 이용자가 Claude 앱에서 사용할 수 있다. 개인용 Pro는 월 20달러다. Max는 월 100달러의 5x와 월 200달러의 20x로 나뉜다. 배수는 Pro보다 많은 세션 사용량을 가리키며 무제한을 뜻하지 않는다.

Opus 5.5 출시와 함께 유료 플랜의 5시간 사용 한도가 늘어났다. 구독자에게는 필요할 때까지 저장해 두었다가 쓰는 limit reset도 제공됐다. 리셋은 새 모델 자체가 아니라 계정에 붙는 별도 혜택이다.

Anthropic 지원 문서는 리셋이 대상 플랜에 간헐적으로 제공된다고 설명한다. 사용하면 5시간 세션 한도나 주간 한도를 즉시 채운다. 어떤 한도가 대상인지는 표시된 안내에 따라 달라진다. 평소 주간 갱신 시각은 바뀌지 않는다.

써본 사람들 사이에서는 한 번의 리셋이 예상보다 넉넉하다는 반응이 있었다. 반대로 5시간 한도만 채우는지, 주간 사용량까지 복구하는지 알기 어렵다는 불만도 나왔다. 공식 문서 역시 모든 계정에 같은 종류의 리셋이 지급된다고 약속하지 않는다.

신규 계정을 만들면 받을 수 있다는 보장은 없다

신규 계정 이야기는 서로 다른 제도가 섞이며 생겼다. Anthropic은 일반 쿠폰과 할인 프로모션이 대체로 첫 유료 플랜 가입자에게 제공된다고 밝힌다. 과거에 결제했거나 현재 구독 중인 계정은 특정 가입 프로모션에서 제외될 수 있다.

하지만 Opus 5.5 출시 리셋을 신규 가입 전용이라고 명시한 공식 자료는 확인되지 않는다. 출시 공지는 구독 사용자에게 리셋을 제공한다고 설명한다. 지원 문서에는 적격 플랜에 간헐적으로 제공된다고 적혀 있다. 일반 할인 쿠폰의 신규 가입 규칙을 리셋에 그대로 적용하면 안 된다.

공통 종료일도 공개 문서만으로 확정할 수 없다. 일부 이용 경험에서 특정 날짜가 거론되지만 Anthropic이 안내하는 기준은 각 계정의 Settings > Usage에 표시된 만료 시각이다. 화면에 리셋이 없다면 새 계정을 결제해도 생긴다고 장담할 근거가 없다.

무제한처럼 느껴져도 두 겹의 한도는 남는다

Claude 유료 플랜에는 5시간 세션 한도와 주간 한도가 함께 적용된다. 웹, 데스크톱, 모바일, Claude Code 사용량도 같은 계정 풀에서 빠진다. 긴 대화, 첨부 파일, 높은 effort, 웹 검색과 도구 호출은 더 많은 용량을 쓴다.

고정된 메시지 개수는 없다. 같은 플랜이라도 짧은 질의와 대규모 저장소 분석은 소모량이 크게 다르다. Opus 5.5가 이전 세대보다 효율적으로 느껴졌다는 의견과 사용량 표시가 뒤늦게 뛰었다는 경험이 함께 나오는 이유다.

Max 20x를 사실상 무제한이라고 평가하는 사용기도 있지만 공식 조건과는 다르다. Max에도 주간 제한이 있다. Anthropic은 모델별·기능별 제한을 추가할 수 있다고 명시한다. 한도를 넘긴 뒤 계속 작업하면 usage credits가 표준 API 요율로 차감된다.

개인 개발자에게는 이 지점이 비용 경계다. 구독료 안에서 멈추려면 Usage credits의 월 지출 한도를 설정해야 한다. 켜 둔 채 한도를 무제한으로 지정하면 구독 사용량이 끝난 뒤에도 과금이 이어질 수 있다.

Claude Code에서는 이렇게 확인하고 사용한다

Claude Code에서 /model을 실행해 Opus 5.5를 선택하거나 실행할 때 claude --model claude-opus-5-5를 지정할 수 있다. API에서는 모델 ID claude-opus-5-5를 쓴다. API 이용은 구독 한도와 별도다. 입력 100만 토큰당 4달러, 출력 100만 토큰당 20달러다.

리셋 버튼은 터미널이나 모바일 앱에 나타나지 않는다. 웹 또는 Claude Desktop에서 Settings > Usage를 열어 Resets 영역의 대상 한도와 만료 시각을 확인해야 한다. 버튼을 누르면 취소할 수 없으므로 긴 구현 작업을 시작하기 직전에 쓰는 편이 활용도가 높다.

Opus 5.5는 100만 토큰 컨텍스트와 최대 12만8천 출력 토큰을 지원한다. 다만 큰 컨텍스트가 구독 사용량을 없애주지는 않는다. 프로젝트 파일과 누적 대화도 처리량에 포함된다. 끝난 작업을 새 세션으로 분리하면 불필요한 소모를 줄일 수 있다.

키쫀쿠라는 말의 정확한 유래는 여전히 확인되지 않는다. 반면 사용 조건은 분명하다. 모델 접근권은 플랜이 정한다. 추가 리셋의 종류와 종료 시점은 각 계정의 Usage 화면이 정한다. ‘무제한’이라는 별칭보다 그 두 화면이 더 정확한 답이다.

자주 묻는 질문

Q

Claude Opus 5.5는 무제한으로 사용할 수 있나요?

아니다. Pro와 Max 모두 5시간 세션 한도와 주간 한도가 있으며, 웹과 Claude Code 사용량이 같은 풀에서 차감된다. 출시 리셋은 한도를 한 번 채우는 혜택이지 무제한 이용권이 아니다.

Q

신규 계정을 만들면 Opus 5.5 리셋을 받을 수 있나요?

신규 계정에 반드시 지급된다는 공식 조건은 확인되지 않았다. 실제 대상 여부와 만료일은 Claude 웹 또는 Desktop의 Settings > Usage에서 확인해야 한다.

Q

Claude Code에서 Opus 5.5를 어떻게 선택하나요?

Claude Code에서 /model 메뉴를 열어 선택하거나 claude --model claude-opus-5-5로 실행한다. API를 사용할 때도 모델 ID는 claude-opus-5-5다.
