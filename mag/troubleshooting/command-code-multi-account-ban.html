Command Code 1달러 다중 계정, 밴과 환불의 실제 기준

월 1달러 Go 플랜을 여러 계정으로 늘리는 전략이 왜 약관과 제품 구조, 실제 비용 모두에서 성립하지 않는지 확인했다

2026-08-31논의 1회 정리

Command Code의 월 1달러 Go 플랜은 AI 코딩 비용을 극단적으로 낮췄다. 그러자 계정을 여러 개 돌리면 더 싸다는 계산도 따라왔다. 정말 몇 개까지는 괜찮을까? 막히면 환불은 받을 수 있을까?

Command Code는 할인 Claude Code 계정이 아니다

이름부터 갈라놓고 봐야 한다. Claude Code는 Anthropic이 운영한다. Pro·Max 구독이나 API로 접속한다. Command Code는 Langbase가 만든 별도의 코딩 에이전트다. 이 안에서 Kimi·DeepSeek·GLM·MiniMax·Qwen과 일부 폐쇄형 모델을 한 CLI로 골라 쓴다.

Anthropic의 개인용 Pro는 월 20달러다. Max 5x와 20x는 각각 월 100달러, 200달러다. 해당 구독에는 Claude Code가 포함되지만 API 비용은 별도다. Command Code의 크레딧과 Anthropic 구독 한도도 서로 공유되지 않는다.

월 1달러 Go는 10달러어치 크레딧을 준다. 공식 문서는 보통 약 1만5천 요청이라고 안내한다. 실제 횟수는 모델, 대화 길이, 캐시 사용량에 따라 달라진다. Go에는 Claude 모델이 없고 API도 열리지 않는다.

여기서 “API가 없는 서비스”라는 설명은 절반만 맞다. Command Code는 2026년 5월 Provider API를 출시했다. 현재 GOAT·Pro·Max·Team은 OpenAI와 Anthropic 호환 엔드포인트를 쓸 수 있다. 월 1달러 Go만 API 대상에서 빠진다.

계정 네 개라는 안전선은 존재하지 않는다

커뮤니티에는 많은 저가 계정이 한꺼번에 정지됐다는 경험담이 돌았다. 적은 수라면 괜찮았다는 의견도 나왔다. 두 주장 모두 공개 자료로 원인을 확인할 수 없다.

확인 가능한 기준은 더 단순하다. Command Code의 2026년 7월 약관은 한 사람이 계정 하나만 보유하도록 정한다. 추가 플랜과 크레딧을 얻거나 제한을 피하려는 다중 계정은 금지한다. 관련 계정 전체가 영구 정지될 수 있다는 문구도 있다.

따라서 네 개는 허용 구간이 아니다. 아직 탐지되지 않았다는 개인 경험도 정책이 되지 않는다. 이메일, 결제수단, 기기를 바꾼 경우도 예외로 적혀 있지 않다.

써본 사람들 사이에서는 VPN, 새 기기, 다른 네트워크가 정지 신호였다는 추측이 엇갈렸다. 정상 복구 사례도 있어 단일 원인으로 묶을 근거는 없다. 공개 약관만으로 특정 정지가 VPN 때문이었다고 단정할 수 없다.

공식 사용법은 계정 복제가 아니라 플랜 선택이다

Command Code는 Node.js 22 이상에서 설치한다. 터미널에 `npm i -g command-code@latest`를 입력한 뒤 `cmd login`으로 인증한다. 프로젝트 폴더에서 `cmd`를 실행한 뒤 `/model`로 모델을 고르면 된다. Windows에서는 짧은 명령이 `cmdc`다.

Claude Code나 Codex 설정도 가져올 수 있다. 세션에서 `/import claude` 또는 `/import codex`를 실행하면 스킬·명령·MCP 설정을 옮긴다. 입력은 기존 에이전트 설정이다. 산출물은 `.commandcode/` 아래의 프로젝트 설정과 taste 프로필이다.

개인 개발자가 API 없이 저장소 작업을 맡기려면 Go부터 시험할 수 있다. 자동화 파이프라인이나 다른 클라이언트 연결이 필요하면 GOAT 이상이 맞다. Claude 모델이 목적이라면 Command Code Pro 이상을 봐야 한다. 공식 가격표는 구독을 자사 사이트에서만 직접 판매한다고 밝힌다.

GOAT는 월 10달러에 70달러 크레딧, Pro는 월 20달러에 80달러 크레딧을 내세운다. 숫자만 비교하면 배수가 커 보인다. 그러나 모델별 허용 범위와 단가, 5시간·주간 사용 제한이 함께 적용된다. 월간 크레딧을 요청 횟수처럼 읽으면 실제 소비량을 잘못 예상하기 쉽다.

이 구분은 비용보다 중요하다. 1달러짜리 계정을 늘려도 API 권한이나 Claude 접근이 생기지 않는다. 계정마다 흩어진 기록과 크레딧은 작업 연속성도 깨뜨린다.

환불 불가 후기는 약관과 맞지만 예외가 있다

Command Code 약관은 구독, 충전, 애드온을 원칙적으로 환불하지 않는다. 미사용 기간이나 남은 크레딧도 일반 환불 대상이 아니다. 약관 위반으로 정지되면 환불하지 않는다고 명시한다.

다만 “어떤 경우에도 환불 불가”는 정확하지 않다. 적용 법률이 요구하거나 회사가 서면 승인하면 예외가 가능하다. 회사가 이용자 잘못 없이 편의상 구독을 끝내면 선납 구독의 미사용분을 일할 환불한다. 다음 갱신을 막으려면 결제일 24시간 전까지 취소해야 한다.

써본 사람들의 평가는 갈렸다. 낮은 진입가와 오픈 모델 선택 폭을 장점으로 꼽는 반응이 있었다. 반대로 크레딧 계산, 사용 제한, 지원 응답을 이해하기 어렵다는 불만도 나왔다. 개별 경험만으로 결제 오류나 서비스 하자를 확정할 수는 없다.

문서끼리 살펴볼 부분도 있다. 약관은 미사용 크레딧의 다음 기간 이월을 부정한다. 반면 가격 문서는 별도 충전 크레딧이 이월되고 만료되지 않는다고 안내한다. 포함 크레딧과 추가 구매분의 차이로 읽힌다. 그래도 결제 전 Billing 화면을 저장할 이유는 충분하다.

1달러 실험의 비용은 계정 수가 아니라 조건에서 갈린다

Go의 매력은 분명하다. 작은 저장소에서 오픈 모델을 비교해보는 비용도, CLI 작업 흐름을 익히는 비용도 낮다. 프롬프트와 코드가 기본적으로 최대 30일 보관될 수 있다는 개인정보 문서도 함께 읽어야 한다. 민감한 저장소라면 `CMD_ZDR=1 cmd`로 저장하지 않는 경로만 허용할 수 있다.

다중 계정은 그 실험을 싸게 확장하는 방법이 아니다. 약관이 금지한다. 정지 뒤 환불 가능성도 좁다. Command Code를 계속 쓸 이유는 “몇 개까지 안 걸리는가”가 아니다. 한 계정의 사용량과 필요한 모델·API를 맞춰도 대안보다 이득이 남는가에 달렸다.

자주 묻는 질문

Q

Command Code 계정은 몇 개까지 만들 수 있나?

현행 약관은 1인 1계정만 허용한다. 네 개까지 안전하다는 공식 기준은 없으며, 제한 우회용 다중 계정은 관련 계정 전체 정지 사유가 될 수 있다.

Q

Command Code 1달러 Go 플랜에서 Claude와 API를 쓸 수 있나?

Go는 오픈 모델과 일부 폐쇄형 모델을 제공하지만 Claude 모델과 Provider API는 제외한다. API는 GOAT 이상에서, Claude 모델은 Command Code Pro 이상에서 확인해야 한다.

Q

Command Code 계정이 정지되면 환불받을 수 있나?

약관 위반 정지는 원칙적으로 환불되지 않는다. 다만 적용 법률, 회사의 서면 승인, 회사 편의에 따른 무과실 종료에는 예외가 있다.
