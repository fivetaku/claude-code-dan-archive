M1 Ultra 128GB에서 M5로 갈아탈 때 따져볼 기준

저장공간 부족과 로컬 AI 발열 때문에 새 맥을 고민한다면, 세대보다 메모리 압력과 작업 시간을 먼저 비교해야 한다.

2026-09-27논의 1회 정리

M1 Ultra 128GB도 부족해졌다면 최신 맥으로 바꿔야 할까. 로컬 LLM과 대형 프로젝트를 다루는 개발자에게 답은 칩 세대만으로 나오지 않는다. 저장공간, 메모리 압력, 이동성 가운데 실제 병목이 무엇인지부터 갈라야 한다.

M6를 기다려도 맥북 프로 선택지는 아직 바뀌지 않는다

2026년 9월 현재 MacBook Pro의 최신 고성능 칩은 M5 Pro와 M5 Max다. M6는 새 Mac mini에 먼저 들어갔으며, M6 Max나 M6 Ultra 탑재 제품은 Apple이 발표하지 않았다. 발표되지 않은 제품의 출시 시기와 성능을 전제로 구매를 미룰 근거는 아직 없다.

현재 선택지는 명확하다. 이동형은 M5 Max MacBook Pro 14·16, 데스크톱은 M5 Max·M5 Ultra Mac Studio다. 국내 시작가는 M5 Max MacBook Pro 14가 579만원, 16이 629만원이다. M5 Ultra Mac Studio는 949만원부터 시작한다.

가격 차이는 단순한 세대 교체 비용이 아니다. M1 Ultra 사용자가 휴대성을 얻으려면 메모리 대역폭과 냉각 여유가 달라지고, 같은 데스크톱으로 가면 구매액이 크게 뛴다.

M1 Ultra에서 M5 Max로 가면 모든 숫자가 커지지는 않는다

2022년형 M1 Ultra는 최대 20코어 CPU, 64코어 GPU, 800GB/s 메모리 대역폭을 제공한다. 통합 메모리는 최대 128GB다. 최신 M5 Max는 18코어 CPU와 최대 40코어 GPU, 614GB/s 대역폭, 최대 128GB 메모리를 갖춘다.

M5 Max는 코어 성능과 AI 처리 구조가 발전했지만, M1 Ultra 128GB에서 옮겨도 메모리 용량은 늘지 않는다. 대형 모델을 메모리에 올리는 능력만 따지면 같은 128GB 안에서 경쟁한다. MLX 문서도 CPU와 GPU가 하나의 통합 메모리 풀을 공유한다고 설명한다.

세대 차이가 두드러지는 지점은 프롬프트 처리, 코드 빌드, 최신 GPU 기능이다. Apple은 M5 Max가 이전 세대보다 전문 작업 CPU 성능을 최대 30% 높였다고 발표했다. M5 Max는 프롬프트 처리 성능 개선을 내세운다.

M5 Ultra는 성격이 다르다. 최대 36코어 CPU, 80코어 GPU, 1.2TB/s 메모리 대역폭과 512GB 통합 메모리를 제공한다. Apple 자체 시험 기준으로 M1 Ultra보다 CPU는 최대 2.4배, GPU는 4.7배, AI 작업은 9.8배 빠르다. Tom’s Hardware의 실측도 대형 로컬 모델을 처리하는 능력을 장점으로 꼽았다.

저장공간 부족은 가장 비싼 업그레이드 신호가 아니다

M1 Ultra의 SSD가 찼다는 사실만으로 새 컴퓨터가 필요하지는 않다. 모델 가중치, Docker 이미지, 빌드 캐시, 영상 원본처럼 다시 만들거나 옮길 수 있는 파일이 공간을 차지한다면 외장 SSD로 먼저 분리할 수 있다. 현재 Mac Studio와 M5 Pro·Max MacBook Pro는 고속 외장 저장장치를 연결할 Thunderbolt 포트를 제공한다.

교체 판단은 같은 작업을 15분씩 반복해 기록하면 선명해진다. 평소 쓰는 모델과 컨텍스트를 불러오고, 코드 빌드나 내보내기를 동시에 실행한다. 활성 상태 보기에서 메모리 압력, 스왑 사용량, CPU 시간을 확인하고 작업 완료 시간을 적는다.

Apple은 메모리 압력이 녹색이면 RAM을 효율적으로 쓰는 상태라고 안내한다. 압력이 계속 노란색이나 빨간색이고 스왑이 늘어난다면 메모리가 병목이다. 반대로 압력은 녹색인데 디스크만 부족하면, M5 Max 128GB로 바꿔도 핵심 문제는 그대로 남는다.

로컬 모델의 크기도 다시 조정할 수 있다. MLX-LM은 양자화, 작은 배치, 짧은 시퀀스, KV 캐시 양자화로 메모리 사용량을 낮출 수 있다. 써본 사람들 사이에서도 가장 큰 모델보다 응답 속도가 빠른 중형 양자화 모델이 실제 코딩에 편하다는 반응이 적지 않다.

14인치와 16인치는 휴대성과 지속 부하의 교환이다

M5 Max의 칩과 최대 128GB 메모리 옵션은 두 크기 모두 같다. 차이는 본체와 전력 조건에서 드러난다. 14인치 M5 Max는 1.62kg, 72.4Wh 배터리와 96W 어댑터를 쓴다. 16인치는 2.15kg, 100Wh 배터리와 140W 어댑터를 갖춘다.

무게 차이는 530g이다. 매일 이동한다면 체감이 크지만, 장시간 LLM 추론이나 렌더링을 돌린다면 전원 환경과 소음도 함께 고려해야 한다. Apple은 두 크기의 지속 성능 차이를 수치로 공개하지 않는다.

실사용 반응도 한쪽으로 모이지 않는다. 14인치는 실제로 들고 다니기 쉬워 작업 장소가 늘었다는 평가가 있다. 반면 GPU를 오래 사용하는 작업에서는 팬 소음과 열이 빨리 느껴진다는 의견도 반복된다. 잠깐 실행하는 빌드와 장시간 추론을 같은 ‘고성능 작업’으로 묶으면 선택을 그르치기 쉽다.

팬을 강제로 돌리기 전에 병목부터 확인해야 한다

Macs Fan Control로 팬 회전수를 높이는 방법은 로컬 모델 사용자들이 공유하는 팁이다. 다만 Apple은 내장 센서와 macOS가 팬을 자동 제어한다고 설명한다. 타사 온도 앱도 하드웨어 이상을 진단하는 도구로 쓰지 말라고 안내한다.

먼저 통풍구를 막지 않고 평평한 곳에서 사용해야 한다. 불필요한 프로세스는 활성 상태 보기에서 찾고, 지원 모델에서는 macOS의 고성능 모드를 시험할 수 있다. 고성능 모드는 팬을 더 빠르게 돌려 냉각 여유를 늘리는 공식 기능이다.

구형 M1 Ultra를 중고로 추가 구매하는 방법도 남아 있다. 거래 전에는 판매자가 ‘나의 찾기’를 끄고 활성화 잠금을 해제했는지 확인해야 한다. 노트북이라면 시스템 정보에서 배터리 사이클도 직접 확인하는 편이 안전하다.

M1 Ultra 128GB에서 M5 Max 128GB로 이동할 명확한 이유는 저장공간이 아니라 시간이다. 같은 작업의 대기 시간이 수입과 출시 속도를 늦추거나, 매일 이동해야 할 때 업그레이드 가치가 생긴다. 메모리 한계가 문제라면 목적지는 M5 Max가 아니라 256GB 이상으로 구성한 M5 Ultra다.

자주 묻는 질문

Q

M1 Ultra 128GB에서 M5 Max 128GB로 바꾸면 로컬 LLM이 빨라지나요?

프롬프트 처리와 최신 런타임에서는 빨라질 수 있지만, 올릴 수 있는 모델 크기는 같은 128GB 한계에 묶인다. 현재 작업의 메모리 압력과 실제 토큰 처리 시간을 측정해 비교해야 한다.

Q

로컬 AI용 M5 Max 맥북 프로는 14인치와 16인치 중 무엇이 낫나요?

매일 이동하면 530g 가벼운 14인치가 실용적이다. 장시간 추론과 렌더링을 자주 실행한다면 더 큰 배터리와 전원 구성을 갖춘 16인치가 적합하다.

Q

M6 Max 맥북 프로를 기다리는 편이 좋을까요?

2026년 9월 현재 M6 Max나 M6 Ultra 제품은 발표되지 않았다. M6는 Mac mini에만 출시됐으므로 확인되지 않은 후속 제품보다 현재 병목과 작업 비용으로 판단하는 편이 정확하다.
