ChatGPT Plus와 클로드 Pro 코딩 한도, 질문 몇 개에 끝나는 이유와 대처법

5시간 창과 주간 한도를 두 회사가 같은 구조로 운영하는 지금, 2만 원 요금제로 코딩 에이전트를 어디까지 굴릴 수 있나

2026-09-09논의 1회 정리

월 2만 원짜리 요금제로 코딩 에이전트를 돌리면 질문 두세 개에 한도가 끝난다는 불만이 클코단에서 이어졌다. 스무 배 요금제를 쓰는 사람도 5시간 창이 순식간에 사라진다고 했다. 이 기사는 그 체감이 어디서 오는지 OpenAI와 Anthropic의 공식 문서로 확인한다. 기본 요금제로 실제 일을 굴리려면 무엇을 바꿔야 하는지도 답한다.

방에서 오간 Plus와 Pro 20x는 ChatGPT의 요금제 이름이다. 클로드 쪽은 Pro와 Max 5x, Max 20x로 나뉜다. 이름은 다르지만 두 회사가 한도를 재는 방식은 거의 같다. 한쪽에서 배운 요령 중 일부는 다른 쪽에도 통한다.

두 회사 모두 5시간 창 위에 주간 한도를 얹는다

OpenAI는 8월 25일부터 Plus 구독자의 Codex와 ChatGPT Work에 5시간 사용 한도를 다시 켰다. 9to5Mac 보도에 따르면 Codex 엔지니어링 책임자가 X에서 이를 알리며, 5시간 창이 컴퓨팅 부하를 고르게 펴서 주간 한도를 후하게 유지하게 해 준다고 설명했다. 몇 주 동안 Plus는 주간 한도만 적용받았는데, 그 기간이 끝난 것이다. 100달러와 200달러 Pro 요금제는 당분간 5시간 창이 꺼진 채 주간 한도만 적용된다.

Anthropic도 같은 구조다. 클로드 도움말은 Pro와 Max 모두 5시간마다 초기화되는 세션 한도와 계정별 고정 시각에 초기화되는 주간 한도를 함께 둔다고 밝힌다. Max 5x는 세션당 Pro의 5배, Max 20x는 20배다. 5월 6일 Anthropic은 Claude Code의 5시간 한도를 두 배로 올리고 피크 시간대 감축을 없앴다. 주간 한도는 그대로였다.

주간 한도는 곧 줄어든다. BleepingComputer에 따르면 Anthropic은 9월 14일부터 Claude Code 주간 한도를 기준선 대비 25% 올려 고정한다. 5월부터 이어진 50% 임시 상향이 함께 끝나므로 지금보다는 17% 줄어든다.

Plus에서 질문 몇 개에 끝나는 건 모델과 턴의 무게 때문이다

OpenAI는 Codex 요금 문서에서 요금제별로 5시간당 로컬 메시지 추정치를 모델별로 공개한다. Plus 기준 GPT-6 Astra는 5~45개, GPT-5.6 Sol은 10~100개, Terra는 25~200개, Luna는 250~2,000개다. Pro 5x는 이 값의 다섯 배, Pro 20x는 스무 배다. 문서는 이 숫자가 고정 한도가 아니며 모델, 작업 크기와 복잡도, 로컬인지 클라우드인지에 따라 달라진다고 못 박는다.

범위의 아래쪽을 보면 방의 불만이 이해된다. 큰 저장소를 읽고 여러 파일을 고치는 에이전트 턴은 짧은 질문보다 많은 토큰을 쓴다. Astra나 Sol을 기본으로 두고 그런 턴을 서너 번 돌리면 5시간 창은 실제로 몇 분 만에 닫힐 수 있다. 클라우드 채팅은 Sol을 쓰고 로컬보다 할당량을 더 많이 소모할 수 있다고 문서가 밝힌다. 빠른 모드는 Astra 기준 2.5배 요율이 붙는다.

써본 사람들 사이에선 Astra 프롬프트 하나가 Plus의 5시간 계량기를 비웠다는 반응이 있다. 주간 한도는 남았는데 5시간 창이 먼저 막혀 손을 놓게 된다는 불만도 나온다. OpenAI 개발자 포럼에는 GPT-5.6 계열이 나온 뒤 같은 한도로 할 수 있는 일이 줄었다는 Plus 사용자의 글이 올라왔다.

한 줄로 줄이면, 계량기는 질문 수가 아니라 토큰을 센다.

20배 요금제도 순식간이라는 후기는 어느 쪽 이야기인가

방에서 나온 스무 배 요금제 후기가 어느 회사 것인지는 정리에 남아 있지 않다. ChatGPT Pro 20x는 8월 말 기준 5시간 창이 꺼져 있어 주간 한도만 남는다. 5시간 창이 한 시간 안에 사라지는 스무 배 요금제 이야기는 지금 클로드 Max 20x 쪽에서 더 많이 나온다.

9월 1일 Claude Fable 5.1이 나왔다. VentureBeat에 따르면 API 가격은 입력 100만 토큰당 10달러, 출력 50달러로 Opus보다 훨씬 비싸다. 캐시 읽기만 75% 내렸다. 클로드 도움말은 Max 요금제에서 Fable이 주간 한도의 최대 50%까지 포함되지만 다른 모델보다 한도를 빨리 소모한다고 적는다. 그 50%는 덤이 아니라 같은 주간 풀 안의 상한이다.

써본 사람들 사이에선 Max 20x의 5시간 창이 프롬프트 하나로 한 시간 안에 비었다거나, 간단한 작업 두 개에 한도가 찼다는 반응이 여럿이다. 노력 수준을 낮추는 우회법이 함께 퍼지고 있다.

기획은 챗으로, 실행은 에이전트로 나누는 순서

방에서는 Plus 사용자라면 기획을 일반 GPT 챗에서 끝내고 에이전트는 실행에만 쓰자는 제안이 나왔다. OpenAI 도움말은 Codex, ChatGPT Work, 엑셀 에이전트가 하나의 에이전트 사용량 풀을 나눠 쓴다고 설명한다. 일반 대화는 그 목록에 없다. 설계 논의를 챗에서 하고 확정된 지시만 Codex에 넘기면 에이전트 풀에서 빠지는 턴 수가 줄어든다.

깃허브 연결도 같은 맥락이다. ChatGPT의 GitHub 앱은 저장소의 코드와 README, 문서를 읽어 질문에 답하는 읽기 전용 연결이다. 설정은 앱 메뉴에서 GitHub를 고른다. 깃허브로 넘어가 ChatGPT 앱을 설치한 뒤 접근을 허용할 저장소를 고르면 끝난다. 이 상태에서 챗에 저장소 구조와 수정 범위를 물어 계획을 굳힌다.

실행은 Codex 클라우드로 넘긴다. OpenAI 문서의 순서는 이렇다. ChatGPT 계정으로 Codex에 로그인한다. GitHub를 연결해 저장소를 고른다. 환경 설정에서 그 저장소용 환경을 만들고 의존성과 환경 변수를 넣는다. 환경을 고른 뒤 원하는 결과를 적으면 작업이 격리된 클라우드에서 돈다. 끝나면 요약과 diff를 보고 후속 수정을 시키거나 풀 리퀘스트를 연다. 클라우드 채팅은 Sol을 쓰며 로컬보다 할당량을 더 많이 소모할 수 있다는 점은 감안해야 한다.

클로드에서는 이 분리가 통하지 않는다. 클로드 도움말은 웹·데스크톱·모바일 앱과 Claude Code, IDE 확장이 모두 하나의 사용량 한도를 공유한다고 밝힌다. claude.ai에서 기획한다고 풀이 아껴지지 않는다. 대신 Claude Code의 opusplan 별칭을 쓰면 계획 모드에서는 Opus가, 실행에서는 Sonnet이 붙는다. 다만 Anthropic 블로그는 opusplan에서 계획 모드를 켜거나 끌 때마다 모델이 바뀌며 프롬프트 캐시가 깨진다고 설명한다.

페이블을 Pro에서 뺀 결정이 합리적이라는 의견의 근거

클로드 도움말에 따르면 Pro 요금제에서 Fable 5와 5.1은 요금제 한도에 포함되지 않고 처음부터 종량제 사용 크레딧으로만 돌아간다. 7월 Fable 5 전환 때는 Pro 사용자에게 일회성 크레딧이 나갔다. 5.1에는 그런 크레딧이 없다. Notebookcheck는 Pro 사용자의 선택지를 크레딧 구매, Max 업그레이드, 한도에 포함된 Opus 5 유지 세 가지로 정리했다.

방에서는 이 결정이 오히려 합리적이라는 의견이 나왔다. Max 20x의 5시간 창도 한 시간 안에 비우는 모델을 Pro 한도에 넣으면 프롬프트 한 번에 요금제가 끝난다는 논리다. 바깥에서는 2만 원을 내고도 최상위 모델을 기본으로 못 쓴다는 아쉬움이 함께 나온다. Anthropic은 7월 X 게시글에서 Fable 수요 예측이 어려워 단계적으로 열었다고 설명했다.

크레딧은 조심할 대목이 있다. 7월 Fable 5 크레딧을 받으면서 종량제가 켜진 채로 한도를 넘겨 청구된 사례가 보고됐다. 클로드 도움말은 한도 안에서만 쓰려면 API 크레딧 선택지를 거절하고 초기화를 기다리라고 안내한다. 사용 크레딧에는 월 지출 상한과 자동 충전 설정이 있으니 설정 > 사용량에서 켜져 있는지 먼저 본다.

남은 한도를 늘리는 설정과 습관

Anthropic이 8월 14일 블로그에 올린 Claude Code 절약법은 대부분 캐시를 지키는 이야기다. 모델과 노력 수준은 세션 시작 때 정한다. 모델을 중간에 바꾸면 대화 전체를 다시 채운다. 작업이 바뀌면 /clear로 비운다. 자리를 뜨기 전에 /compact로 요약해 둔다. 구독 포함량으로 쓰는 주 대화의 캐시는 기본적으로 한 시간 동안 요청이 없으면 만료되므로 그 전에 요약하는 편이 싸다.

새 세션에서 /context를 한 번 돌리면 CLAUDE.md와 MCP 도구 정의가 얼마나 실려 있는지 보인다. 안 쓰는 MCP 서버는 /mcp로 끈다. 파일은 경로를 타이핑하지 말고 @로 언급해 붙이면 읽기 호출 하나가 준다. 시끄러운 명령에는 조용한 플래그를 붙여 출력이 컨텍스트에 남지 않게 한다. 로그 뒤지기 같은 출력 많은 일은 서브에이전트에 넘긴다. 반복되는 서브에이전트는 model을 haiku로 지정한다.

노력 수준은 별도 다이얼이다. 클로드 도움말은 낮음과 중간이 사용량을 늘려 준다고 적는다. Anthropic 블로그는 높은 노력이 파일 읽기와 검증까지 포함해 턴당 토큰을 여러 배 키운다고 설명한다. Fable 5.1은 Claude Code에서 높음, 웹에서는 중간이 기본이라는 것이 Notebookcheck의 정리다. Claude Code에서 Fable을 쓴다면 /effort로 중간까지 내리는 것이 Max 사용자들 사이의 첫 번째 우회법이다. 남은 한도와 초기화 시각은 /usage로 본다.

Codex 쪽은 /status로 남은 양을 확인한다. 한도에 가까워지면 Terra나 Luna로 내려 남은 할당량을 아낀다. Plus와 Pro는 요금제를 바꾸지 않고도 크레딧을 살 수 있다. 한도에 걸린 턴은 공정 사용 범위에서 계속 진행할 수 있다.

두 회사 문서를 나란히 놓으면 방의 불만은 질문 두세 개의 문제가 아니라 무거운 에이전트 턴 두세 개의 문제였다. 9월 14일 클로드 주간 한도가 줄고 Codex에는 Astra가 들어온 지금, 기본 요금제가 코딩 요금제인지 코딩 체험이 딸린 대화 요금제인지는 각자 /usage와 /status가 답해 줄 것이다.

자주 묻는 질문

Q

ChatGPT Plus로 Codex를 쓰면 5시간에 몇 번이나 쓸 수 있나?

OpenAI 요금 문서는 Plus 기준 5시간당 로컬 메시지 추정치를 GPT-6 Astra 5~45개, GPT-5.6 Sol 10~100개, Terra 25~200개, Luna 250~2,000개로 안내한다. 고정 한도가 아니라 작업 크기와 모델, 클라우드 여부에 따라 달라지며, 8월 25일부터 5시간 창과 주간 한도가 함께 적용된다.

Q

클로드 Pro 요금제에서 Fable 5.1을 쓸 수 있나?

쓸 수는 있지만 요금제 한도에 포함되지 않는다. Pro에서는 처음부터 종량제 사용 크레딧으로만 돌아가고, Fable 5 때 있었던 일회성 크레딧도 5.1에는 없다. Max 요금제는 주간 한도의 최대 50%까지 Fable에 쓸 수 있으며 이 값은 덤이 아니라 같은 풀 안의 상한이다.

Q

Claude Code 사용량을 아끼는 가장 효과 큰 설정은 무엇인가?

세션 시작 때 /model과 /effort를 정하고 중간에 바꾸지 않는 것이다. 둘 다 프롬프트 캐시 키에 들어가 바꾸면 대화 전체를 다시 채운다. 작업이 바뀌면 /clear, 자리를 뜨기 전 /compact, 새 세션에서 /context로 불필요한 MCP 서버와 CLAUDE.md 내용을 줄이는 습관이 뒤따른다.

Q

클로드 웹에서 기획하고 Claude Code로 실행하면 한도가 절약되나?

아니다. 클로드는 웹·데스크톱·모바일 앱과 Claude Code, IDE 확장이 하나의 사용량 한도를 공유한다. ChatGPT는 Codex·Work·엑셀 에이전트가 별도의 에이전트 풀을 나눠 쓰므로 기획을 일반 챗으로 옮기는 방식이 통하지만, 클로드에서는 opusplan이나 노력 수준 조정처럼 모델과 토큰을 줄이는 쪽이 답이다.
