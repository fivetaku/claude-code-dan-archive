Fable·Mythos 5.2 출시

  • Fable 5.2와 Mythos 5.2가 출시됐다는 소식이 공유됨.

  • Fable 5.2는 유료 플랜, Claude Platform, 주요 클라우드, Claude Code에서 사용 가능하다고 함.
  • API 가격은 입력 1M 토큰당 8달러, 출력 1M 토큰당 40달러로 제시됨.

Fable 초기화권 범위

Fable 초기화권이 Fable 전용인지 Claude 전체 한도인지 질문이 나옴. 공유된 결론은 초기화권이 특정 모델 전용이 아니라 계정 전체의 Claude 한도를 다시 채우며, 5시간 세션 한도 또는 주간 한도 중 제안된 한쪽을 채우는 방식이라는 것임. 과거 Claude Duet 초기화 안내와 플랜별 횟수, 한국 계정 적용 사례가 미확인이라는 기록도 함께 언급됨. 이후 실제로 Fable 사용 한도도 함께 반환된다는 경험이 공유됨.

  • 초기화권이 Fable 전용인지 Claude 전체용인지에 대한 질문이 제기됨.
  • 공유된 결론은 계정 전체 Claude 한도를 다시 채우는 방식이라는 것임.
  • 5시간 세션 한도와 주간 한도 중 한 번에 하나가 채워지는 것으로 설명됨.
  • 과거 Claude Duet용 한도 초기화 안내와 Pro 3회, Max·Ultra 1회 정보가 언급됨.
  • 한국 계정에서의 적용 사례는 당시 미확인으로 정리됨.
  • 실제 사용 경험상 Fable이 사용한 한도도 함께 반환된다는 반응이 나옴.

  • 현재 플랜 결제 시도가 되지 않는 상황이 공유됨.
  • 이미 구독 중이면 같은 방식의 추가 구독을 할 수 없다는 설명이 있었음.
  • 업그레이드, 크레딧 구매, 이용권 선물이 대안으로 제시됨.
  • 기존 구독을 해지해야 새로 결제할 수 있다고 안내됨.
