클로드 코드 기록 복구

Claude Code 대화 내역이 사라졌을 때 복구할 방법을 질문했다. 우선 로그인 계정과 `/resume` 목록을 확인하고, 전체 프로젝트 목록에서도 없으면 세션 기록 파일 저장 여부를 점검하라는 답이 나왔다. 기본 설정에서는 30일이 지난 기록이 자동 삭제될 수 있고, 기록은 `~/.claude/projects/` 아래 JSONL 파일에 저장된다고 설명됐다. WSL·Windows·다른 계정·`CLAUDE_CONFIG_DIR` 차이로 기록 위치가 갈릴 수 있으며, 파일 자체가 없으면 복구가 어렵다는 결론이었다.

  • 먼저 현재 로그인 계정과 `/resume`에서 전체 프로젝트 목록을 확인하는 방법이 제시됐다.
  • 기본값 기준으로 30일이 지난 세션은 자동 정리될 수 있다고 언급됐다.
  • 세션 기록 파일은 프로젝트별 JSONL 형태로 저장된다고 설명됐다.
  • WSL, Windows, 사용자 계정, `CLAUDE_CONFIG_DIR` 설정에 따라 저장 위치가 달라질 수 있다.
  • 기록 파일이 남아 있으면 해당 프로젝트에서 `claude --resume`을 시도하고, 파일이 없으면 복구가 어렵다.

결혼용 캐릭터 일관성

결혼식 용도로 사진을 캐릭터화하는 작업에서 인물 비율·화풍·특징이 생성마다 달라지는 문제가 논의됐다. 단순히 특징을 나열하기보다 기준 캐릭터를 먼저 만들고, 그 베이스를 기준으로 행동·장면을 생성하도록 구성하는 방안이 제안됐다. ComfyUI 기반 레퍼런스와 오픈소스 활용, 하위 에이전트 역할 분리도 검토 대상이 됐다. 추가 결제보다 현 사용 환경에서 목표와 문제를 명확히 정의해 충분히 시도한 뒤 판단하자는 조언이 나왔다.

  • 사진 기반 캐릭터 생성에서 얼굴, 신체 비율, 화풍이 매번 달라져 일관성이 떨어지는 문제가 핵심이었다.
  • 발끝·손끝·허리·턱·어깨선 등을 정렬해도 비율이 무너지는 현상이 언급됐다.
  • 기준 캐릭터를 베이스로 정한 뒤 그 캐릭터의 행동과 장면을 생성하는 흐름이 제안됐다.
  • ComfyUI로 만든 레퍼런스 사례와 Paperclip 등 오픈소스 활용 가능성이 거론됐다.
  • GitHub 소스를 찾아 코덱스에 현재 문제를 해결할 수 있는지 분석시키는 탐색 방법도 공유됐다.

  • 오래 닫아 둔 대화를 재개해도 캐시 미스 페널티가 없을 수 있다는 점이 핵심이다.
