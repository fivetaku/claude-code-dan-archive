엑셀 자동화 배포 조언

고객주문내역을 엑셀로 자동 옮기는 프로그램을 만든 사람에게 pyinstaller로 exe 패키징하는 구체적 프롬프트가 공유됐다. 경로 하드코딩 대신 %APPDATA% 사용, 실행 후 즉시 안 닫히게 하기, UI에서 파일 선택 가능하게 하기가 핵심 요구사항으로 제시됐다. PyQt6로 UI를 그리고 파이썬 없는 환경에서도 돌아가게 만들라는 추가 팁도 나왔고, 원샷으로 끝내려 하지 말고 UI를 직접 뜯어보며 수정하라는 조언이 붙었다.

  • pyinstaller로 윈도우 어디서든 실행되는 exe 만들기
  • 경로는 %APPDATA% 같은 상대경로로 하드코딩 금지
  • PyQt6로 UI 구성 + 엑셀 파일 선택 기능 필요
  • 원샷 요청보다 UI 보면서 단계별로 뜯어보라는 조언
