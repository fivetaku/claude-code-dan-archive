Claude 장애와 복구

Claude Fable, Sonnet, Haiku에서 심각한 오류가 발생했다가 복구되는 상태 알림이 공유됐다. 복구 직후에도 일시적 과부하와 529 오류를 겪었다는 이용자 보고가 나왔고, 이어 Opus 오류도 별도로 발생했다가 복구됐다. Claude 웹·API·Claude Code·Claude Cowork 전반이 영향 대상이었으며, API 호출로 서비스가 멈출 때는 응답 오류 확인, 타임아웃과 재시도 설정, 요청 폭주 여부 점검이 기본 대응으로 언급됐다.

  • Claude Fable·Sonnet·Haiku 오류가 조사, 원인 확인, 복구 관찰을 거쳐 복구 완료로 전환됐다.
  • 복구 공지 뒤에도 일부 사용자는 temporarily overloaded 및 529 과부하 오류를 경험했다.
  • Opus에서도 별도 오류가 발생했지만 약 6분 뒤 복구 완료 공지가 나왔다.
  • 영향 범위는 claude.ai, Claude API, Claude Code, Claude Cowork로 안내됐다.
  • 외부 API 지연·오류에 대비해 타임아웃, 재시도, 요청량을 점검하라는 운영 팁이 나왔다.
