RAG·벡터DB 기초

벡터DB, RAG, 시맨틱 서치, 엘라스틱서치의 차이와 관계를 짧게 정리했다. 벡터DB는 임베딩 벡터와 메타데이터를 저장하고 유사도 검색에 쓰며, RAG는 검색한 문서 조각을 LLM 입력에 붙이는 구조라고 설명했다. 의미적 가까움은 문자열 유사도가 아니라 임베딩 모델이 만들며, 코사인 유사도·내적·유클리드 거리는 비교 방식이고 HNSW는 검색 가속용 인덱스라는 구분이 나왔다. 청크 크기를 토큰 단위로 조절하는 것이 인덱싱 효율 개선의 시작점이라는 팁도 제시됐다.

  • 벡터DB는 의미 기반 유사도 검색에 특화된 저장·검색 계열이다.
  • RAG는 검색 결과를 LLM 컨텍스트에 추가해 답변 근거로 쓰는 패턴이다.
  • 시맨틱 서치는 단어 일치보다 의미적 유사성을 중심으로 찾는다.
  • 엘라스틱서치는 역색인 기반 키워드 검색이 중심이며 벡터 검색도 지원할 수 있다.
  • 임베딩·거리 계산·근사 최근접 이웃 인덱스는 각각 의미 표현, 비교, 속도 최적화 역할을 맡는다.

옵시디언과 그래프

옵시디언의 노트 연결 방식과 벡터DB·RAG를 비교했다. 옵시디언은 로컬 마크다운 파일과 위키링크를 바탕으로 사람이 명시한 관계를 그래프로 보여주며, 벡터DB는 링크가 없어도 임베딩 의미가 가까운 문서를 찾는다는 차이가 정리됐다. 그래프 뷰는 노드·엣지가 늘수록 force-directed 레이아웃 계산과 렌더링 비용 때문에 무거워질 수 있다. 대규모 볼트에서는 필터, 로컬 그래프, 고립 노드 숨김을 쓰고 실제 탐색은 검색 중심으로 하는 것이 권장됐다.

  • 옵시디언은 노트를 로컬 마크다운 파일로 저장하고 위키링크로 연결한다.
  • 그래프의 연결은 기본적으로 명시적 링크에서 생기며 임베딩 기반 자동 관계와는 다르다.
  • 옵시디언 볼트를 청크로 분할·임베딩해 RAG의 지식 원본으로 활용할 수 있다.
  • 대규모 전체 그래프는 시각화 부하가 커질 수 있어 필터와 로컬 그래프가 유용하다.
  • 파일 인덱싱보다 전체 그래프 레이아웃·렌더링이 체감 성능 병목이 되기 쉽다.

GTX 1070 Ti 모델

GTX 1070 Ti 8GB VRAM에서 구동 가능한 로컬 모델을 질문했다. 8GB VRAM에서는 Q4 양자화 기준 7~8B급 소형 모델이 현실적이라는 답이 나왔다. 시스템 RAM은 64GB 정도로 넉넉하지만 GPU 메모리가 병목이라는 점도 확인했다. GPU RAM이라는 표현을 VRAM으로 바로잡았다.

  • 8GB VRAM 환경에서는 7~8B급 양자화 모델이 주된 선택지로 언급됐다.
  • Q4 양자화는 제한된 VRAM에 모델을 올리는 방법으로 제시됐다.
  • 시스템 RAM이 커도 GPU 추론에서는 VRAM 용량이 핵심 제약이 될 수 있다.
  • GPU 메모리의 일반적인 용어는 VRAM이다.

구글 앱 연결 중복

  • 하나의 서비스도 웹과 모바일에서 별도 OAuth 연결로 표시될 수 있다.

웹 코드 참고 방법

참고할 홈페이지의 코드 구조를 확인하는 방법을 질문했다. 크롬 개발자도구를 열고 요소 선택기로 원하는 UI를 찍어 Elements 패널에서 HTML을 확인하는 기본 절차가 안내됐다. 단축키로 DevTools와 요소 선택기를 여는 방법, 선택 요소에서 복사 메뉴를 쓰는 방법이 언급됐다. 답변 일부가 끊겨 CSS 확인 이후의 과정은 완결되지 않았다.

  • Windows에서는 F12 또는 Ctrl+Shift+I, macOS에서는 Cmd+Option+I로 개발자도구를 열 수 있다.
  • 요소 선택기는 Windows Ctrl+Shift+C, macOS Cmd+Option+C로 실행할 수 있다.
  • 페이지에서 원하는 요소를 클릭하면 해당 HTML 구조를 Elements 패널에서 확인할 수 있다.
  • 참고 디자인을 구현할 때는 구조를 학습하되 원본 코드·자산의 무단 복제와 라이선스 문제를 주의해야 한다.

SSD 구매 추천

삼성·하이닉스 병행수입 SSD 추천을 요청했다. 일반 작업과 게임에는 PCIe 4.0 기반 삼성 990 PRO 또는 하이닉스 Platinum P41급이 무난하다는 의견이 나왔고, PCIe 5.0은 가격과 발열 때문에 특별한 필요가 없으면 우선순위가 낮다고 했다. 병행수입은 가격 이점 대신 국내 A/S와 판매처 보증 조건을 반드시 확인해야 한다는 조언이 나왔다. 용량은 가격 차이가 크지 않다면 2TB를 우선 고려하라고 제안했다.
