쉬운 설명 스킬

Claude Code 답변의 어려운 용어와 문장을 쉽게 풀어 주는 방법을 논의했다. CLAUDE.md에 전문용어 풀이, 비유, 짧은 문장 같은 규칙을 넣는 방안과 설명형 출력 스타일, 커스텀 스킬·슬래시 명령 사용이 제안됐다. i-have-adhd 계열 스킬과 ELI5가 대안으로 언급됐고, 실제 사용자가 i-have-adhd가 좋다고 평가했다. 프록시에서 입력 토큰을 최적화하고 답변을 간결하게 만드는 도구·스킬의 존재도 함께 회상됐다.

  • CLAUDE.md에 쉬운 용어 풀이와 짧은 문장 규칙을 상시 설정하는 방법이 제안됐다.
  • 설명형 출력 스타일은 버전에 따라 이름과 위치가 달라질 수 있다고 언급됐다.
  • 필요할 때만 적용하려면 커스텀 스킬이나 슬래시 명령으로 분리할 수 있다.
  • i-have-adhd 저장소가 공유됐고 실제 사용 후기가 긍정적이었다.
  • ELI5는 초보자가 시작하기 좋은 방식으로 언급됐다.
  • https://github.com/ayghri/i-have-adhd

윈도우 CLI 호출 오류

윈도우 데스크톱 앱이 설치한 실행 파일을 CLI처럼 호출할 때 api_error가 발생하는 문제를 다뤘다. 최신 exe를 자동 탐색하고 여러 요청을 묶어 하이쿠에 보내며 실패 사유를 반환하는 파이썬 코드가 공유됐다. 앱 내부용 exe를 CLI 용도로 쓰는 방식은 업데이트에 취약할 수 있고, exe 미발견을 명시 처리해야 한다는 의견이 나왔다. 매 발화 전 처리라면 90초 타임아웃은 지나치게 길며, 짧게 실패 처리하고 원래 흐름으로 복귀하는 설계가 권장됐다.

  • 앱이 포함한 claude.exe 호출 시 api_error가 발생했다고 했다.
  • 실행 파일의 최신 경로 탐색, 배치 요청, 실패 사유 반환 구조를 검토했다.
  • cli()가 실행 파일을 찾지 못한 경우를 별도로 처리하는 편이 낫다는 지적이 나왔다.
  • 앱 전용 실행 파일을 비공식 CLI로 쓰는 구조는 업데이트에 따라 깨질 수 있다.
  • 라우팅 전단의 짧은 처리에는 긴 타임아웃보다 빠른 폴백이 적합하다는 의견이 제시됐다.

JEV와 하이쿠 라우팅

매 발화마다 라우팅이나 스킬 실행 전 짧은 판단 단계를 넣기 위해 하이쿠 CLI 사용을 검토했다. 로컬 환경에서는 프로세스 기동만 약 1.9초가 걸리고, 이 단계가 라우터 전단이라 비동기 처리도 어렵다는 제약이 나왔다. JEV는 TypeSafe AI의 System One 모델로, 텍스트 대신 타입이 지정된 확률적 결정을 반환해 자동화와 AI 에이전트 검증에 쓰는 도구로 소개됐다. 기본 판단은 가벼운 결정 모델·규칙으로 처리하고 애매한 경우만 하이쿠로 넘기는 하이브리드 방향이 논의됐지만, 상시 프로세스 대기와 직접 API 호출의 실현 조건은 추가 검토가 필요하다.

  • 하이쿠를 매 발화 전 라우팅 판단에 넣는 방안을 검토했다.
  • PC 환경에서 CLI 기동 시간만 약 1.9초라고 했다.
  • 프로세스 재사용과 API 직접 호출은 기동 비용을 줄이는 방안으로 언급됐다.
  • 라우터 앞단이라 결과를 나중에 반영하는 비동기 방식은 어렵다는 제약이 제시됐다.
  • JEV는 타입 지정 확률적 결정을 반환하는 System One 모델로 공유됐다.

Kordoc 문서 처리

Kordoc의 출력 품질이 괜찮다는 반응과 함께 용도를 묻는 질문이 나왔다. Kordoc은 HWP·PDF·오피스 문서·이미지를 파싱·비교·생성하고, Claude Code 같은 AI 에이전트에 MCP나 플러그인으로 연결하는 문서 처리 도구다. 대화에서는 HWP/HWPX·PDF·Office 문서·이미지를 Markdown 또는 구조화 데이터로 바꾸고 OCR, 양식 채우기, 문서 비교, HWPX 생성을 지원한다는 설명도 공유됐다. 이후 용도 질문에는 근거를 확인하지 못했다며 답변이 중단돼, 에이전트 연계 문서 자동화라는 핵심 활용처가 충분히 이어지지는 않았다.

  • Kordoc의 문서 처리 품질에 대한 긍정적 반응이 나왔다.
  • HWP, PDF, Office 문서, 이미지의 파싱·비교·생성을 지원한다.
  • 문서를 Markdown이나 구조화 데이터로 변환하고 OCR 및 양식 채우기를 지원한다.
  • Claude Code 등 AI 에이전트에 MCP·플러그인으로 연결할 수 있다.
  • 문서 비교와 HWPX 생성 기능이 언급됐다.

  • 상단안은 태아·완두콩 콘셉트가 눈에 잘 띈다는 평가를 받았다.
  • 하단안은 더 귀엽고 아기용 앱 같은 인상이라는 의견이 나왔다.
  • 상단안은 자동차보험 캐릭터 같은 익숙한 인상을 준다는 반응도 있었다.
  • 배경 제거, 하트 요소, 니트 인형 질감 등 후속 변형을 검토했다.

  • Capsomnia는 Caps Lock으로 잠자기 방지를 전환하는 macOS 앱이다.
