GPT 리셋권과 소진율

지피티 사용량 리셋권이 지급되자 반응이 갈렸다. 리셋권을 주는 대신 앞으로 사용량이 더 빨리 닳게 한 것 아니냐는 의견이 나왔고, 아스트라 6.2는 기존 대비 40%, 솔은 25% 더 빨리 소진된다는 내용이 공유됐다. 오류 덕에 유저가 이득을 본 상황이라 리셋권은 안 줘도 되는 것 아니냐는 시각도 있었다. 6.2는 별로라는 사람과 나름 괜찮아졌다는 사람이 있었고, 소진율이 그 정도면 다시 생각해 봐야겠다는 반응이 나왔다. 가격 인상 글 아니냐는 반응도 있었다.

  • 아스트라 6.2는 Codex에서 시험 중인 것으로 보이는 GPT-6.2 계열 모델이며 공식 발표는 확인되지 않았다.
  • 솔(GPT-5.6 Sol)은 OpenAI 모델로, 프록시나 공식 Codex 플러그인을 통해 Claude Code 안에서 구동할 수 있다.
  • 소진 속도는 아스트라 6.2가 40%, 솔이 25% 더 빠르다는 내용이 공유됐다.
  • 40%면 반토막 수준이라는 반응과, 6.2가 나름 좋아졌지만 25~40% 더 쓰면 재고가 필요하다는 반응이 있었다.
  • 신모델이 언제 나오나 기다려진다는 이야기도 나왔다.

피클 vs vooy 비교

개인 AI 에이전트 앱 피클과 vooy의 차이를 두고 질문이 이어졌다. 피클은 미국 Pickle, Inc.가 만든 앱으로 전화 걸기, 예약·주문, 지메일·캘린더 연동을 하고 돈 쓰기 전 승인을 받으며 가입에 초대 링크가 필요하다고 한다. vooy는 서울 강남 팀이 만든 아시아 사용자용 메신저 에이전트로 예약·이동·쇼핑·행정을 한 문장으로 시키는 방식이며, 운영 법인 이름은 확인되지 않았다. 국내 사용자 수나 앱 순위 같은 비교 지표는 검색이 막혀 확인하지 못했고, 초대권 방식 차이로 피클이 더 많을 거라는 건 추측이다.

  • 피클과 비교되는 서비스로 Grok Bot, 메타 Muse, OpenAI Dots(클라우드 PC 비서), 인스팅트가 소개됐다.
  • 방에서 인스팅트는 앱 없이 문자나 아이메시지로 시키는 방식이며 한국 공식 지원 여부는 안 밝혀졌다고 소개됐다.
  • 별도 확인 자료의 인스팅트(Claude Code 확장 프로젝트)와 같은 대상인지는 불분명하다.
  • vooy는 한국·일본·태국·대만·싱가포르·UAE 확장을 내세우며, 친구 에이전트끼리 약속을 잡는 기능은 두 앱 모두 방향이 비슷하다.
  • 가격과 실제 성능 차이, 한국 가입자 수는 미확인이다. 비교하려면 앱스토어 순위, 다운로드 추정치, 회사 발표를 봐야 한다.
  • datapopcorn.ai/blog/pickle-ai-agent-guide

CLI 로그인 자꾸 풀림

우분투 SSH 환경에서 CLI 로그인이 재접속할 때 풀리기도 하고 안 풀리기도 하는데, 오류 문구는 없다는 증상이 논의됐다. 같은 증상의 원인은 검색으로 확인하지 못했고, 비슷한 사례로 OAuth 성공 직후 계정이 'ineligible'로 처리됐다는 보고만 있었다. 토큰 저장소(keyring)나 접속마다 달라지는 환경이 원인일 수 있다는 추측이 나왔지만 확정된 것은 아니다. 로그인이 풀렸을 때 다른 SSH 창이 열려 있었는지, 접속 방식이 같았는지 비교해 보라는 안내로 마무리됐다.

  • 헤드리스 SSH 우분투는 데스크톱 keyring이 안 떠 있어 토큰 저장이 불안정할 수 있다는 일반론이 제시됐다.
  • 접속마다 dbus·keyring 세션이 떠 있는지가 달라질 가능성이 언급됐다.
  • 여러 SSH 세션을 동시에 쓰면 토큰 갱신이 서로 덮어쓸 수 있다는 가설이 나왔다.
  • 계정 쪽에서 세션을 끊는 경우는 서버 쪽 일이라 로컬에서 확인하기 어렵다고 했다.
  • 이 CLI의 실제 토큰 저장 방식은 확인하지 못했다.
