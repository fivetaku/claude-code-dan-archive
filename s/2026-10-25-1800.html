  • Claude 서비스 전반에 큰 영향의 오류가 보고됐다.
  • 상태는 조사 중, 원인 확인, 복구 관찰 순으로 갱신됐다.
  • 특정 모델군의 오류로 공지가 구체화됐다.
  • 최종적으로 공식 복구 완료가 안내됐다.

Claude 데이터 절약법

Claude 사용량을 효율적으로 아끼는 방법으로 컨텍스트를 줄이는 원칙이 정리됐다. 대화가 길어지면 새 세션으로 전환하고, 요청을 구체화하며, 관련 파일만 제공하라는 팁이 제시됐다. 단순 작업은 가벼운 모델에 맡기고 규칙 파일을 짧게 유지하는 것도 권장됐다.

  • 긴 세션은 매 턴 이전 내용을 다시 읽어 사용량을 빠르게 소모할 수 있다.
  • 요청을 한 번에 구체적으로 작성해 반복 질의를 줄이는 것이 좋다.
  • 레포 전체 대신 작업에 필요한 파일과 부분만 제공해야 한다.

  • 매 세션에서 읽히는 규칙 파일은 짧게 유지하는 것이 유리하다.

Claude 반복 장애

Claude 웹, API, Claude Code, Cowork에서 일부 장애와 오류 증가가 다시 발생했다. Sonnet 계열 및 다른 모델, 이후 Fable 5.1 관련 오류로 공지가 갱신됐으며 조사·원인 확인·복구 관찰 단계를 거쳤다. 두 차례 모두 공식 복구 완료가 안내됐고, 사용자들은 장애 상황이면 사용 한도 리셋을 제공해 달라는 반응을 보였다.

  • Claude 서비스 전반이 정상 운영에서 일부 장애 상태로 변경됐다.
  • Sonnet 계열 모델의 높은 오류율이 공지됐다.
  • 한 차례 복구 뒤 Fable 5.1 관련 오류가 추가로 발생했다.
  • 각 장애는 원인 확인과 복구 관찰을 거쳐 복구 완료로 안내됐다.
  • 사용자들은 장애에 따른 사용량 보상을 기대하는 반응을 보였다.

미니PC·맥미니 선택

오픈클로·헤르메스 상시 구동용으로 N100 미니PC를 맞추려다 32GB 램 가격 부담 때문에 맥미니까지 비교하는 대화가 나왔다. 맥에서는 TTS·RAG 라벨링·간단한 이미지 생성용 로컬 모델을 돌릴 수 있을지, 리눅스·윈도우 대비 단점이 무엇인지가 질문이었다. 중고 DDR4 기반 N100 미니PC는 저렴하게 구할 수 있다는 의견과, 하드웨어 구매 전 구체적 사용 목적부터 정하라는 조언이 제시됐다. 입문 단계라면 미니PC 대신 VPS와 Dots를 고려하라는 제안도 나왔다.

  • N100과 32GB 메모리 구성 비용이 예상보다 높아 맥미니를 대안으로 검토했다.
  • 맥미니에서는 로컬 TTS, RAG 라벨링, 간단한 이미지 생성 등을 기대했다.
  • DDR4 중고 부품 및 중고 N100 미니PC를 활용하면 비용을 낮출 수 있다는 의견이 나왔다.
  • AI 비서 목적만으로 고가 장비를 먼저 구매하기보다 할 일을 정의하라는 조언이 핵심이었다.
  • VPS와 Dots를 이용한 입문 경로도 제안됐다.

로컬 LLM GPU 구성

로컬 모델 구동용 GPU로 5060 Ti 16GB, 5090, 라데온 기반 듀얼 GPU, 메모리 증설 조합 등이 논의됐다. 5060 Ti는 8GB보다 16GB 모델을 골라야 코딩용 로컬 모델에 유리하며, 모델 크기를 먼저 정하고 구매하라는 조언이 나왔다. Qwen 계열 27B 모델을 Q6로 라데온에서 구동 중인 사례와 더 큰 모델 구동 사양에 대한 관심도 공유됐다. 로컬 AI 하드웨어 비교 사이트도 소개됐다.

  • 5060 Ti 구매 시 8GB와 16GB VRAM 구성을 구분해야 한다는 조언이 나왔다.
  • 로컬 코딩 모델 용도라면 16GB VRAM이 더 적합하다고 언급됐다.
  • 상위 GPU는 성능이 좋지만 비용 부담이 큰 선택지로 거론됐다.
  • 라데온 GPU에서 Qwen 계열 27B Q6 모델을 구동한 사례가 공유됐다.
  • 로컬 AI 구성 비교를 위해 canirun.ai 링크가 소개됐다.
  • https://www.canirun.ai/

테더링 연결·데이터

테더링 연결이 불안정한 원인으로 핫스팟 자동 해제, 절전·배터리 최적화, 5GHz 연결 문제가 논의됐다. 자동 해제를 끄고 절전 설정을 해제하며 2.4GHz로 바꿔보라는 점검 순서가 제안됐다. 이후 실제로는 모바일 데이터가 소진된 것 같다는 반응이 나왔고, 테더링의 높은 데이터 사용량과 월말 요금제 문제가 언급됐다.

  • 테더링에서 연결 상태는 남지만 실제 통신이 되지 않는 현상이 논의됐다.
