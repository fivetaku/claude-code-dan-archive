Codex Desktop 멀티모델 커스텀 성공

한 참여자가 Codex Desktop 네이티브 앱에서 Fable 5.1, Grok 등 다른 모델을 선택해 쓸 수 있게 만들었다고 공유해 큰 반응을 얻었다. Astra에게 '데스크탑에서 fable, grok 모델 선택하고 실제 네이티브 느낌으로 쓸 수 있게 해줘'라고만 시켰더니 앱 재시작만으로 구현됐다는 설명이었다. 이는 이미 알려진 오픈소스 도구 오픈코덱스와 유사한 결과물이라는 지적이 나왔고, 오픈코덱스 깃허브 링크가 공유됐다. 클라우드 원격세션까지 무료로 딸려온다는 장점도 언급됐다.

  • Astra에게 요청만으로 Codex Desktop에서 Fable/Grok 모델 선택 기능 구현
  • 구현 방식은 앱 종료 후 재시작이 전부였다고 설명
  • 오픈소스 도구 오픈코덱스와 유사한 결과물이라는 지적
  • 클라우드 원격세션까지 무료로 활용 가능하다는 장점 언급
  • 컨텍스트 윈도우 피팅과 오토 컴팩션 임계값 조절 작업 진행 중
  • https://github.com/lidge-jun/opencodex/blob/main/readme/README.ko.md

Aside vs Ego Lite 비교 논의

브라우저 자동화 에이전트 Aside와 Ego Lite를 놓고 어느 쪽이 나은지 의견이 오갔다. 메인 에이전트 보조용으로는 Ego Lite, 윈도우 e2e 테스트 안정성 면에서는 Aside가 낫다는 결론이 나왔다. 한편 Hermes+Aside CLI+Astra 조합을 쓰는 사람은 '모든 게 가능하다'며 만족감을 표했다.

  • Aside와 Ego Lite 실사용 비교
  • 메인 에이전트 보조용으로는 Ego Lite 추천 의견
  • 윈도우 e2e 테스트 안정성은 Aside가 낫다는 의견
  • Hermes+Aside CLI+Astra 조합 사용 후기 '감탄중'

AI 사용량 위젯 만들기 논의

클로드·코덱스 사용량을 폰 홈 화면 위젯으로 보고 싶다는 질문에서 시작해 안드로이드는 위젯 단독 설치가 어렵고 앱을 만들어야 한다는 답이 나왔다. PWA로 구축 후 세션 훅에 걸어 Cloudflare로 무료 서빙하는 방법, Tailscale로 보안을 처리하는 방법 등이 제안됐고, 결국 굳이 필요한가 하는 반응도 있었다. 회사 보안 정책 때문에 원격 접속이 번거롭다는 하소연으로 마무리됐다.

  • 안드로이드는 위젯 단독 설치가 어려워 앱 제작이 필요함
  • PWA + Cloudflare 무료 서빙 + 세션 훅 갱신 방식 제안
  • 로컬 서버는 해킹 위험 때문에 비추천, Tailscale로 보안 강화 대안 제시
  • 실사용 빈도 대비 과한 구축이라는 반응도 있었음
  • 회사 보안 정책으로 원격 접속이 번거롭다는 불만

뉴스 크롤링·번역 파이프라인 최적화

GPT 플러스로 해외/국내 뉴스를 크롤링해 요약·번역하는 작업에서 토큰 부족 문제로 무료 API 대안을 찾는 질문이 나왔다. 램 8기가 서버라 로컬 모델은 무리라는 판단 하에, 번역은 DeepL API Free나 Google Cloud Translate 같은 무료 번역 API를 여러 개 fallback으로 묶어 쓰는 방안이 제안됐다. 요약은 품질이 중요하니 별도 모델에 맡기고 번역만 분리하는 게 낫다는 결론으로 정리됐다.

  • 램 8기가 서버 환경으로 로컬 AI 모델 사용은 비추천
  • DeepL API Free, Google Cloud Translate 등 무료 번역 API를 fallback으로 묶어 사용 제안
  • 무료 API 2개 조합시 월 100만자까지 번역 커버 가능
  • 요약은 품질이 중요하므로 별도로 최적화, 번역만 분리 처리
  • 현재는 Grok 무료 한도(1분당 1회)로 50개 기사를 50분에 걸쳐 처리 중
