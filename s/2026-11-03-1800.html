에이전트 오케스트레이션

세션을 트리로 구성하고 단계마다 요약을 전달하며 발주 카드와 훅으로 누락을 막는 오케스트레이션 하네스가 공유됨. 결과 판정은 PASS·WARN·UNDECIDABLE로 제한하고 Codex에는 러너 스크립트로 여섯 역할을 배차하는 구상이나, 핵심 코드가 빠져 있고 적용 시험 전이라 그대로 설치할 수는 없음. 레이어와 훅이 지나치게 많고 토큰 소모가 크지 않은지 점검하자는 의견이 나왔으며, 키워드 트리거 대신 의미 기반으로 스킬을 연결하는 gptaku-core도 참고 대상으로 제안됨. 구조를 늘리기보다 실행과 로그 분석을 반복하고, 서브에이전트가 필요한 작업인지 단순 병렬 세션으로 충분한지 따져보라는 조언이 이어짐. 직접 지정한 스킬도 Claude Code가 불필요하다고 판단해 거부하는 사례와 기존 실행이 약 20시간 걸렸던 경험도 공유됨.

  • 세션 트리는 뿌리·기둥·가지·일꾼으로 구성하며 각 단계에서 요약 한 장을 넘기는 방식임.
  • 10칸 발주 카드와 관문 훅으로 누락을 막고 결과는 세 가지 상태로 판정하는 구상임.
  • 훅·러너·기억 엔진 코드가 빠져 있고 실전 적용 시험도 끝나지 않아 즉시 설치할 수 없음.
  • gptaku-core의 의미 기반 스킬 라우팅을 살펴보고 기존 구조와 비교하거나 이식할 아이디어를 얻자는 제안이 나옴.
  • 과도한 훅과 토큰 사용량, 스킬 호출 거부 이유를 실제 대화와 실행 로그로 분석할 필요가 제기됨.

윤문 모델 맞히기

윤문 결과를 보고 작성 모델을 맞히는 실험 링크가 공유돼 여러 사람이 참여함. 정답 수는 0개부터 한 주제에서 5개까지 다양했고, AI가 쓴 느낌은 나더라도 어느 모델인지 구별하기 어렵다는 반응이 많았음. 사람 같은 글을 Opus나 Gemini로 골랐다는 의견, 문장이 짧으면 GPT 같고 문체가 좋으면 Claude 같다는 개인적인 추측이 나왔으나 참가자마다 판단이 달랐음. 평소 쓰는 GPT의 문체와 실험 결과가 다르다는 반응과 개인적으로 윤문 프롬프트를 다듬고 있다는 경험도 공유됨.

  • 윤문 결과의 모델을 추측하는 실험에 여러 참여자가 점수를 공유함.
  • 한 참여자는 첫 번째 주제에서 2개, 두 번째 주제에서 5개를 맞혔다고 밝힘.
  • 모델별 문장 길이와 문체를 단서로 삼았지만 개인별 인상과 추측이 엇갈림.
  • AI가 작성한 듯한 특징과 정돈된 기승전결이 느껴져도 모델을 식별하기는 어렵다는 의견이 나옴.
  • 일부 참여자는 평소 사용 중인 모델의 글쓰기 결과와 실험 속 문체가 다르다고 느낌.
  • https://vote.axwith.com/

피클 작업 자동화

피클에 매일 쇼핑몰 리뷰 작성과 이벤트 응모를 시킨 뒤 체험단에 선정됐다는 경험이 공유됨. 매일 커피나 기프티콘 이벤트 세 건에 응모하라는 식의 자연어 지시를 사용했으며, 다른 참여자는 항공권과 숙박권 이벤트에도 에이전트를 활용한다고 소개함. AI가 만든 리뷰가 늘어나는 상황을 두고 죽은 인터넷 이론과 오프라인 활동의 가치에 대한 우려도 나옴. Aside로도 비슷한 작업을 할 수 있는지 비교하면서 피클은 리눅스 기반으로 웹사이트에 접속한다는 사용자 관찰이 공유됐고, 로그인과 작업 속도가 느려 틈틈이 맡기는 편이 낫다는 의견이 이어짐.

  • 매일 리뷰를 작성하고 가능한 한 이벤트에 응모하도록 맡긴 사용자가 체험단 선정 경험을 소개함.
  • 선정 후 제시된 상품이 기대했던 고가 제품과는 달랐다는 후기도 공유됨.
  • 항공권이나 숙박권 응모처럼 반복적이고 번거로운 작업에 AI 에이전트를 활용하는 사례가 추가됨.
  • AI 생성 리뷰의 확산과 사람이 줄어드는 온라인 환경에 대한 우려가 제기됨.
  • Aside와의 편의성 차이 및 피클의 느린 로그인·작업 속도가 논의됨.

  • 여러 참여자가 같은 날 Codex 사용 중 이상 동작을 겪었다고 보고함.
  • 일부는 오전에 나타난 문제가 오후에 사라지거나 간헐적으로만 발생했다고 말함.
  • Sol High 사용 중 유사한 현상이 자주 나타난다는 경험이 공유됨.
  • Gemini API 서버 과부하 경험도 언급됐지만 Codex 문제와의 관련성은 확인되지 않음.
  • 리셋이 언급됐으나 문제 해결 여부와 근본 원인은 확인되지 않음.
