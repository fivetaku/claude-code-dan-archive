Claude Code 과검증

Claude Code가 최근 검증과 테스트를 과도하게 수행해 토큰 소모와 주간 한도 사용량이 늘었다는 경험이 공유됐다. 테스트·조사를 여러 서브에이전트로 돌리고 전체 테스트를 반복하는 사례가 나왔으며, 간단한 안드로이드 UI 수정에도 26분이 소요됐다고 했다. 원인은 단정하기 어렵고, 과하다 싶으면 사이드 대화에서 검증의 필요성과 구조를 재질문해 보라는 의견이 나왔다. 사용자는 이후 Claude.md에 검증 원칙을 추가했다고 밝혔다.

  • 동일한 사용 패턴인데 Claude Code 주간 한도 소모가 크게 늘었다는 체감이 제기됐다.
  • 테스트·조사를 서브에이전트 3~4개로 수행하는 사례가 언급됐다.
  • 안드로이드 앱 UI·글자색·팝업 수정에서 전체 테스트를 세 차례 실행한 사례가 나왔다.
  • 모델의 반응을 그대로 믿기보다 검증 필요성과 작업 구조를 재질문하라는 팁이 제시됐다.
  • 검증 범위를 제어하기 위해 Claude.md에 원칙을 추가한 사례가 공유됐다.

  • Antigravity 연동 사용 사례가 언급됐다.
  • IDE 없이 Claude Code를 쓰는 방식도 가능하다는 사례가 나왔다.
  • 터미널과 데스크톱 앱을 작업별로 병행하라는 팁이 제시됐다.
  • Antigravity·Cursor 등 IDE는 크게 구분하기보다 편한 도구를 쓰라는 의견이 나왔다.

  • 24GB RAM 증설 후 체감 성능 향상 경험이 공유됐다.
  • 영상 제작 외에 고메모리를 요구하는 코딩 작업이 무엇인지 질문했다.
  • 고사양 VPS와 무제한 대역폭 전용 서버를 대안으로 검토했다.
