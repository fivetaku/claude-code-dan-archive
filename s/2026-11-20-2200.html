  • 클로드의 한국어 표현이 어렵게 느껴져 제미나이로 윤문한다는 사례가 나왔다.

  • 항공정비 언어 방식으로 답하도록 지시하는 방법이 문체 개선 팁으로 공유됐다.
  • 보고서를 HTML로만 받도록 한다는 설정도 언급됐다.
  • 모델별 결과 비교 이미지와 관련 원문이 공유됐으나 이미지 내용은 텍스트로 확인되지 않는다.

맥 장비와 로컬 LLM

맥북 관련 농담에서 시작해 고메모리 맥 장비를 유지하거나 판매할지, 추가 장비를 살지 논의했다. 한쪽은 로컬 LLM보다 작업·빌드·CI·서비스용 컴퓨팅이 목적이라 맥 한 대를 팔고 스레드리퍼 서버를 구성하는 방안을 고민했다. 다른 쪽은 내부 로컬 LLM과 업무·서버 수요 때문에 더 큰 메모리와 엔비디아 장비를 고려했다. 개인정보가 포함된 업무에서는 로컬에서 마스킹한 뒤 클라우드 API를 쓰는 방법과 비용·속도에 관한 의견도 나왔다.

  • 128GB 맥 장비를 여러 대 보유하거나 512GB 장비를 추가하는 선택지가 언급됐다.
  • 로컬 LLM이 목적이 아닌 경우 작업·빌드·CI·서비스용 서버 구성에 초점을 뒀다.
  • 컴퓨팅 수요를 위해 맥 한 대를 팔고 스레드리퍼 서버를 만드는 방안이 거론됐다.
  • 개인정보를 로컬에서 마스킹하고 클라우드 API를 이용하는 방법이 제안됐다.
  • 로컬 추론의 답답한 속도와 클라우드 API 비용을 비교했으며 속도 중요도는 업무마다 다르다는 의견이 나왔다.
