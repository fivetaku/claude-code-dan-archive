  • 이미지 처리 실패 API 오류 메시지가 공유됐다.
  • 파일 경로를 통한 이미지 읽기는 정상 작동한다고 했다.
  • 대화창에 직접 삽입한 스크린샷만 처리되지 않는다고 했다.
  • 이미지 크기나 입력 방식 관련 유사 사례를 찾고 있었다.

  • Grok 4.6이 오퍼스급인지 다룬 매거진 글이 반복 공유됐다.
  • Grok 사용 경험에 대해 긍정적인 반응이 있었다.
  • 입력 100만 토큰당 2달러, 출력 6달러라는 가격이 언급됐다.
