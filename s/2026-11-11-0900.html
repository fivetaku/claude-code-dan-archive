Whosup 배포

여러 터미널 AI 에이전트 세션을 브라우저 상황판에서 관리하는 herdr 플러그인 Whosup의 배포와 저장소가 공유됐다. 각 세션의 입력 필요·실패·답변 도착·진행 중·유휴 상태를 확인하고 해당 칸으로 포커스를 옮길 수 있으며, 재부팅 뒤에는 빈 칸에서 최근 Claude Code 대화를 이어 열 수 있다. 한 참가자가 제미나이의 잘못된 설명을 보고 웹 차단 우회 도구로 오해했으나, 다시 확인하면서 세션 모니터링 도구라는 점을 파악했고 AI 답변 검증의 필요성이 언급됐다. 설치에는 herdr 0.9.0 이상과 Node.js 22.13 이상이 필요하며 macOS와 Linux를 지원하는 MIT 오픈소스다.

  • 설치 명령은 herdr plugin install fivetaku/whosup --yes이며 상황판 주소는 http://127.0.0.1:4790이다.
  • 상황판에서 세션 상태를 한눈에 확인하고 칸을 누르면 herdr가 해당 세션으로 포커스를 옮긴다.
  • 재부팅 뒤 빈 칸의 '이어서 열기'로 해당 폴더의 최근 Claude Code 대화를 이어 열 수 있다.
  • 제미나이가 처음에는 웹 자동화 차단 우회와 코드 리뷰 등을 위한 도구라고 잘못 설명해 용도에 대한 혼선이 생겼다.
  • 관련 설명 중 인세인 리서치와 Claude Code 플러그인 마켓플레이스가 혼동됐을 가능성이 언급됐다.
  • https://github.com/fivetaku/whosup

페이블 초기화권

Claude의 페이블 사용량 초기화권이 별도 페이블 한도와 전체 주간 사용량에 어떻게 반영되는지 여러 참가자가 논의했다. 참가자들은 페이블 초기화 시 전체 주간 한도가 무조건 초기화되는 것이 아니라 페이블 사용분만큼 차감되는 것으로 이해했으며, 페이블을 적게 썼다면 사용 전 손익을 확인하라고 조언했다. 페이블만 사용한 사례에서 전체 주간 사용량도 0%가 되는지 질문과 긍정적 추정이 나왔고, 초기화 후 사용량이 크게 회복됐다는 경험도 공유됐다. 별도의 전체 초기화권을 받았다는 발언도 있었지만 지급 조건이나 정확한 계산 방식은 공식적으로 확인되지 않았다.

  • 페이블 사용량과 전체 주간 사용량이 별도로 증가하는지, 무료 초기화권의 대상이 페이블인지 질문이 나왔다.
  • 참가자들은 페이블 초기화가 전체 주간 사용량의 페이블 사용분에도 반영된다고 이해했다.
  • 페이블을 적게 쓰고 주간 한도를 채웠다면 초기화권을 쓰기 전에 페이블 사용량을 확인하라는 조언이 나왔다.
  • 페이블만 사용한 경우 전체 주간 사용량도 0%가 되는지 논의했으나 대화상 확정적인 공식 설명은 없다.
  • 전체 초기화권을 받았다는 발언과 페이블 초기화 후 사용량이 크게 회복됐다는 개인 경험이 공유됐다.

제미나이 카본 평가

제미나이 카본이 나왔다는 소식과 사용 가능 요금제에 관한 대화가 오갔다. 참가자들은 울트라 요금제부터 이용할 수 있다는 인상과 한국어 성능이 아르곤보다 뛰어나다는 전언을 공유했다. 오퍼스와 비교해 상위 호환이라는 평가와 오퍼스보다 못하다는 평가가 엇갈렸으며, 접근 범위와 성능은 대화에서 독립적으로 검증되지 않았다.

  • 카본이 일부 사용자에게 제공되는 것으로 보인다는 반응이 나왔다.
  • 프로는 안 되고 울트라 요금제부터 가능하다는 참가자 추정이 있었다.
  • 한국어 성능이 아르곤보다 좋다는 전언이 공유됐다.
  • 오퍼스와의 비교에서는 높게 평가하는 전언과 직접 체감상 못하다는 의견이 엇갈렸다.

맥 스튜디오 저장장치

  • 추가 저장공간은 외장 인클로저를 붙여 확보할 계획이 공유됐다.
  • 맥 미니의 작업 부담과 사용하지 않는 맥북 자원, 맥 스튜디오 선호에 관한 경험이 오갔다.
