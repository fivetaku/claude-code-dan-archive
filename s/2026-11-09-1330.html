Claude나 Codex를 여러 계정으로 쓰려면 별도 구글 계정을 만드는지, 한도 초과 시 작업 상태를 유지하며 계정을 전환할 수 있는지 질문이 나왔다. 가능하다는 답과 함께 OpenCodex, CLIProxyAPI, TeamClaude가 언급됐고, 기본 기능은 아니라는 반응이 이어졌다. 한 참가자는 두 계정을 사용하다 한도를 소진하면 로그아웃 후 다시 로그인한다고 공유했다. OmO를 다시 써야 할지에 대한 언급도 있었다.

  • 한 계정에 Claude 구독을 두 개 추가하기 어려운 듯해 별도 계정 사용 여부를 물었다.
  • 계정 전환 관련 도구로 OpenCodex, CLIProxyAPI, TeamClaude가 언급됐다.
  • OpenCodex는 여러 모델을 연결하는 로컬 프록시이고, CLIProxyAPI는 AI CLI 구독 계정을 호환 API로 연결하는 프록시로 소개됐다.
  • TeamClaude는 여러 계정과 API 키를 묶어 사용량 한도에 따라 계정을 전환하는 도구로 소개됐다.
  • 별도 도구 대신 한도 소진 시 로그아웃하고 다른 계정으로 로그인하는 사용 사례도 나왔다.
