  • OmO Native는 별도 복잡한 설정 없이 명령어 하나로 시작하는 버전으로 소개됐다.
  • OMC·OMP·OMX 등 OM 계열 하네스가 언급됐다.
  • 긴 데이터 분류나 큰 작업은 실행 시간이 길어질 수 있다는 의견이 나왔다.
  • Claude Code는 순정 하네스, Codex·GPT 모델은 OmO 하네스로 분리해 쓰는 사례가 공유됐다.
  • 모델 둘 다 사용 가능하면 OmO Native에 함께 연결하라는 제안이 나왔다.

예상치 못한 사용량

개인 계정에서 Claude Code를 사용하지 않았는데 사용량이 소진됐다는 문제가 제기됐다. 계정 탈취 가능성이 언급됐으며, 비밀번호 변경과 설정의 인증 토큰·생성 키 확인이 권장됐다. 알 수 없는 키가 반복 생성되면 이상 징후일 수 있어 토큰을 모두 폐기(revoke)하는 방안도 제시됐다.

  • 사용하지 않은 개인 계정에서 사용량이 소진된 사례가 보고됐다.
  • 해킹 또는 인증 정보 노출 가능성이 거론됐다.
  • 비밀번호 변경과 계정 설정 점검이 권장됐다.
  • Claude Code 설정에서 인증 토큰을 확인하라는 조언이 나왔다.
  • 모르는 키가 있거나 키가 계속 생성되면 토큰 전체 폐기를 검토하라는 의견이 나왔다.

  • OmO의 방식을 Claude Code 내부의 Codex 스킬로 옮긴 사례가 공유됐다.

  • 훅과 설정 패턴을 여러 개 미리 정리해 사용하는 방식이 언급됐다.
  • Claude Code의 오케스트레이션 시 Codex에 우선 작업을 맡기도록 구성할 수 있다.
  • 이 구성은 강제가 아니라 상황에 따라 조정하는 방식으로 설명됐다.
