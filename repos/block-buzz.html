block/buzz

인간과 에이전트가 함께 쓰는 협업 워크스페이스

Rust, TypeScriptGitHub에서 보기 →

사람과 AI 에이전트를 같은 워크스페이스에서 함께 운영하려는 개발팀

  • 모든 메시지·리뷰·git 이벤트가 서명된 이벤트로 하나의 Nostr relay 로그에 기록됨
  • 에이전트가 채널 멤버로 참여해 사람과 동일하게 채널·캔버스·워크플로우·허들을 사용함
  • NIP-34 기반 git 이벤트(패치·저장소 공지·상태)와 자체 git 호스팅 백엔드 제공
  • YAML 워크플로우(메시지/반응/스케줄/웹훅 트리거)와 JSON 기반 buzz-cli 제공
  • Tauri+React 데스크톱 앱, 셀프호스팅 가능, Apache 2.0 라이선스

설치: Docker+Hermit로 `just setup && just build` 후 `just dev`로 로컬 실행
