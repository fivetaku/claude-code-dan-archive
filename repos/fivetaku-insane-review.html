fivetaku/insane-review

API 없는 GPT Pro를 브라우저로 호출하는 리뷰 플러그인

PythonGitHub에서 보기 →

Claude Code로 개발하며 API가 없는 GPT Pro의 코드 리뷰를 구독 비용만으로 활용하려는 개발자.

  • GPT Pro는 공식 API가 없어 로그인된 ChatGPT 웹 세션을 CDP로 직접 제어해 리뷰를 수행한다.
  • repomix로 관련 코드를 라인 번호 포함 전체 코드로 패킹해 전송한다(리뷰 시 --compress 미사용).
  • 모델 불일치, 미로그인, 빈 패킹, 이전 턴 응답 등 이상 상황에서는 fail-closed로 전송·저장을 거부한다.
  • 독립 리뷰어 또는 agent-council의 웹 전용 멤버 두 가지 방식으로 사용할 수 있다.
  • 응답은 프로젝트별 .insane-review/ 폴더에 pack·response 파일로 저장되며 파일 권한이 제한된다(chmod 600).

설치: /plugin marketplace add 후 /plugin install insane-review, CDP 브라우저 세팅 후 /insane-review 실행
