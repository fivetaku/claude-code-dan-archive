fivetaku/kkirikkiri

한 문장 설명으로 AI 에이전트 팀을 구성해 실행하는 Claude Code 플러그인

GitHub에서 보기 →

Claude Code에서 여러 AI 에이전트로 구성된 팀을 빠르게 조직해 리서치·개발·분석·콘텐츠·PM 작업을 맡기고 싶은 사용자

  • 자연어 입력만으로 인터뷰(2~3개 질문)를 거쳐 팀을 자동 구성한다
  • 설치된 도구(Codex CLI, Antigravity CLI, .claude/agents/)를 스캔해 환경에 맞는 팀을 만든다
  • Claude, Codex CLI, Antigravity CLI가 각각 다른 역할을 맡는 멀티모델 팀 구성을 지원한다
  • 결과가 부족하면 최대 3라운드까지 팀을 재시도하거나 재구성하는 검증 루프가 있다
  • 팀 작업 내용을 .kkirikkiri/teams/에 공유 메모리로 남겨 세션 간 이어받기가 가능하다

설치: /plugin marketplace add https://github.com/fivetaku/gptaku_plugins.git 후 /plugin install kkirikkiri

이런 얘기가 매일 오가는 방이 있어요
