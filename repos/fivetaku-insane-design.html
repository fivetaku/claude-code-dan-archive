fivetaku/insane-design

웹사이트 CSS에서 디자인 토큰을 추출해 design.md로 만드는 도구

PythonGitHub에서 보기 →

특정 사이트의 디자인 시스템을 추출해 AI 코딩 에이전트나 자신의 프로젝트에 반영하려는 개발자에게 유용하다.

  • 실제 CSS를 파싱해 색상, 타이포그래피, 스페이싱, 그림자, 반경 토큰을 추출한다.
  • AI 에이전트가 바로 참고할 수 있는 16개 섹션 구조의 design.md 문서를 생성한다.
  • Stripe, Apple, Linear 등 100개 사이트의 사전 분석 결과를 분석 없이 바로 적용할 수 있다.
  • 클릭으로 색상값을 복사할 수 있는 인터랙티브 HTML 리포트를 함께 제공한다.
  • 기존 프로젝트의 CSS나 Tailwind 설정에 추출한 디자인 토큰을 주입하는 적용 모드를 지원한다.

설치: Claude Code 플러그인 마켓플레이스 추가 후 /plugin install insane-design
